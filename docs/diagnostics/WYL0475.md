# WYL0475

```
error[WYL0475]: shared lambda cannot capture 'value'
```

A non-escaping shared lambda refers to what it captures in place, and another thread reads that
place while the lambda runs
([Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)). The function holding
a `ref` parameter may change the value during that time, so a shared lambda may not capture one.

## Example

```wyl
void run(shared fn() -> int f) { }

void read(ref int value) {
    run(() -> value);
}

void main() { }
```

## Fix

Copy the value to a local first, or take it as an `in` parameter, which a shared lambda may capture.

Spec: [Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)
