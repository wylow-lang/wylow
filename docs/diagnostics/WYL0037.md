# WYL0037

```
error[WYL0037]: 'static' cannot be used on an import
```

The only modifier an import takes is a visibility, which re-exports the name it brings in.

## Example

```wyl
static import std::collections::List;

void main() { }
```

## Fix

Remove the modifier.

Spec: [Imports](../spec/03-programs.md#programs.imports)
