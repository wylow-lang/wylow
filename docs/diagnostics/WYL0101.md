# WYL0101

```
error[WYL0101]: struct cannot declare a parameterless constructor
```

`T()` is the struct's default value, made from its field initializers, and a struct cannot declare it.

## Example

```wyl
struct Point {
    pub int x;

    pub Point() { x = 1; }
}

void main() { }
```

## Fix

Give the fields initializers instead: `pub int x = 1;`.

Spec: [The default value](../spec/07-structs.md#structs.constructors.default)
