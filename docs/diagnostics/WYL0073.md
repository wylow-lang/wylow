# WYL0073

```
error[WYL0073]: 'new' cannot create an array of arrays
```

One `new` creates one array; it has no form that creates the inner arrays too.

## Example

```wyl
void main() {
    var grid = new int[2][3];
}
```

## Fix

Create the outer array, then each inner one.

Spec: [Arrays](../spec/04-types.md#types.arrays)
