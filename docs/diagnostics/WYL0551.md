# WYL0551

```
error[WYL0551]: the downloaded archive holds no file 'sample/absent.h'
note: the archive is from 'https://files.test/sample.zip'
```

A package's `fetch` entry names the files of the download that the package uses. The compiler
reports this error when a path in the `files` list is not a file of the archive. The error names
the path and the URL. No file of the download joins the package's native files.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "fetch_missing_file";

native {
    fetch {
        url = "https://files.test/sample.zip";
        sha256 = "3806927d8ed43dea85666325770b2a572b1dcc6e355127eaa87938ec1d85ab11";
        files = ["sample/absent.h"];
    }
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Name each file by its path inside the archive, as the archive stores it. A path is relative to the
archive's root, and each segment is separated by `/`.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
