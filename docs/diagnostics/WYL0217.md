# WYL0217

```
error[WYL0217]: default value of 'holder' must be 'null'
```

A parameter whose type involves a type parameter has only `null` as its default value.

## Example

```wyl
struct Holder<T> {
    int count;
    T? item;
}

void generic<T>(Holder<T> holder = Holder<T>()) { }

void main() { }
```

## Fix

Use `null`, or remove the default value.

Spec: [Parameters](../spec/12-functions.md#functions.parameters)
