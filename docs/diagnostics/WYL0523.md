# WYL0523

```
error[WYL0523]: 'next' has type 'fn(void*, int) -> int', which cannot be converted to 'extern fn(void*, long) -> int'
```

A `@CCallback` function converts only to the `extern fn` type whose parameter types and return type
are the function's own. C calls the pointer with the types of the `extern fn` type, so a function
that expects other types would read its arguments wrongly. If the name has several overloads and
none of them has the types, the message says so instead.

## Example

```wyl
@CCallback
int next(void* context, int value) { return value + 1; }

void main() {
    extern fn(void*, long) -> int handler = next;
}
```

## Fix

Declare the function with the parameter and return types of the `extern fn` type:

```wyl
@CCallback
int next(void* context, long value) { return (int) value + 1; }

void main() {
    extern fn(void*, long) -> int handler = next;
}
```
