# WYL0394

```
error[WYL0394]: 'count' might not have been assigned
```

A local declared without an initializer holds no value until it is assigned on every path to the
use.

## Example

```wyl
void main() {
    int count;
    std::print(count);
}
```

## Fix

Assign the local before it is read on every path, or give it an initializer where it is declared.

Spec: [Definite assignment](../spec/16-flow.md#flow.definite-assignment)
