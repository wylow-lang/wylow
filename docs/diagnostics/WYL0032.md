# WYL0032

```
error[WYL0032]: directory 'order-queue' contains source files, but 'order-queue' is not an identifier
```

A directory under `src/` that holds source files, or a directory below it that does, is a module, and a module's name is the directory's, so it is an identifier.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

```wyl src/main.wyl
void main() { }
```

```wyl src/order-queue/queue.wyl
pub struct Queue { }
```

## Fix

Rename the directory to an identifier, by convention in `snake_case`: `order_queue`.

Spec: [Modules](../spec/03-programs.md#programs.modules)
