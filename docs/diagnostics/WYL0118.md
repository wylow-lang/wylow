# WYL0118

```
error[WYL0118]: only one of 'virtual', 'override', and 'abstract' can be used
```

A method is `virtual`, `override`, or `abstract`; the three do not combine.

## Example

```wyl
class Shape {
    pub virtual abstract int area();
}

void main() { }
```

## Fix

Keep the one that applies.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
