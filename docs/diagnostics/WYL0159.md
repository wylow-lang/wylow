# WYL0159

```
error[WYL0159]: values of 'Shape.Circle': expected 1, found 2
```

A variant is created with one value for each of its fields.

## Example

```wyl
enum Shape {
    Circle(int radius),
    Empty
}

void main() {
    var s = Shape.Circle(1, 2);
}
```

## Fix

Give the number of values the variant declares.

Spec: [Variants](../spec/09-enums.md#enums.variants)
