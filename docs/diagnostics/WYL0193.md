# WYL0193

```
error[WYL0193]: type parameter 'T' hides the type parameter 'T' of its type
```

A method of a generic type may not declare a type parameter with the name of one of its type.

## Example

```wyl
struct Box<T> {
    pub T value;

    pub void each<T>(T other) { }
}

void main() { }
```

## Fix

Rename the method's type parameter.

Spec: [Type parameters](../spec/11-generics.md#generics.parameters)
