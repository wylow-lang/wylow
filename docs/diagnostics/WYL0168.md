# WYL0168

```
error[WYL0168]: '@Repr' type: expected an integer type, found 'float'
```

The type in `@Repr` is one of the integer types.

## Example

```wyl
@Repr(float)
enum Color {
    Red,
    Green
}

void main() { }
```

## Fix

Use an integer type: `byte`, `short`, `int`, `long`, or an unsigned or pointer-sized one.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
