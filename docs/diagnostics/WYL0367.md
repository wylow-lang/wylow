# WYL0367

```
error[WYL0367]: cannot switch on a 'void' value
```

A switch tests a value, and a call that returns nothing produces none.

## Example

```wyl
void nothing() { }

void main() {
    switch (nothing()) {
        default -> { }
    }
}
```

## Fix

Switch on an expression that produces a value.

Spec: [Switch statements](../spec/14-statements.md#statements.switch)
