# WYL0447

```
error[WYL0447]: 'this' parameter is only for a method of a struct or enum
```

A by-value receiver is a struct's or an enum's, whose method it is. A class, an interface, a
constructor, an indexer, and a free function have none.

## Example

```wyl
class Cell {
    int value;

    int read(this Cell cell) {
        return cell.value;
    }
}

void main() { }
```

## Fix

Declare the method on a struct or an enum, or take the value as an ordinary parameter.

Spec: [By-value receivers](../spec/07-structs.md#structs.methods.by-value)
