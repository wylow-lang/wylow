# WYL0447

```
error[WYL0447]: 'this' parameter is only for a method of a struct or enum, or an extension method
```

Only a method of a struct or enum can have a by-value receiver, and only a top-level function can
mark its first parameter `this` to be an extension method. A method of a class or an interface, a
constructor, and an indexer cannot have a `this` parameter.

## Example

```wyl
class Cell {
    int value;

    int read(this Cell cell) {
        return cell.value;
    }
}

void main() { }
```

## Fix

Declare the method on a struct or an enum, declare a top-level function to write an extension method,
or take the value as an ordinary parameter.

Spec: [By-value receivers](../spec/07-structs.md#structs.methods.by-value)
