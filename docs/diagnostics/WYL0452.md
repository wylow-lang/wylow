# WYL0452

```
error[WYL0452]: Item.name cannot implement an interface method with a by-value receiver
```

An interface call uses its receiver in place, so a method that takes its receiver by value cannot
implement one. The receiver is not part of the signature, so the ordinary signature check does not
catch this.

## Example

```wyl
interface Named {
    int name();
}

struct Item implements Named {
    int value;

    int name(this Item item) {
        return item.value;
    }
}

void main() { }
```

## Fix

Implement the interface method with an ordinary method, in place.

Spec: [Implementing an interface](../spec/10-interfaces.md#interfaces.implementing)
