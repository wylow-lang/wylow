# WYL0086

```
error[WYL0086]: cannot assign a 'void' value to a variable
```

A call to a function that returns nothing gives no value to hold.

## Example

```wyl
void nothing() { }

void main() {
    var v = nothing();
}
```

## Fix

Call the function as a statement.

Spec: [Inferred types](../spec/06-variables.md#variables.locals.var)
