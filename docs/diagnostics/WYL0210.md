# WYL0210

```
error[WYL0210]: 'final' cannot be used on an interface
```

A type declaration takes only the modifiers its kind defines.

## Example

```wyl
final interface Flagged { }

void main() { }
```

## Fix

Remove the modifier, or use it on a declaration of a kind that takes it.

Spec: [Function declarations](../spec/12-functions.md#functions.declarations)
