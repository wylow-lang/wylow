# WYL0518

```
error[WYL0518]: 'include' names 'vendor/parser/include', which is not a directory
```

Each path in the manifest's `native` block is relative to the package's directory. Each directory that `include` or `libraryPaths` names must exist, and so must each file that `copy` names. The compiler checks the lists of `native` and the lists of the platform block for the platform that the program is built for. It does not check the platform blocks of other platforms.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "parser_tool";

native {
    include = ["vendor/parser/include"];
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Correct the path, or add the directory or file that it names.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
