# WYL0445

```
error[WYL0445]: cannot bind 'ref' to a field of a variant
```

A variant's field is not changed in place, so it is bound with `in var`, not `ref var`.

## Example

```wyl
enum Shape {
    Circle(int radius),
    Empty,
}

void main() {
    var s = Shape.Circle(1);
    switch (s) {
        case Circle(ref var r) -> { }
        default -> { }
    }
}
```

## Fix

Bind the field with `in`.
