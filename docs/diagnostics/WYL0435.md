# WYL0435

```
error[WYL0435]: '{' in an interpolated string is not closed
```

A hole of an interpolated string ends with its `}`. Here its format specifier runs to the string's closing `"`.

## Example

```wyl
void main() {
    int x = 1;
    std::print($"{x:D5");
}
```

## Fix

End the hole with `}` before the closing `"`: `$"{x:D5}"`.

Spec: [Interpolated strings](../spec/02-lexical.md#lexical.literals.interpolated)
