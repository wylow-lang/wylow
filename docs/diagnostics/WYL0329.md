# WYL0329

```
error[WYL0329]: 'null' cannot be a pattern of 'is'
```

`is` tests a type or a variant. A null test is written with `== null`.

## Example

```wyl
void main() {
    int? x = 1;
    var b = x is null;
}
```

## Fix

Compare with `== null`.

Spec: [`is`](../spec/13-expressions.md#expressions.is)
