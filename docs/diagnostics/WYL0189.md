# WYL0189

```
error[WYL0189]: 'Box.name' cannot be 'unsafe'
```

A call through an interface needs no `unsafe` code, so an implementation cannot require it.

## Example

```wyl
interface Named {
    String name();
}

class Box implements Named {
    unsafe String name() { return "b"; }
}

void main() { }
```

## Fix

Remove `unsafe`, and put the unsafe code of the body in an `unsafe` block.

Spec: [Implementing an interface](../spec/10-interfaces.md#interfaces.implementing)
