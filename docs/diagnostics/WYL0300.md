# WYL0300

```
error[WYL0300]: cannot find method 'missing' in 'Point'
```

A method call names a method the receiver's type declares.

## Example

```wyl
struct Point { int x; }

void main() {
    var p = Point(1);
    p.missing();
}
```

## Fix

Use a declared method, or correct the method's name.

Spec: [Calls](../spec/13-expressions.md#expressions.calls)
