# WYL0411

```
error[WYL0411]: 'point' might be set to null while its value is in use
```

A place in the value of a narrowed nullable local is used while an operation runs. That operation
can set the local to null, which would destroy the place.

## Example

```wyl
struct Point { pub int x; }

int clear(ref Point? point) {
    point = null;
    return 1;
}

void main() {
    mut Point? point = Point(1);
    if (point != null) {
        point.x = clear(ref point);
    }
}
```

## Fix

Copy the value to a variable first, or set the local to null after the operation that uses the
place.

Spec: [Nullable references](../spec/17-memory.md#memory.nullable-references)
