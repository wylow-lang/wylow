# WYL0321

```
error[WYL0321]: '?:' cannot choose between references
```

A reference must refer to one place for its whole life, and a conditional would choose between two references.

## Example

```wyl
struct Bag {
    int[2] items;

    mut ref? int at(int index) {
        return ref items[index];
    }
}

void main() {
    mut Bag bag = Bag();
    bool flag = true;
    var x = flag ? bag.at(0) : null;
}
```

## Fix

Use `if` with a variable for each branch.

Spec: [The conditional operator](../spec/13-expressions.md#expressions.conditional)
