# WYL0063

```
error[WYL0063]: cannot find type 'Node'
```

A type name must be declared in the program, imported, or one of the names every file sees.

## Example

```wyl
void main() {
    Node first;
}
```

## Fix

Declare the type, or import it, as in `import std::collections::List;`.

Spec: [Writing types](../spec/04-types.md#types.syntax)
