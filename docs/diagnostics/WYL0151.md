# WYL0151

```
error[WYL0151]: enum variants must come before the enum's methods
```

The variants of an enum are listed first. The methods follow, after a `;`.

## Example

```wyl
enum Color {
    Red;

    pub int code() { return 1; }

    Green
}

void main() { }
```

## Fix

Move the variant above the first method.

Spec: [Enum declarations](../spec/09-enums.md#enums.declarations)
