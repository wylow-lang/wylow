# WYL0052

```
error[WYL0052]: 'pub(crate)' is not a visibility
```

In `pub(...)`, the parentheses name a scope. A visibility is one word: `module`, `package`, or `pub`. The parenthesized forms `pub(module)` and `pub(package)` are removed.

## Example

```wyl
class Account {
    pub(crate) int balance;
}

void main() { }
```

## Fix

Write `module` or `package`, without parentheses.

Spec: [Visibility](../spec/03-programs.md#programs.visibility)
