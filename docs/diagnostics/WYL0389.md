# WYL0389

```
error[WYL0389]: only 'null' can be listed with 'default'
```

A case that lists `default` may list only `null` with it, because `default` already covers every other value.

## Example

```wyl
void main() {
    int n = 1;
    switch (n) {
        case 1, default -> { }
    }
}
```

## Fix

Write `case null, default`, or put the other pattern in a case of its own.

Spec: [`case null`](../spec/15-patterns.md#patterns.cases.null)
