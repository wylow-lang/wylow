# WYL0342

```
error[WYL0342]: variable cannot be declared here
```

A variable can be declared only in the initializer of a `for` loop; the condition and the increment are expressions.

## Example

```wyl
void main() {
    for (int i = 0; i < 3; int j = 1) { }
}
```

## Fix

Move the declaration into the loop's initializer or its body.

Spec: [Declaration statements](../spec/14-statements.md#statements.declarations)
