# WYL0180

```
error[WYL0180]: cannot create an instance of interface 'Named'
```

An interface has no objects of its own. A variable of the interface type refers to an object of a class that implements it.

## Example

```wyl
interface Named {
    String name();
}

void main() {
    var n = new Named();
}
```

## Fix

Create an object of a class that implements the interface.

Spec: [Interface declarations](../spec/10-interfaces.md#interfaces.declarations)
