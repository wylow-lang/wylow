# WYL0029

```
error[WYL0029]: dependency 'parser' is not a block
```

Each entry of `dependencies` is a block that gives the library's directory with `path`. An entry that gives a string or a list in place of a block is an error.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    parser = "vendor/parser";
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Write the entry as a block: `parser { path = "vendor/parser"; }`.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
