# WYL0131

```
error[WYL0131]: cannot call abstract method 'Shape.area' through 'super'
```

An abstract method has no implementation for `super` to call.

## Example

```wyl
abstract class Shape {
    pub abstract int area();
}

class Square extends Shape {
    pub override int area() { return super.area(); }
}

void main() { }
```

## Fix

Do not call it; compute the value in the override.

Spec: [Abstract and final classes](../spec/08-classes.md#classes.abstract)
