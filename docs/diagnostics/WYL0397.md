# WYL0397

```
error[WYL0397]: 'node' might be null
```

A nullable local or by-value parameter is used as its non-null type where narrowing does not show
that it is not null.

## Example

```wyl
class Node { pub int value; }

void show(Node? node) {
    std::print(node.value);
}

void main() { }
```

## Fix

Check it with `if (node != null)`, or use `?.` or `!`. A `ref` variable and a local that a lambda
assigns are never narrowed, so copy one to a local first.

Spec: [Narrowing](../spec/16-flow.md#flow.narrowing)
