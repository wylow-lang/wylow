# WYL0253

```
error[WYL0253]: 'operator []=' must take the indices, then the assigned value
```

`operator []=` takes the indices and then the assigned value.

## Example

```wyl
struct Shapes {
    int operator [](int i) {
        return 0;
    }

    mut void operator []=(int i) { }
}

void main() { }
```

## Fix

Add the value parameter after the indices.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
