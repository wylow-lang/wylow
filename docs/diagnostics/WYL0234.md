# WYL0234

```
error[WYL0234]: no overload of 'id' takes 2 type arguments
```

An overload is selected only when an overload takes the number of type arguments written.

## Example

```wyl
T id<T>(T value) {
    return value;
}

void main() {
    id<int, int>(1);
}
```

## Fix

Write the number of type arguments that the function takes.

Spec: [Overload resolution](../spec/12-functions.md#functions.overloading.resolution)
