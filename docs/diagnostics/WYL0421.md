# WYL0421

```
error[WYL0421]: 'Result' returned by 'read' is not used
```

A call that returns a `Result` reports a failure the program should handle or choose to ignore. The
call is used, returned, or discarded explicitly.

## Example

```wyl
enum IoError { Missing }

Result<int, IoError> read() {
    return Ok(1);
}

void main() {
    read();
}
```

## Fix

Handle the result with `switch` or `is`, return it, or discard it: `_ = read();`.

Spec: [Unused results](../spec/18-errors.md#errors.unused)
