# WYL0214

```
error[WYL0214]: 'AB.f' inherits different default values for parameter 'x'
```

A class that inherits two methods of one name must receive the same default value for each parameter from both.

## Example

```wyl
interface A {
    void f(int x = 1);
}

interface B {
    void f(int x = 2);
}

class AB implements A, B {
    void f(int x) { }
}

void main() { }
```

## Fix

Give both inherited methods the same default value for the parameter.
