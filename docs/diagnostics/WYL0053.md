# WYL0053

```
error[WYL0053]: visibility cannot be given to a block of members
```

Each member has its own visibility.

## Example

```wyl
class Account {
    pub {
        int balance;
    }
}

void main() { }
```

## Fix

Write the visibility on each member: `pub int balance;`.

Spec: [Visibility](../spec/03-programs.md#programs.visibility)
