# WYL0482

```
error[WYL0482]: '@SuppressWarnings' takes one or more string literals
```

`@SuppressWarnings` names the warnings it turns off, each as a string literal. An annotation with no arguments, or with an argument that is not a string literal, names no warning.

## Example

```wyl
@SuppressWarnings
void main() { }
```

## Fix

List the names of the warnings to turn off: `@SuppressWarnings("unqualified-call")`.

Spec: [`@SuppressWarnings`](../spec/22-annotations.md#annotations.suppress-warnings)
