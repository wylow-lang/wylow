# WYL0331

```
error[WYL0331]: pattern always matches
```

`is` requires a pattern that can fail. A pattern that matches every value leaves nothing to test.

## Example

```wyl
void main() {
    int n = 1;
    var b = n is var all;
}
```

## Fix

Use a pattern that can fail, or test the value directly.

Spec: [`is`](../spec/13-expressions.md#expressions.is)
