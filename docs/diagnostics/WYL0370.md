# WYL0370

```
error[WYL0370]: 'default' must be the last case
```

The `default` case is written last, after every other case.

## Example

```wyl
void main() {
    int? n = 1;
    switch (n) {
        default -> { }
        case null -> { }
    }
}
```

## Fix

Move `default` to the end of the switch.

Spec: [Switch statements](../spec/14-statements.md#statements.switch)
