# WYL0459

```
error[WYL0459]: cannot discard 'x'
```

`discard` ends the lifetime of a by-value parameter of a unique struct that declares a
destructor. It does not apply to a local variable, to a `ref` or `in` parameter, to a nullable
parameter, or to a value whose type has no destructor.

## Example

```wyl
void close(int x) {
    discard x;
}

void main() { }
```

## Fix

Discard a by-value parameter of a unique struct that declares a destructor. Otherwise, remove the
statement and let the value be released at the end of the function.

Spec: [Destructors and `discard`](../spec/07-structs.md#structs.unique.destructors)
