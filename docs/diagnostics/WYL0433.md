# WYL0433

```
error[WYL0433]: cannot find annotation '@Fast'
```

An annotation's name is one of the annotations the specification gives.

## Example

```wyl
@Fast
void run() { }

void main() { }
```

## Fix

Write the annotation's name, or remove it. The annotations are in [The
annotations](../spec/22-annotations.md#annotations.list).

Spec: [The annotations](../spec/22-annotations.md#annotations.list)
