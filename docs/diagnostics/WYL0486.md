# WYL0486

```
error[WYL0486]: elements of an 'InIterator' cannot be borrowed with 'ref'
```

The `current` method of an `InIterator<T>` returns an `in T`: a read-only reference to the element.
A container gives an `InIterator` when changing an element in place would break the container,
such as a map whose keys decide where its entries are. A loop over an `InIterator` therefore binds
its variable with `in` or as a copy, and cannot bind it with `ref`.

## Example

```wyl
import std::iteration::InIterator;

struct Cells implements InIterator<int> {
    int[2] values;
    int at;

    pub mut bool moveNext() {
        at++;
        return at < 2;
    }

    pub in int current() {
        return ref values[at];
    }
}

void main() {
    for (ref int value : Cells([1, 2], -1)) { }
}
```

## Fix

Declare the variable `in` to read each element in place, or without `ref` to copy it. To change
the elements, loop over an iterator that the container gives for changing them, which implements
`RefIterator<T>`.
