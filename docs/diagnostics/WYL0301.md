# WYL0301

```
error[WYL0301]: 'Point.x' is a field, not a method
```

A field holds a value. It is read or assigned without parentheses.

## Example

```wyl
struct Point { int x; }

void main() {
    var p = Point(1);
    p.x();
}
```

## Fix

Remove the parentheses.

Spec: [Calls](../spec/13-expressions.md#expressions.calls)
