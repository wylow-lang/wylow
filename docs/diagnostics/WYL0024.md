# WYL0024

```
error[WYL0024]: 'name' is already given
```

A key is given at most once in a block of the manifest.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
name = "store";
```

```wyl src/main.wyl
void main() { }
```

## Fix

Remove one of the entries.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
