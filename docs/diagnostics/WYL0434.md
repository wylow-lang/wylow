# WYL0434

```
error[WYL0434]: '@CallerLocation' cannot be used on virtual, abstract, or interface methods
```

A `@CallerLocation` function is passed the location of its call, which is fixed when the call is
made. A virtual, abstract, or interface method is called through dispatch, where the call does not
name the method that runs. A method that implements an interface method may be called through the
interface or through a bound, and such a call passes no location, so the annotation is an error on
that method too.

## Example

```wyl
class Base {
    @CallerLocation
    virtual void check() { }
}

void main() { }
```

## Fix

Remove the annotation from the virtual method, or make the method that a class marks
`@CallerLocation` non-virtual.

Spec: [`@CallerLocation`](../spec/22-annotations.md#annotations.caller-location)
