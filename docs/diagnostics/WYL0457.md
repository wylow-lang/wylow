# WYL0457

```
error[WYL0457]: cannot move 'value', which a lambda captures
```

A lambda may run more than once, so a value it captures stays where it is. A by-value use of that
value copies it, and not every type can be copied.

## Example

```wyl
fn() -> T picked<T>(T value) {
    return () -> value;
}

void main() {
    var f = picked(5);
}
```

## Fix

Give the type parameter the `copyable` bound, or refer to the captured value with `in` or `ref`.

Spec: [Captures](../spec/12-functions.md#functions.lambdas.captures)
