# WYL0442

```
error[WYL0442]: 'Buffer' cannot be a type argument
```

Generic code copies a value of its type parameter, so a type argument must be copyable. A unique struct or enum cannot be copied, and neither can a type holding one inline.

## Example

```wyl
unique struct Buffer {
    pub int length;
}

struct Box<T> {
    pub T value;
}

void main() {
    var box = Box<Buffer>(Buffer(1));
}
```

## Fix

Use a copyable type as the type argument, such as a class over the unique value, or store the value on its own.
