# WYL0527

```
error[WYL0527]: library does not give its 'version'
```

A library must declare its version in its manifest, so that a package that depends on the library can state the version it needs. The error is reported at the `kind` entry that makes the package a library.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "parser";
kind = "library";
```

```wyl src/parser.wyl
pub int depth() { return 0; }
```

## Fix

Add a `version` entry of the form `"major.minor.patch"`, such as `version = "0.1.0";`.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
