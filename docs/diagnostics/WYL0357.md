# WYL0357

```
error[WYL0357]: characters of a string cannot be borrowed with 'ref'
```

A string's characters are decoded from its bytes, so a loop cannot borrow them.

## Example

```wyl
void main() {
    String s = "abc";
    for (ref char c : s) { }
}
```

## Fix

Loop without `ref` or `in`.

Spec: [For-each](../spec/14-statements.md#statements.for-each)
