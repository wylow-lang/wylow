# WYL0508

```
error[WYL0508]: reading field 'whole' of union 'Cell' can only be done in 'unsafe' code
```

The fields of a union share their storage, and the union holds the field that was written last. A
read of a field gives the value whose bits are the union's bytes at that field. If those bits are
not a valid value of the field's type, the program's behavior is undefined, so the read needs
`unsafe` code. Writing a field needs no `unsafe` code. A compound assignment such as `+=` reads the
field before it writes it, so it needs `unsafe` code too.

## Example

```wyl
@Include("cell.h")
extern {
    union Cell {
        pub int whole;
        pub float real;
    }
}

void main() {
    mut var cell = Cell();
    cell.real = 1.5f;
    std::print(cell.whole);
}
```

## Fix

Read the field inside an `unsafe` block. The program is then responsible for reading the field
that the union holds:

```wyl
@Include("cell.h")
extern {
    union Cell {
        pub int whole;
        pub float real;
    }
}

void main() {
    mut var cell = Cell();
    cell.real = 1.5f;
    unsafe {
        std::print(cell.real);
    }
}
```
