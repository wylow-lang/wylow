# WYL0049

```
error[WYL0049]: visibility must come before other modifiers
```

A declaration's visibility comes first among its modifiers, after its annotations.

## Example

```wyl
class Account {
    static pub void open() { }
}

void main() { }
```

## Fix

Move the visibility first: `pub static void open()`.

Spec: [Visibility](../spec/03-programs.md#programs.visibility)
