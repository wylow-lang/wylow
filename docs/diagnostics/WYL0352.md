# WYL0352

```
error[WYL0352]: cannot loop over elements inside nullable 'v'
```

A loop over elements of a nullable value would borrow into a value that assigning `null` to the variable could destroy.

## Example

```wyl
struct Vec {
    int x;
    int[2] pair;
}

void main() {
    mut Vec? v = Vec(x: 1);
    if (v != null) {
        for (int e : v.pair) { }
    }
}
```

## Fix

Copy the value into a non-nullable variable, then loop over its elements.

Spec: [For-each](../spec/14-statements.md#statements.for-each)
