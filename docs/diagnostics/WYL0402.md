# WYL0402

```
error[WYL0402]: 'Weak' cannot take a nullable type
```

The type argument of `Weak` is a class or interface type without `?`. A weak reference can always
be null itself, so a nullable type argument adds nothing.

## Example

```wyl
import std::Weak;

class Node {
    Weak<Node?> parent;
}

void main() { }
```

## Fix

Write `Weak<Node>`.

Spec: [Weak references](../spec/17-memory.md#memory.weak)
