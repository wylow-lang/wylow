# WYL0207

```
error[WYL0207]: 'Point' cannot be a bound
```

A bound is an interface, or the name of a type property.

## Example

```wyl
struct Point {
    pub int x;
}

void f<T extends Point>(T value) { }

void main() { }
```

## Fix

Bound the type parameter by an interface that `Point` implements, or write the type itself.

Spec: [Bounds](../spec/11-generics.md#generics.bounds)
