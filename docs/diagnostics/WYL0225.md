# WYL0225

```
error[WYL0225]: 'ref' argument: expected 'long', found 'int'
```

A `ref` argument has exactly the type of its parameter; no conversion applies.

## Example

```wyl
void widen(ref long x) { }

void main() {
    mut int n = 1;
    widen(ref n);
}
```

## Fix

Pass a variable of the parameter's type.

Spec: [Parameter modes](../spec/12-functions.md#functions.parameters.modes)
