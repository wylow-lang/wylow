# WYL0292

```
error[WYL0292]: 'super' can only be used to call methods
```

`super` selects the base class's members for a call. A field is reached through `this`.

## Example

```wyl
class Base { int x; }

class Derived extends Base {
    void f() {
        var y = super.x;
    }
}

void main() { }
```

## Fix

Write `this.x`, or call a base method with `super`.

Spec: [Member access](../spec/13-expressions.md#expressions.members)
