# WYL0522

```
error[WYL0522]: 'next' cannot be converted to 'extern fn(void*, int) -> int' because it is not marked '@CCallback'
```

Only a function marked `@CCallback` converts to an `extern fn` type, a C function pointer. The
annotation marks each function that C code may call, and the compiler checks that the function's
parameter and return types are blittable.

## Example

```wyl
int next(void* context, int value) { return value + 1; }

void main() {
    extern fn(void*, int) -> int handler = next;
}
```

## Fix

Mark the function `@CCallback`:

```wyl
@CCallback
int next(void* context, int value) { return value + 1; }

void main() {
    extern fn(void*, int) -> int handler = next;
}
```
