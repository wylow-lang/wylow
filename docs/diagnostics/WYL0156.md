# WYL0156

```
error[WYL0156]: variant fields cannot have default values
```

A variant field takes its value from the expression that creates the variant, so it has no default.

## Example

```wyl
enum Shape {
    Circle(int radius = 1),
    Empty
}

void main() { }
```

## Fix

Remove the default value.

Spec: [Variants](../spec/09-enums.md#enums.variants)
