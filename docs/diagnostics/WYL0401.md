# WYL0401

```
error[WYL0401]: 'pick' must return a value on every path
```

A function, method, or lambda whose return type is not `void` reaches the end of its body without
returning a value.

## Example

```wyl
int pick(bool found) {
    if (found) {
        return 1;
    }
}

void main() { }
```

## Fix

Return a value on every path, or end a path with `panic(...)`, which never returns.

Spec: [Returns and reachability](../spec/16-flow.md#flow.returns)
