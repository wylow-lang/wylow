# WYL0027

```
error[WYL0027]: package name 'my-shop' is not an identifier
```

A package's name is an identifier: ASCII letters, digits, and `_`, not starting with a digit, and not a keyword.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "my-shop";
```

```wyl src/main.wyl
void main() { }
```

## Fix

Use an identifier, by convention in `snake_case`: `my_shop`. It need not match the directory's name.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
