# WYL0223

```
error[WYL0223]: cannot pass 'n' by 'ref'
```

A place is passed by `ref` only when it is mutable.

## Example

```wyl
void bump(ref int x) { }

void main() {
    int n = 1;
    bump(ref n);
}
```

## Fix

Declare the variable `mut`, or pass a mutable place.

Spec: [Parameter modes](../spec/12-functions.md#functions.parameters.modes)
