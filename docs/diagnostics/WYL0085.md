# WYL0085

```
error[WYL0085]: 'var' declaration must have an initializer
```

`var` takes its type from the initializer, so without one it has no type.

## Example

```wyl
void main() {
    var v;
}
```

## Fix

Add an initializer, or write the type.

Spec: [Inferred types](../spec/06-variables.md#variables.locals.var)
