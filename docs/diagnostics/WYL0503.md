# WYL0503

```
error[WYL0503]: '@CallerLocation' cannot be used on a function without a body
```

Outside the standard library, a function without a body in an extern block is C++ code, and C++
code receives no caller location.

## Example

```wyl
@Include("checks.h")
extern {
    @CallerLocation
    void check(int index);
}

void main() { }
```

## Fix

Remove the annotation. To report the location of the caller, wrap the call in a Wylow function that
is marked `@CallerLocation`.

Spec: [The standard library's extern declarations](../spec/21-interop.md#interop.extern.std)
