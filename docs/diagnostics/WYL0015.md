# WYL0015

```
error[WYL0015]: '\u' is not followed by 1 to 6 hex digits in braces
```

A `\u` escape writes a code point as 1 to 6 hexadecimal digits in braces.

## Example

```wyl
void main() {
    char c = '\u41';
}
```

## Fix

Put the digits in braces: `'\u{41}'`.
