# WYL0261

```
error[WYL0261]: parameters of lambda for 'fn(int) -> int': expected 1, found 2
```

A lambda has the number of parameters of its function type.

## Example

```wyl
void main() {
    fn(int) -> int f = (x, y) -> x;
}
```

## Fix

Give the lambda the number of parameters of the function type.

Spec: [Typing lambdas](../spec/12-functions.md#functions.lambdas.typing)
