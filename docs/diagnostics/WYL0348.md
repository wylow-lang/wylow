# WYL0348

```
error[WYL0348]: cannot assign to a field of a temporary value
```

A field of a temporary value is gone after the statement, so an assignment to it would be lost.

## Example

```wyl
struct Point {
    int x;
}

Point make() {
    return Point(x: 1);
}

void main() {
    make().x = 4;
}
```

## Fix

Store the value in a `mut` variable, then assign to its field.

Spec: [Assignment](../spec/14-statements.md#statements.assignment)
