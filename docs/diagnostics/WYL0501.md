# WYL0501

```
error[WYL0501]: struct in an extern block cannot be 'unique'
```

A struct or union in an extern block is a C++ type, and C++ code copies it by its bytes. Such a type
cannot be `unique` or `ref`.

## Example

```wyl
@Include("token.h")
extern {
    unique struct Token {
        pub int id;
    }
}

void main() { }
```

## Fix

Remove the modifier. To give the C++ type an owner, wrap it in a unique struct of the program, and
release the C++ resource in that struct's destructor.

Spec: [Extern blocks](../spec/21-interop.md#interop.extern)
