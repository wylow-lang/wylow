# WYL0416

```
error[WYL0416]: 'Span<int>' cannot view inside nullable 'buffer'
```

A `ref struct` cannot view inside the value of a nullable local that can be assigned again:
assigning the local null would destroy what it views.

## Example

```wyl
struct Buffer implements Spannable<int> {
    int[2] data;

    pub ReadOnlySpan<int> asReadOnlySpan() {
        return data;
    }

    pub mut Span<int> asSpan() {
        return data;
    }
}

void main() {
    mut Buffer? buffer = Buffer();
    if (buffer != null) {
        Span<int> view = buffer.asSpan();
    }
}
```

## Fix

Copy the value to a variable first.

Spec: [Second-class values](../spec/17-memory.md#memory.second-class)
