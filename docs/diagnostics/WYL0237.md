# WYL0237

```
error[WYL0237]: call to 'pair' is ambiguous
```

Exactly one overload remains after the arguments are checked.

## Example

```wyl
void pair(int a, long b) { }

void pair(long a, int b) { }

void main() {
    short narrow = 1;
    pair(narrow, narrow);
}
```

## Fix

Cast an argument to select one overload, or give the overloads distinct parameter types.

Spec: [Overload resolution](../spec/12-functions.md#functions.overloading.resolution)
