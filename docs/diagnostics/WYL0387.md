# WYL0387

```
error[WYL0387]: case with 'null' cannot have a guard
```

A `case null` matches the null value itself. A guard is not allowed on it.

## Example

```wyl
void main() {
    int? x = null;
    bool flag = true;
    switch (x) {
        case null when flag -> { }
        default -> { }
    }
}
```

## Fix

Remove the guard and test the condition inside the case.
