# WYL0055

```
error[WYL0055]: 'count' cannot be re-exported to reach farther than it is visible
```

A re-export makes a name visible as far as the import's visibility, which is no farther than the name it re-exports.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

```wyl src/main.wyl
pub import orders::count;

void main() { }
```

```wyl src/orders/count.wyl
package int count() { return 0; }
```

## Fix

Give the re-export a visibility no wider than the name's (`package import`), or widen the name's own.

Spec: [Visibility](../spec/03-programs.md#programs.visibility)
