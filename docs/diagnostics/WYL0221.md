# WYL0221

```
error[WYL0221]: argument 1 of 'f' cannot be passed with 'ref'
```

An argument is written with `ref` only when its parameter is `ref` or `ref?`.

## Example

```wyl
void f(int x) { }

void main() {
    int n = 1;
    f(ref n);
}
```

## Fix

Remove `ref` from the argument, or declare the parameter `ref`.

Spec: [Parameter modes](../spec/12-functions.md#functions.parameters.modes)
