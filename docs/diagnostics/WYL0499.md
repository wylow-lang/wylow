# WYL0499

```
error[WYL0499]: extern block has no '@Include'
```

An extern block names the C++ header that declares its members with `@Include`.

## Example

```wyl
extern {
    int version();
}

void main() { }
```

## Fix

Write `@Include("header.h")` before `extern`, with the path of the header.

Spec: [Extern blocks](../spec/21-interop.md#interop.extern)
