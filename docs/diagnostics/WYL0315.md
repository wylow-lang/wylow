# WYL0315

```
error[WYL0315]: '??' cannot be applied to a nullable non-escaping function
```

A non-escaping function value cannot be copied out by `??`.

## Example

```wyl
void uses(bool flag, (fn(int) -> int)? f, fn(int) -> int g) {
    var fallback = f ?? g;
}

void main() { }
```

## Fix

Check it for null with `if`.

Spec: [Null operators](../spec/13-expressions.md#expressions.null)
