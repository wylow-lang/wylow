# WYL0123

```
error[WYL0123]: cannot override final method 'Square.area'
```

A method declared `final` is the last override of its signature.

## Example

```wyl
class Shape {
    pub virtual int area() { return 0; }
}

class Square extends Shape {
    pub final override int area() { return 1; }
}

class Cube extends Square {
    pub override int area() { return 2; }
}

void main() { }
```

## Fix

Remove `final` from the overridden method, or do not override it.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
