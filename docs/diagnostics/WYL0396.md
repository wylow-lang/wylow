# WYL0396

```
error[WYL0396]: 'case null' can never match
```

Narrowing shows that the local is not null where the `case null` tests it, so the case can never
match.

## Example

```wyl
void main() {
    int? value = 1;
    switch (value) {
        case null -> { }
        default -> { }
    }
}
```

## Fix

Remove the `case null`, or remove the narrowing that shows the local is not null.

Spec: [Narrowing](../spec/16-flow.md#flow.narrowing)
