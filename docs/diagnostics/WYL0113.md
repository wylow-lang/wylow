# WYL0113

```
error[WYL0113]: class cannot extend interface 'Named'
```

A class extends a class. It lists interfaces after `implements`.

## Example

```wyl
interface Named {
    String name();
}

class Shape extends Named { }

void main() { }
```

## Fix

Write `implements` instead of `extends`.

Spec: [Inheritance](../spec/08-classes.md#classes.inheritance)
