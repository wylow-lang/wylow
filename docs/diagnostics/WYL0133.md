# WYL0133

```
error[WYL0133]: 'Square' does not implement abstract method 'Shape.area()'
```

A class that is not abstract implements every abstract method it inherits.

## Example

```wyl
abstract class Shape {
    pub abstract int area();
}

class Square extends Shape { }

void main() { }
```

## Fix

Add an `override` of the method, or declare the class `abstract`.

Spec: [Abstract and final classes](../spec/08-classes.md#classes.abstract)
