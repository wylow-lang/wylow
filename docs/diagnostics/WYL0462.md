# WYL0462

```
error[WYL0462]: cannot move a field out of a value of type 'Handle', which has a destructor
```

A pattern moves a value's fields out by taking them apart. A value whose type has a destructor
keeps one whole value for its destructor to run on, so a pattern does not move a field out of it.
A value that holds it may be taken apart, as long as its own type has no destructor.

## Example

```wyl
import std::print;

unique struct Inner {
    pub int value;
}

unique struct Handle {
    pub Inner inner;

    ~Handle() { }
}

void main() {
    var handle = Handle(Inner(value: 1));
    switch (handle) {
        case Handle(var inner) -> print(inner.value);
    }
}
```

## Fix

Bind the field by reference, using `in var`, or let the value stay whole. A destructor that needs
what the fields hold reads them directly.

Spec: [Moving bindings](../spec/15-patterns.md#patterns.bindings.moves)
