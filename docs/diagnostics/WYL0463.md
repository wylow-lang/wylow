# WYL0463

```
error[WYL0463]: generic type 'Box' cannot declare a static field
```

A static field has one value for the whole program, but a generic type has no value until its type
arguments are given, and the compiler would have to choose one set of type arguments for the static.

## Example

```wyl
struct Box<T> {
    static int count;
}

void main() { }
```

## Fix

Declare the static in a type that has no type parameters. A generic type may still declare a
static method.

Spec: [Statics](../spec/06-variables.md#variables.statics)
