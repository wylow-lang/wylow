# WYL0100

```
error[WYL0100]: 'Order' needs a value for field 'customer'
```

The memberwise constructor takes a value for every field that has no initializer and whose type has no default value.

## Example

```wyl
class Customer { }

struct Order {
    pub int id;
    pub Customer customer;
}

void main() {
    var o = Order(id: 3);
}
```

## Fix

Pass a value for the field, or give the field an initializer if its type has a default value.

Spec: [The memberwise constructor](../spec/07-structs.md#structs.constructors.memberwise)
