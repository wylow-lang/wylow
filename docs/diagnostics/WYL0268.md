# WYL0268

```
error[WYL0268]: cannot reassign non-escaping variable 'inc'
```

A non-escaping function variable or parameter keeps the function it was given and cannot be assigned after its declaration.

## Example

```wyl
void main() {
    fn(int) -> int inc = x -> x;
    inc = x -> x;
}
```

## Fix

Declare a new variable, or declare the variable or parameter `escaping`.

Spec: [Escaping and non-escaping](../spec/12-functions.md#functions.lambdas.escaping)
