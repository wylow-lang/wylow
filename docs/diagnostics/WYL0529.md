# WYL0529

```
error[WYL0529]: library 'parser' has a 'main' function in its root module
```

A library has no entry point, so the root module of a library must not declare a function named `main`. A function named `main` in another module of the library is an ordinary function.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "parser";
kind = "library";
version = "1.0.0";
```

```wyl src/main.wyl
void main() { }
```

## Fix

Rename the function, or move it to a module below the root module. A program that demonstrates the library is a separate package that depends on the library. If the package is meant to be a program, remove its `kind` entry.

Spec: [The entry point](../spec/03-programs.md#programs.entry)
