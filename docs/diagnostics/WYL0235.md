# WYL0235

```
error[WYL0235]: no overload of 'named' takes these named arguments
```

Named arguments are matched only when one overload takes those names.

## Example

```wyl
void named(int a) { }

void named(String b) { }

void main() {
    named(c: 1);
}
```

## Fix

Use names that one overload declares.

Spec: [Overload resolution](../spec/12-functions.md#functions.overloading.resolution)
