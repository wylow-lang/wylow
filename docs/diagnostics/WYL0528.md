# WYL0528

```
error[WYL0528]: version '1.4' does not have the form 'major.minor.patch'
```

A package's `version` entry has three numbers separated by dots, such as `"1.4.2"`. The `version` entry of a dependency may leave out the patch number, as in `"1.4"`. Each number is written in decimal digits, and a number other than 0 does not start with the digit 0. A version has no other text, such as a space or a `-beta` suffix.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
version = "1.4";
```

```wyl src/main.wyl
void main() { }
```

## Fix

Write the version with all of its numbers, such as `version = "1.4.0";`.
