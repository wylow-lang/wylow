# WYL0530

```
error[WYL0530]: cannot build or run library 'parser'
```

A library has no entry point, so `wyl build`, `wyl run`, `wyl interpret`, `wyl emit`, and `wyl ir` cannot take a library. The compiler reports the error only after the library has passed every other check, and reports it at the `kind` entry of the library's manifest. `wyl check` checks a library on its own and reports no such error.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "parser";
kind = "library";
version = "1.0.0";
```

```wyl src/parser.wyl
pub int depth() { return 0; }
```

## Fix

Check the library with `wyl check`. To run the library's code, build a program that depends on the library.
