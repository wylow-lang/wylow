# WYL0222

```
error[WYL0222]: 'ref' argument must be a variable, field, or element
```

A `ref` argument is a mutable place: a variable, a field, or an element.

## Example

```wyl
void bump(ref int x) { }

void main() {
    bump(ref 2);
}
```

## Fix

Pass a variable, a field, or an element.

Spec: [Parameter modes](../spec/12-functions.md#functions.parameters.modes)
