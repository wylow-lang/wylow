# WYL0172

```
error[WYL0172]: variant's value must be an integer literal
```

The value of a variant is an integer literal.

## Example

```wyl
enum Color {
    Red = 1 + 1,
    Green
}

void main() { }
```

## Fix

Write the number.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
