# WYL0391

```
error[WYL0391]: case can never be reached
```

Each case must match at least one value that the cases above it do not.

## Example

```wyl
enum Color { Red, Green }
void main() {
    Color c = Color.Red;
    switch (c) {
        case Red -> { }
        case Red -> { }
        default -> { }
    }
}
```

## Fix

Remove the case, or move it above the case that already matches its values.
