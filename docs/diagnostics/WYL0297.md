# WYL0297

```
error[WYL0297]: cannot find field 'z' in 'Point'
```

A field access names a field the type declares.

## Example

```wyl
struct Point { int x; }

void main() {
    var p = Point(1);
    var z = p.z;
}
```

## Fix

Use a declared field, or add the field to the type.

Spec: [Member access](../spec/13-expressions.md#expressions.members)
