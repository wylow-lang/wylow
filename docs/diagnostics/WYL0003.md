# WYL0003

```
error[WYL0003]: block comment is not closed
```

A block comment starts with `/*` and ends at the first `*/` after it. This one reaches the end of the file.

## Example

```wyl
void main() { }
/* notes about main
```

## Fix

End the comment with `*/`, or use `//` comments.

Spec: [Comments](../spec/02-lexical.md#lexical.comments)
