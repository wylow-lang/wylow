# WYL0309

```
error[WYL0309]: shift count 32 is out of range for 'int'
```

A shift count must be from 0 to one less than the bit width of the left operand's type.

## Example

```wyl
void main() {
    int n = 1;
    var x = n << 32;
}
```

## Fix

Use a count from 0 to 31, or widen the value first.

Spec: [Shifts](../spec/13-expressions.md#expressions.shifts)
