# WYL0313

```
error[WYL0313]: '??' cannot be applied to 'ref? int'
```

`??` needs a value it can copy. A reference that might refer to nothing cannot be copied.

## Example

```wyl
struct Box {
    int[2] items;

    mut ref? int at(int i) {
        return ref items[i];
    }
}

void main() {
    mut Box b = Box();
    var x = b.at(0) ?? 1;
}
```

## Fix

Check the reference for null with `if`.

Spec: [Null operators](../spec/13-expressions.md#expressions.null)
