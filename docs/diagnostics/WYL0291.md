# WYL0291

```
error[WYL0291]: 'int' cannot be created with 'new'
```

`new` creates a class instance. A built-in type has no constructor.

## Example

```wyl
void main() {
    var n = new int();
}
```

## Fix

Write a literal or a conversion of that type.

Spec: [Construction](../spec/13-expressions.md#expressions.construction)
