# WYL0204

```
error[WYL0204]: cannot infer type argument 'T' of 'same'
```

The arguments give two types for the type argument, and neither one is a type the other converts to.

## Example

```wyl
void same<T>(T a, T b) { }

void main() {
    same(1, "a");
}
```

## Fix

Convert an argument, or write the type argument.

Spec: [Inferring type arguments](../spec/11-generics.md#generics.arguments.inference)
