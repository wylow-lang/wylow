# WYL0399

```
error[WYL0399]: field 'next' might not have been assigned
```

A constructor reads a field that might not have been assigned yet.

## Example

```wyl
import std::print;

class Node { }

class Link {
    Node next;

    Link() {
        print(next == null);
        next = new Node();
    }
}

void main() { }
```

## Fix

Assign the field before it is read.

Spec: [Fields in constructors](../spec/16-flow.md#flow.constructors)
