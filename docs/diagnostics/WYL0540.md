# WYL0540

```
error[WYL0540]: argument 1 of 'Code.tryFrom': expected an integer type, found 'String'
```

`E.tryFrom(x)` converts the integer `x` to the variant of the enum `E` that has the value of `x`, or
to null if no variant has it. The argument may have any integer type, and it must have one: a
string, a floating-point number, a `char`, or a nullable integer is not an integer.

## Example

```wyl
enum Code {
    Ok,
    Busy,
}

void main() {
    Code? code = Code.tryFrom("1");
}
```

## Fix

Convert the value to an integer first. If the integer is nullable, check it for null first.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
