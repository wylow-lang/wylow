# WYL0009

```
error[WYL0009]: literal is too large for 'float'
```

A floating-point literal's value, rounded to its type, is finite. A literal without a `d` suffix is a `float`, whose largest value is about 3.4e38.

## Example

```wyl
void main() {
    float big = 1e39;
}
```

## Fix

Add a `d` suffix to make it a `double` (`1e39d`), or write a smaller value.

Spec: [Floating-point literals](../spec/02-lexical.md#lexical.literals.float)
