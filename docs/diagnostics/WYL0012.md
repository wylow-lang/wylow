# WYL0012

```
error[WYL0012]: character literal holds more than one character
```

A character literal holds exactly one character or escape; a `char` is one code point.

## Example

```wyl
void main() {
    char c = 'ab';
}
```

## Fix

Use a string literal for more than one character: `"ab"`.

Spec: [Character literals](../spec/02-lexical.md#lexical.literals.char)
