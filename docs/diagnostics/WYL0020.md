# WYL0020

```
error[WYL0020]: 'src/' contains no '.wyl' files
```

A package has at least one source file in `src/` or a directory below it. Files with other names, and directories whose names start with `.`, are not part of it.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

```text src/notes.txt
Not a source file.
```

## Fix

Add the package's source files, such as `src/main.wyl`.

Spec: [Packages](../spec/03-programs.md#programs.packages)
