# WYL0017

```
error[WYL0017]: '}' in an interpolated string is not doubled
```

In the text of an interpolated string, `{` opens a hole and `}` ends one, so a brace that is text is doubled: `{{` and `}}`.

## Example

```wyl
void main() {
    std::print($"a } b");
}
```

## Fix

Write `}}` for the brace, or remove the `$` if nothing is interpolated.

Spec: [Interpolated strings](../spec/02-lexical.md#lexical.literals.interpolated)
