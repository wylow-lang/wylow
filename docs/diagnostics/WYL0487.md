# WYL0487

```
error[WYL0487]: cannot call 'shift' on a temporary value
```

An extension method that declares its receiver as `this ref` may change the receiver, so the
receiver must be a variable. A temporary is a value that is gone after its statement, so a change
to it would be lost.

## Example

```wyl
struct Point {
    pub int x;
}

void shift(this ref Point p) {
    p.x += 1;
}

Point make() {
    return Point(1);
}

void main() {
    make().shift();
}
```

## Fix

Store the value in a `mut` variable first, and call the extension method on the variable.
