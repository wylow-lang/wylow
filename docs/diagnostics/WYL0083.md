# WYL0083

```
error[WYL0083]: cannot cast 'float' to 'bool'
```

A cast exists only between the pairs of types the spec lists.

## Example

```wyl
void main() {
    bool b = (bool)1.5;
}
```

## Fix

Compare instead, as in `x != 0.0`, or cast to a type the pair allows.

Spec: [Casts](../spec/05-conversions.md#conversions.casts)
