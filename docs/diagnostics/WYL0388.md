# WYL0388

```
error[WYL0388]: pattern 'null' can never match a value of non-nullable type 'int'
```

The `null` pattern matches only the null value. A value of a non-nullable type is never null.

## Example

```wyl
void main() {
    int n = 1;
    switch (n) {
        case null -> { }
        default -> { }
    }
}
```

## Fix

Remove the `null` pattern, or make the value's type nullable.

Spec: [`case null`](../spec/15-patterns.md#patterns.cases.null)
