# WYL0524

```
error[WYL0524]: a lambda cannot be converted to 'extern fn(void*, int) -> int'
```

An `extern fn` type is a C function pointer, which is the address of a function and holds no
captured values. A lambda does not convert to it, even one that captures nothing. Only a reference
to a function marked `@CCallback` converts.

## Example

```wyl
void main() {
    extern fn(void*, int) -> int handler = (context, value) -> value + 1;
}
```

## Fix

Declare a top-level or static function marked `@CCallback`, and use its name:

```wyl
@CCallback
int next(void* context, int value) { return value + 1; }

void main() {
    extern fn(void*, int) -> int handler = next;
}
```
