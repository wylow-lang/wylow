# WYL0285

```
error[WYL0285]: 'super' can only be used to call a base class constructor or method
```

`super` reaches the base class only through a `super(...)` call or a method call.

## Example

```wyl
class Base { }

class Derived extends Base {
    void f() {
        var s = super;
    }
}

void main() { }
```

## Fix

Call a base method, or name the base class constructor in `super(...)`.

Spec: [Names, literals, and `this`](../spec/13-expressions.md#expressions.primary)
