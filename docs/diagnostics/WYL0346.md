# WYL0346

```
error[WYL0346]: cannot assign to an element of a temporary value
```

A temporary value is gone after the statement, so an assignment to its element would be lost.

## Example

```wyl
struct Cells {
    int[2] items;

    int operator [](int i) {
        return items[i];
    }

    mut void operator []=(int i, int value) {
        items[i] = value;
    }
}

Cells cells() {
    return Cells();
}

void main() {
    cells()[0] = 1;
}
```

## Fix

Store the value in a `mut` variable, then assign to its element.

Spec: [Assignment](../spec/14-statements.md#statements.assignment)
