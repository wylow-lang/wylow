# WYL0103

```
error[WYL0103]: 'mut' cannot be used on a class method
```

A class method does not change the reference it is called through, so it is not `mut`. Which fields of an object can change is decided by the fields.

## Example

```wyl
class Counter {
    mut int n;

    pub mut void bump() { n++; }
}

void main() { }
```

## Fix

Remove `mut` from the method, and declare the fields it changes `mut`.

Spec: [`mut` methods](../spec/07-structs.md#structs.methods.mut)
