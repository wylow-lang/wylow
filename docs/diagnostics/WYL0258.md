# WYL0258

```
error[WYL0258]: lambda parameters must all have types or all leave them out
```

A lambda's parameters either all have types or all leave them out.

## Example

```wyl
void main() {
    fn(int) -> int f = (int a, b) -> a;
}
```

## Fix

Give every parameter a type, or remove the types.

Spec: [Lambdas](../spec/12-functions.md#functions.lambdas)
