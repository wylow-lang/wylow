# WYL0065

```
error[WYL0065]: 'n.next' might be null
```

A member of a nullable value is reached only through `?.`, through `!`, or after a check that narrows the value to non-null.

## Example

```wyl
class Node {
    int value;
    Node? next;
}

void main() {
    var n = new Node();
    std::print(n.next.value);
}
```

## Fix

Write `n.next?.value`, or `n.next!.value` to panic on null, or check `n.next` for null first.

Spec: [Nullable types](../spec/04-types.md#types.nullable)
