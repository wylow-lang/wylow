# WYL0144

```
error[WYL0144]: 'virtual' cannot be used on a destructor
```

The runtime calls a destructor, so its name and the class name are all it has: no modifier applies.

## Example

```wyl
class Box {
    virtual ~Box() { }
}

void main() { }
```

## Fix

Remove the modifier.

Spec: [Destructors](../spec/08-classes.md#classes.destructors)
