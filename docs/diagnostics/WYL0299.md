# WYL0299

```
error[WYL0299]: cannot call 'm' of non-function type 'int'
```

A call applies the parentheses to a function, a function value, or a callable type. An `int` is none of these.

## Example

```wyl
void main() {
    int m = 5;
    m(1);
}
```

## Fix

Call a function value, or remove the call.

Spec: [Calls](../spec/13-expressions.md#expressions.calls)
