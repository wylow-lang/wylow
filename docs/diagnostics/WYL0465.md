# WYL0465

```
error[WYL0465]: cannot assign to static 'Settings.LIMIT'
```

Every static is read-only. A value that has to change for the whole program is held by an object
that the static refers to, such as a mutex or an atomic, and changes through that object's
operations.

## Example

```wyl
class Settings {
    static int LIMIT = 5;
}

void main() {
    Settings.LIMIT = 6;
}
```

## Fix

Remove the assignment, or move the value that changes into a local of `main` or into a
synchronization object that the static refers to.

Spec: [Statics](../spec/06-variables.md#variables.statics)
