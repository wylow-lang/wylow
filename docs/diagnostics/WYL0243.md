# WYL0243

```
error[WYL0243]: only instance methods can return 'Span<int>'
```

Only an instance method returns a `ref struct` such as `Span<T>`, since the result views the receiver.

## Example

```wyl
Span<int> make() {
    return Span<int>();
}

void main() { }
```

## Fix

Declare the function as an instance method of the receiver's type.

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
