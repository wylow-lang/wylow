# WYL0371

```
error[WYL0371]: 'break' can only be used inside a loop
```

`break` and `continue` leave or advance an enclosing loop.

## Example

```wyl
void main() {
    break;
}
```

## Fix

Move the statement into a loop, or remove it.

Spec: [`break` and `continue`](../spec/14-statements.md#statements.jumps)
