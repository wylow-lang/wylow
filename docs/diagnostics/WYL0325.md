# WYL0325

```
error[WYL0325]: cases of the switch expression have incompatible types 'int', 'String'
```

A switch expression produces one type, so every case must have a common type.

## Example

```wyl
void main() {
    int n = 1;
    var x = switch (n) {
        case 1 -> 1;
        default -> "other";
    };
}
```

## Fix

Convert the cases to one type.

Spec: [Switch expressions](../spec/13-expressions.md#expressions.switch)
