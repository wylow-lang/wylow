# WYL0080

```
error[WYL0080]: integer literal is too large for 'int'
```

An integer literal must fit the type it is given. Without a suffix it is an `int`.

## Example

```wyl
void main() {
    int big = 3000000000;
}
```

## Fix

Add a suffix for a larger type, such as `L` for a `long`, or use a smaller value.

Spec: [Integer constants](../spec/05-conversions.md#conversions.constants)
