# WYL0265

```
error[WYL0265]: 'escaping' can only be used on parameters, local variables, and fields of a 'ref struct'
```

`escaping` is written only on a parameter, a local, a function type's parameter, or a field of a
`ref struct`. A function value anywhere else is escaping already.

## Example

```wyl
escaping void annotated() { }

void main() { }
```

## Fix

Remove `escaping`; every other position holds an escaping function.

Spec: [Escaping and non-escaping](../spec/12-functions.md#functions.lambdas.escaping)
