# WYL0332

```
error[WYL0332]: operand of 'try': expected a 'Result', found 'int'
```

`try` unwraps a `Result`, so its operand must have a `Result` type.

## Example

```wyl
Result<int, String> parse() {
    int a = try 5;
    return Result.Ok(a);
}

void main() { }
```

## Fix

Apply `try` to a `Result`.

Spec: [`try`](../spec/13-expressions.md#expressions.try)
