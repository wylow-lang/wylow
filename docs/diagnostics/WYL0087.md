# WYL0087

```
error[WYL0087]: cannot infer a type from 'null'
```

`null` belongs to no type, so `var` has nothing to infer from.

## Example

```wyl
void main() {
    var x = null;
}
```

## Fix

Declare the variable with a nullable type, as in `int? x = null;`.

Spec: [Inferred types](../spec/06-variables.md#variables.locals.var)
