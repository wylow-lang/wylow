# WYL0282

```
error[WYL0282]: instance field 'x' cannot be used here
```

An instance field exists only in an instance. A static method, a field initializer, and a constructor chain argument are evaluated without one.

## Example

```wyl
struct Point {
    int x;

    static int origin() {
        return x;
    }
}

void main() { }
```

## Fix

Use the field through an instance, or make the member an instance member.

Spec: [Names, literals, and `this`](../spec/13-expressions.md#expressions.primary)
