# WYL0045

```
error[WYL0045]: 'value' is ambiguous here
```

Two `*` imports bring in different meanings of a name, and the name is used. Unused, the two imports are valid.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

```wyl src/main.wyl
import alpha::*;
import beta::*;

void main() {
    int n = value();
}
```

```wyl src/alpha/a.wyl
pub int value() { return 1; }
```

```wyl src/beta/b.wyl
pub int value() { return 2; }
```

## Fix

Import the one meant by name, which comes before the `*` imports: `import alpha::value;`.

Spec: [Imports](../spec/03-programs.md#programs.imports)
