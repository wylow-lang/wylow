# WYL0095

```
error[WYL0095]: structs cannot extend a type
```

A struct has no base type. It can implement interfaces, which is written with `implements`.

## Example

```wyl
struct Base { }

struct Point extends Base { }

void main() { }
```

## Fix

Remove `extends`. To use an interface, write `implements` and its name.

Spec: [Struct declarations](../spec/07-structs.md#structs.declarations)
