# WYL0375

```
error[WYL0375]: type pattern cannot name a function type
```

A type pattern names a class, interface, enum, struct, or primitive type. A function type is not one.

## Example

```wyl
void main() {
    (fn() -> int)? f = null;
    if (f is fn() -> int g) { }
}
```

## Fix

Compare the nullable function with `null` instead.

Spec: [Kinds of patterns](../spec/15-patterns.md#patterns.kinds)
