# WYL0319

```
error[WYL0319]: branches of '?:' have incompatible types 'int' and 'String'
```

The conditional operator produces one type, so both branches must have a common type.

## Example

```wyl
void main() {
    bool flag = true;
    var x = flag ? 1 : "a";
}
```

## Fix

Convert one branch to the other's type, or use `if`.

Spec: [The conditional operator](../spec/13-expressions.md#expressions.conditional)
