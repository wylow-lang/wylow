# WYL0134

```
error[WYL0134]: 'virtual' cannot be used on a constructor
```

A constructor is not inherited, overridden, static, or `mut`.

## Example

```wyl
class Box {
    pub virtual Box() { }
}

void main() { }
```

## Fix

Remove the modifier.

Spec: [Constructors](../spec/08-classes.md#classes.constructors)
