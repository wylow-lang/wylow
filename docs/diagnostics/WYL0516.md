# WYL0516

```
error[WYL0516]: cannot take the address of 'limit'
```

Code may write through a pointer, so `&` takes the address only of a place that an assignment
could write. A variable that is not `mut`, a field that is not `mut`, an `in` parameter, and a
static are read-only, and so is everything inside them.

## Example

```wyl
void main() {
    int limit = 10;
    unsafe {
        int* p = &limit;
    }
}
```

## Fix

Declare the variable with `mut`, or copy the value into a `mut` variable and take the address of
that variable.

Spec: [Pointers](../spec/20-unsafe.md#unsafe.pointers)
