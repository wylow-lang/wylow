# WYL0543

```
error[WYL0543]: value of constant 'SUM' must be a literal of type 'int'
```

An extern constant may give its value, as in `static int LIMIT = 8;`, so that a pattern may name
it. The value must be a literal of the constant's type: an integer literal, which may be negated, a
`char` literal, `true`, or `false`. An integer literal without a suffix may give the value of any
integer type that holds it. A constant of another type, such as `double`, cannot give a value.

## Example

```wyl
@Include("codes.h")
extern {
    static int SUM = 1 + 2;
}

void main() { }
```

## Fix

Write the value as one literal, such as `static int SUM = 3;`, or leave the value out.

Spec: [Extern constants](../spec/21-interop.md#interop.extern.constants)
