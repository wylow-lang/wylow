# WYL0242

```
error[WYL0242]: returned 'Span<int>' must view the method's receiver
```

A returned span or other `ref struct` views the method's receiver.

## Example

```wyl
struct Samples {
    int[2] values;

    mut Span<int> other(Span<int> given) {
        return given;
    }
}

void main() { }
```

## Fix

Return a view of a field or element of `this`.

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
