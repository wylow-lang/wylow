# WYL0248

```
error[WYL0248]: indexer is not declared with 'operator []'
```

An indexer is declared as `operator []`.

## Example

```wyl
class C {
    int this[int i] {
        return i;
    }
}

void main() { }
```

## Fix

Rewrite the declaration as `operator []`.
