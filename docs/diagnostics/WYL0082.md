# WYL0082

```
error[WYL0082]: expected 'int', found a choice of lambdas
```

A conditional expression whose branches are lambdas converts only to a function type.

## Example

```wyl
void run(int n) { }

void main() {
    run(true ? y -> y : y -> 1);
}
```

## Fix

Pass a value of the expected type, or change the parameter to a function type.

Spec: [Function conversions](../spec/05-conversions.md#conversions.functions)
