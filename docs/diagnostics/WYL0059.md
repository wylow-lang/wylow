# WYL0059

```
error[WYL0059]: 'main' cannot take these parameters
error[WYL0059]: 'main' cannot have type parameters
```

The entry point takes no parameters, or one by-value `String[]`, which holds the program's
arguments: `void main()`, `int main()`, `void main(String[] args)`, or `int main(String[] args)`.
It has no type parameters.

## Example

```wyl
void main(int count) { }
```

## Fix

Take the arguments as `String[] args` and read the count as `args.length`, or remove the parameters.

Spec: [The entry point](../spec/03-programs.md#programs.entry)
