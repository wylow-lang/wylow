# WYL0040

```
error[WYL0040]: 'List' is already imported
```

Two imports of a file bring in the same name by name, so the name would mean two things in the file.

## Example

```wyl
import std::collections::List;
import std::collections::List;

void main() { }
```

## Fix

Remove one, or import one of them under another name with `as`.

Spec: [Imports](../spec/03-programs.md#programs.imports)
