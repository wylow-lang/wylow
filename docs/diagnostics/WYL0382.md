# WYL0382

```
error[WYL0382]: case with several patterns cannot bind names
```

A case that lists several patterns cannot bind names, because a match does not say which pattern it was.

## Example

```wyl
enum Shape { Point, Circle(int r) }
void main() {
    Shape s = Shape.Point;
    switch (s) {
        case Circle(var r), Point -> { }
        default -> { }
    }
}
```

## Fix

Bind no names in a case with several patterns, or split it into one case for each pattern.

Spec: [Bindings](../spec/15-patterns.md#patterns.bindings)
