# WYL0461

```
error[WYL0461]: cannot move out of 'this' in a destructor
```

A destructor runs on the value it is destroying. If the destructor moved the value, or a field of
it, out, then `this` would no longer hold what the destructor is about to release.

## Example

```wyl
unique struct Handle {
    pub int id;

    ~Handle() {
        var kept = this;
    }
}

void main() { }
```

## Fix

Read the fields the destructor needs, or assign to them. Do not move the value or its fields out.

Spec: [Destructors and `discard`](../spec/07-structs.md#structs.unique.destructors)
