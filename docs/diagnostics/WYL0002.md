# WYL0002

```
error[WYL0002]: character '#' does not start a token
```

A character outside a comment, a character literal, or a string literal starts no token: `#`, a `$` not followed by `"`, or a letter outside `A` to `Z` and `a` to `z`.

## Example

```wyl
void main() {
    int count# = 1;
}
```

## Fix

Remove the character, or put it in a string literal or a comment. Identifiers are written with ASCII letters, digits, and `_`.

Spec: [Tokens and whitespace](../spec/02-lexical.md#lexical.tokens)
