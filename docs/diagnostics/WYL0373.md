# WYL0373

```
error[WYL0373]: cannot return a value from a constructor
```

A constructor and a destructor produce no value, so `return` in either cannot carry one.

## Example

```wyl
struct Point {
    int x;

    Point(int x) {
        this.x = x;
        return 5;
    }
}

void main() { }
```

## Fix

Remove the value from `return`.

Spec: [`return`](../spec/14-statements.md#statements.return)
