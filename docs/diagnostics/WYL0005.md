# WYL0005

```
error[WYL0005]: '_' in a number literal must be between digits
```

A `_` in a number literal separates digits, so it needs a digit on each side: not at either end, and not next to a `.`, an exponent's `e`, or the `x` or `b` of a prefix.

## Example

```wyl
void main() {
    int big = 1_000_;
}
```

## Fix

Remove the `_`, or move it between two digits: `1_000`.

Spec: [Literals](../spec/02-lexical.md#lexical.literals)
