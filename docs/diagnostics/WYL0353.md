# WYL0353

```
error[WYL0353]: cannot loop over 'int'
```

A for-each loop iterates a sequence: an array, a string, a list, a span, or a range.

## Example

```wyl
void main() {
    int n = 3;
    for (int x : n) { }
}
```

## Fix

Loop over a sequence, or use a `for` loop with a counter.

Spec: [For-each](../spec/14-statements.md#statements.for-each)
