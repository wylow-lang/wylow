# WYL0030

```
error[WYL0030]: dependency 'parser' has no 'path'
```

An entry of `dependencies` names its library's directory with `path`. The compiler reads no library from anywhere else, so an entry without `path` names no library.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    parser { version = "1.4"; }
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Add the directory that holds the library, relative to the manifest's own directory: `parser { path = "vendor/parser"; version = "1.4"; }`.

Spec: [Dependencies](../spec/03-programs.md#programs.manifest.dependencies)
