# WYL0294

```
error[WYL0294]: cannot find member 'size' in 'int[4]'
```

The only member of a fixed array is `length`, which holds its number of elements.

## Example

```wyl
void main() {
    int[4] a = [1, 2, 3, 4];
    var s = a.size;
}
```

## Fix

Write `length`, or index the array.

Spec: [Member access](../spec/13-expressions.md#expressions.members)
