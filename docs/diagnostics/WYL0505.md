# WYL0505

```
error[WYL0505]: '@Include' takes one string literal
```

`@Include`, `@CppNamespace`, and `@CppName` each take one string literal: the path of a header, a
C++ namespace, or a C++ name.

## Example

```wyl
@Include
extern {
    int version();
}

void main() { }
```

## Fix

Write the annotation with one string literal, as in `@Include("version.h")`.

Spec: [The annotations](../spec/22-annotations.md#annotations.list)
