# WYL0023

```
error[WYL0023]: 'version' is not a key here
```

The manifest's keys are fixed, so a misspelled or unknown one is an error rather than being ignored. At the top level they are `name`, `dependencies`, and `native`.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
version = "1.0";
```

```wyl src/main.wyl
void main() { }
```

## Fix

Remove the entry, or correct its key.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
