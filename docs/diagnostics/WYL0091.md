# WYL0091

```
error[WYL0091]: 'ref' variable must be initialized with the variable, field, or element it refers to
```

A `ref` variable is bound to a place when it is declared.

## Example

```wyl
void main() {
    ref int r;
}
```

## Fix

Add the initializer, as in `ref int r = n;`.

Spec: [`ref` and `in` variables](../spec/06-variables.md#variables.references)
