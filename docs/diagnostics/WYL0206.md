# WYL0206

```
error[WYL0206]: cannot infer type argument 'U' of 'each' from a lambda
```

More than one overload takes the arguments, and the type of the lambda's result depends on which one is chosen.

## Example

```wyl
void each<U>(fn(int) -> U f) { }

void each<U>(fn(bool) -> U f) { }

void main() {
    each(x -> 1);
}
```

## Fix

Write the type argument, or the type of the lambda's parameter.

Spec: [Inferring type arguments](../spec/11-generics.md#generics.arguments.inference)
