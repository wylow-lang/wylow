# WYL0279

```
error[WYL0279]: 'Point' is a type, not a value
```

A type names no value. An expression that is expected to produce a value cannot be a type name.

## Example

```wyl
struct Point { }

void main() {
    var p = Point;
}
```

## Fix

Write a value of that type, such as a construction or a variable.

Spec: [Names, literals, and `this`](../spec/13-expressions.md#expressions.primary)
