# WYL0374

```
error[WYL0374]: cannot return a value from 'void' function 'returnsValue'
```

A `void` function returns nothing, so `return` in it cannot carry a value.

## Example

```wyl
void returnsValue() {
    return 1;
}

void main() { }
```

## Fix

Return nothing, or give the function the value's type as its return type.

Spec: [`return`](../spec/14-statements.md#statements.return)
