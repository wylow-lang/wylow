# WYL0283

```
error[WYL0283]: 'this' can only be used inside a struct or class
```

`this` names the receiver of an instance member. Code outside a struct or class has no receiver.

## Example

```wyl
void main() {
    var t = this;
}
```

## Fix

Move the expression into an instance method or constructor, or remove `this`.

Spec: [Names, literals, and `this`](../spec/13-expressions.md#expressions.primary)
