# WYL0492

```
error[WYL0492]: cannot implement unsafe interface 'Checked' without 'unsafe'
```

An unsafe interface asks each type that implements it for a promise that the compiler cannot
check, which the interface's documentation states. If a type breaks the promise, the behavior is
undefined. A type therefore writes `unsafe` before the interface's name in its `implements` list,
so that the promise is visible where the type makes it, as an `unsafe` block is.

## Example

```wyl
unsafe interface Checked {
    void check();
}

class Missing implements Checked {
    void check() { }
}

void main() { }
```

## Fix

Read the interface's documentation, and check that the type keeps its promise. Then write
`implements unsafe Checked`.
