# WYL0398

```
error[WYL0398]: field 'next' must be assigned before the constructor returns
```

A field that needs a value is not assigned on every path before this constructor returns.

## Example

```wyl
class Node { }

class Link {
    Node next;

    Link(bool found) {
        if (found) {
            next = new Node();
        }
    }
}

void main() { }
```

## Fix

Assign the field on every path before the constructor returns.

Spec: [Fields in constructors](../spec/16-flow.md#flow.constructors)
