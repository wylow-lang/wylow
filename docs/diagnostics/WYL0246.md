# WYL0246

```
error[WYL0246]: 'void' cannot be returned by 'ref'
```

`ref` and `in` return a place of a type other than `void`.

## Example

```wyl
struct Cell {
    int value;

    mut ref void none() { }
}

void main() { }
```

## Fix

Return a type other than `void`, or remove `ref`.

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
