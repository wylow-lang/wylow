# WYL0154

```
error[WYL0154]: enum variants cannot have a visibility
```

A variant is as visible as its enum, so it has no visibility of its own.

## Example

```wyl
enum Color {
    pub Red,
    Green
}

void main() { }
```

## Fix

Remove the visibility.

Spec: [Variants](../spec/09-enums.md#enums.variants)
