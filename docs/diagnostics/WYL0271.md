# WYL0271

```
error[WYL0271]: non-escaping variable 'g' cannot be stored or returned
```

A non-escaping parameter or local cannot be stored in a field or container, passed to an escaping parameter, or returned.

## Example

```wyl
void keep(escaping fn() -> void f) { }

void main() {
    fn() -> void g = () -> { };
    keep(g);
}
```

## Fix

Declare the parameter or local `escaping`.

Spec: [Escaping and non-escaping](../spec/12-functions.md#functions.lambdas.escaping)
