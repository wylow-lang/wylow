# WYL0546

```
error[WYL0546]: '@Include' path '<codec.h' does not name a system header
help: write a system header as '@Include("<header.h>")'
```

An `@Include` path that starts with `<` names a system header, which the C++ compiler finds in its
own directories. The path must end with `>`, and it must name a header between the two brackets.

## Example

```wyl
@Include("<codec.h")
extern {
    static int CODEC_LEVEL;
}

void main() { }
```

## Fix

Close the path with `>`, as in `@Include("<codec.h>")`. If the header belongs to the package, write
its path without brackets, as in `@Include("codec.h")`.

Spec: [Extern blocks](../spec/21-interop.md#interop.extern)
