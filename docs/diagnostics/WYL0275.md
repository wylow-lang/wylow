# WYL0275

```
error[WYL0275]: instance method 'key' cannot be used as a value
```

Only a function or a static method is used as a function value; an instance method needs its receiver.

## Example

```wyl
class Order {
    int key(int x) {
        return x;
    }

    void test() {
        fn(int) -> int f = key;
    }
}

void main() { }
```

## Fix

Use a lambda that calls the method, or make the method static.
