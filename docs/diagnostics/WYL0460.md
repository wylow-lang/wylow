# WYL0460

```
error[WYL0460]: cannot discard 'h' outside the file of 'Handle'
```

`discard` ends a value's lifetime without running its destructor, so a type allows it only in the
file that declares the type. That keeps control of how the type's values end in the type itself.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "handles";
```

```wyl src/handle.wyl
pub unique struct Handle {
    pub int id;

    ~Handle() { }
}
```

```wyl src/main.wyl
void close(Handle h) {
    discard h;
}

void main() { }
```

## Fix

Call a function that the type's file declares and that discards the value. Otherwise, let the
value be released at the end of the function.

Spec: [Destructors and `discard`](../spec/07-structs.md#structs.unique.destructors)
