# WYL0318

```
error[WYL0318]: '?.' cannot produce a nullable 'ReadOnlySpan<byte>'
```

A view type cannot be nullable, so `?.` cannot wrap the member's result.

## Example

```wyl
void main() {
    String? text = "abc";
    var bytes = text?.bytes();
}
```

## Fix

Check the receiver for null with `if`, then access the member.

Spec: [Null operators](../spec/13-expressions.md#expressions.null)
