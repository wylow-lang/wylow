# WYL0079

```
error[WYL0079]: expected 'int', found 'String'
```

The value does not convert implicitly to the type expected where it is used: an initializer, an assignment, an argument, a returned value, or a default value.

## Example

```wyl
void main() {
    int n = "text";
}
```

## Fix

Change the value or the type. Where the message has a `help:` line, follow it.

Spec: [Where conversions apply](../spec/05-conversions.md#conversions.contexts)
