# WYL0286

```
error[WYL0286]: fields cannot be set in braces after a construction
```

A construction takes its field values as arguments. Braces after it do not set fields.

## Example

```wyl
struct Point {
    int x;
}

void main() {
    var p = Point { x = 1 };
}
```

## Fix

Name the fields in the construction, as in `Point(x: 1)`.

Spec: [Construction](../spec/13-expressions.md#expressions.construction)
