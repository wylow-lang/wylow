# WYL0489

```
error[WYL0489]: cannot call 'shift' on 'maybe' of nullable type 'Point?'
```

An extension method that declares its receiver as `this ref Point` refers to a `Point` in place.
A nullable variable holds its value inside the nullable value, and nothing may refer into a
nullable value, even where a null check narrows the variable. The call therefore cannot pass the
nullable variable to the receiver.

## Example

```wyl
struct Point {
    pub int x;
}

void shift(this ref Point p) {
    p.x += 1;
}

void main() {
    mut Point? maybe = Point(1);
    if (maybe != null) {
        maybe.shift();
    }
}
```

## Fix

Declare the receiver as `this ref Point?`, so that the extension method refers to the nullable
variable itself. Otherwise, copy the value into a `mut` variable of type `Point`, call the
extension method on that variable, and assign the variable back.
