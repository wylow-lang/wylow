# WYL0306

```
error[WYL0306]: 'int' cannot be indexed
```

Only a fixed array and a type that declares `operator []` can be indexed.

## Example

```wyl
void main() {
    int n = 3;
    var x = n[0];
}
```

## Fix

Index a fixed array or a type with an indexer.

Spec: [Indexing](../spec/13-expressions.md#expressions.indexing)
