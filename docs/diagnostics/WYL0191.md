# WYL0191

```
error[WYL0191]: cannot construct type parameter 'T'
```

A type parameter stands for any type, and a constructor is called on a type that is known. To make a value of the type argument, take a function that makes it.

## Example

```wyl
T make<T>() {
    return T();
}

void main() { }
```

## Fix

Take the value as a parameter, or a function that returns it: `T make<T>(fn() -> T create)`.

Spec: [Type parameters](../spec/11-generics.md#generics.parameters)
