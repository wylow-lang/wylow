# WYL0479

```
error[WYL0479]: 'Atomic' type argument: expected an integer type, found 'double'
```

An `Atomic<T>` holds an integer that several threads read and change without a lock
([Atomics](../spec/19-concurrency.md#concurrency.atomic)). Its type argument must be one of the
integer types, such as `int`, `long`, or `byte`. A type parameter is refused too, because the code
that uses it could be given any type.

## Example

```wyl
import std::threading::Atomic;

void main() {
    var ratio = new Atomic<double>(0.5);
}
```

## Fix

Hold a `bool` in an `AtomicBool`:

```wyl
import std::threading::AtomicBool;

void main() {
    var done = new AtomicBool(false);
}
```

Hold any other value in a `Mutex<T>`, which guards a value of any type with a lock:

```wyl
import std::threading::Mutex;

void main() {
    var ratio = new Mutex<double>(0.5);
}
```
