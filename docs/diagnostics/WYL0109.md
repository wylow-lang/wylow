# WYL0109

```
error[WYL0109]: 'virtual' cannot be used on a field
```

A field is not inherited behavior, so the modifiers of methods (`virtual`, `override`, `abstract`, `final`), `unsafe`, and `extern` do not apply to it.

## Example

```wyl
class Box {
    pub virtual int size;
}

void main() { }
```

## Fix

Remove the modifier.

Spec: [Fields](../spec/08-classes.md#classes.fields)
