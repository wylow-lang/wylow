# WYL0136

```
error[WYL0136]: 'super(...)' can only be used in a class constructor
```

`super(...)` calls the base class constructor, so it is written in a class constructor.

## Example

```wyl
class Shape {
    pub Shape() { }
    pub Shape(int id) { }
}

class Square extends Shape {
    pub void reset() {
        super(1);
    }
}

void main() { }
```

## Fix

Remove the call.

Spec: [Constructors](../spec/08-classes.md#classes.constructors)
