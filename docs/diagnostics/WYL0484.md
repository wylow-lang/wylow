# WYL0484

```
error[WYL0484]: cannot loop over 'I', which implements both 'Iterator<int>' and 'Iterator<long>'
```

A loop over an iterator binds each element to the type argument of the type's `Iterator`,
`RefIterator`, or `InIterator`, and binds it as that interface's `current` returns it: a value, a
reference, or a read-only reference. If the type implements two of the three interfaces, or one of
them with two type arguments, the loop has no single way to bind its variable, and the compiler
cannot tell which `current` method to call. A type parameter reaches this error when its bounds
name two of them, or one of them twice.

## Example

```wyl
import std::iteration::Iterator;

void sum<I extends Iterator<int> & Iterator<long>>(I source) {
    for (var value : source) { }
}

void main() { }
```

## Fix

Give the type one iterator interface with one type argument. In the example, bound `I` by
`Iterator<long>` alone.
