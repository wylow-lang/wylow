# WYL0484

```
error[WYL0484]: cannot loop over 'I', which implements both 'Iterator<int>' and 'Iterator<long>'
```

A loop over an iterator binds each element to the type argument of the type's `Iterator`. If the
type implements `Iterator` with two type arguments, the loop has no single element type, and the
compiler cannot tell which `current` method to call. A type parameter reaches this error when its
bounds name `Iterator` twice.

## Example

```wyl
import std::Iterator;

void sum<I extends Iterator<int> & Iterator<long>>(I source) {
    for (var value : source) { }
}

void main() { }
```

## Fix

Give the type one `Iterator` type argument. In the example, bound `I` by `Iterator<long>` alone.
