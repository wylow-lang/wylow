# WYL0521

```
error[WYL0521]: '@CCallback' function 'visit' cannot be generic
```

A function marked `@CCallback` converts to a C function pointer, and C calls the pointer with
values of fixed types. A generic function has no fixed parameter types, so no single C function can
call it. The compiler also reports this error for a static method of a generic type.

## Example

```wyl
@CCallback
void visit<T>(T* value) { }

void main() { }
```

## Fix

Write one `@CCallback` function for each type that C passes:

```wyl
@CCallback
void visit(int* value) { }

void main() { }
```
