# WYL0424

```
error[WYL0424]: extern function 'run' cannot have a body
```

A function at the top level of an extern block declares a function that C++ source defines, so the
declaration has no body.

## Example

```wyl
@Include("runner.h")
extern {
    void run() { }
}

void main() { }
```

## Fix

Remove the body, and define the function in the C++ source that the block's `@Include` names. If
the function is Wylow code, declare it outside the extern block.

Spec: [Extern blocks](../spec/21-interop.md#interop.extern)
