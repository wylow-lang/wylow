# WYL0424

```
error[WYL0424]: extern function 'run' cannot have a body
```

An extern function declares a function that C++ source defines; the declaration gives no body.

## Example

```wyl
extern void run() { }

void main() { }
```

## Fix

Remove the body and define the function in the C++ source that the block's `@Include` names.

Spec: [Extern declarations](../spec/21-interop.md#interop.extern)
