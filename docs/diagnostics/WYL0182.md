# WYL0182

```
error[WYL0182]: 'name()' is already declared in interface 'Named'
```

A method of an interface is declared once, in it or in the interfaces it extends.

## Example

```wyl
interface Named {
    String name();
}

interface Labeled extends Named {
    String name();
}

void main() { }
```

## Fix

Remove the second declaration.

Spec: [Interface declarations](../spec/10-interfaces.md#interfaces.declarations)
