# WYL0437

```
error[WYL0437]: cannot import a declaration as 'Result'
```

The names every file sees (`String`, `Array`, `Span`, `ReadOnlySpan`, `Result`, `Spannable`,
`ReadOnlySpannable`, `Borrowable`, `Printable`, and `Comparable`) always mean the
language's own declarations, so an import may not bring in anything else under one of them.
Importing the declaration itself, as in `import std::Result;`, is valid.

## Example

```wyl
import std::collections::List as Result;

void main() { }
```

## Fix

Import it under another name: `import std::collections::List as Items;`.

Spec: [Names every file sees](../spec/03-programs.md#programs.builtin-names)
