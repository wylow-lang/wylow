# WYL0485

```
error[WYL0485]: cannot loop over 'Buffer', which is an iterator and converts to a span
```

A for-each loop iterates a value that converts to a span through the span, and iterates an iterator
through `moveNext` and `current`. If a type is both, the two loops could visit different elements,
so the compiler does not choose between them.

## Example

```wyl
import std::Iterator;

struct Buffer implements Iterator<int>, ReadOnlySpannable<int> {
    int[2] values;

    pub mut bool moveNext() {
        return false;
    }

    pub int current() {
        return 0;
    }

    pub ReadOnlySpan<int> asReadOnlySpan() {
        return values;
    }
}

void main() {
    var buffer = Buffer([1, 2]);
    for (int value : buffer) { }
}
```

## Fix

Loop over the span by name, as in `for (int value : buffer.asReadOnlySpan())`, or over an iterator
that a method of the type returns. A container usually names its iterator with a method such as
`iterator()` rather than implementing `Iterator` itself.
