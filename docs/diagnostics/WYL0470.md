# WYL0470

```
error[WYL0470]: field 'count' of shared class 'Counter' cannot be 'mut'
```

Several threads read a shared class's fields, and no thread synchronizes with another to write one
([Shared classes](../spec/19-concurrency.md#concurrency.shared-classes)). A `mut` field could change
while another thread reads it, so a shared class cannot declare one. A shared class writes its
other fields in its constructors only.

## Example

```wyl
shared class Counter {
    mut int count;
}

void main() { }
```

## Fix

Remove `mut` and give the field its value in a constructor. A value that changes on several threads
belongs in a synchronization type, such as the standard library's `Atomic<T>` or `Mutex<T>`.

Spec: [Shared classes](../spec/19-concurrency.md#concurrency.shared-classes)
