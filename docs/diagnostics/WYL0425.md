# WYL0425

The compiler no longer emits this code, and no other diagnostic will take it.

The code reported a method declared `extern` that was neither static nor a member of an extern
struct. The `extern` modifier no longer exists. A method without a body in a struct of an extern
block is provided by C++, and every other method has a body
([decision 0084](../design/decisions/0084-extern-blocks-are-the-one-extern-form.md)).

Spec: [Extern blocks](../spec/21-interop.md#interop.extern)
