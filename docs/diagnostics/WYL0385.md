# WYL0385

```
error[WYL0385]: 'ref' pattern can only be used with 'is'
```

A `ref` or `in` pattern is a test of a nullable reference, and only `is` accepts it.

## Example

```wyl
void main() {
    int x = 1;
    switch (x) {
        case ref int e -> { }
        default -> { }
    }
}
```

## Fix

Write the test with `is` in an `if` or another expression.

Spec: [Reference bindings](../spec/15-patterns.md#patterns.references)
