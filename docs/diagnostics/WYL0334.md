# WYL0334

```
error[WYL0334]: 'try' can only be used in a function that returns a 'Result'
```

`try` returns the error to the enclosing function, so that function must return a `Result`.

## Example

```wyl
Result<int, String> read() {
    return Result.Ok(1);
}

int plain() {
    int a = try read();
    return a;
}

void main() { }
```

## Fix

Use `try` in a function that returns a `Result`, or handle the `Result` directly.

Spec: [`try`](../spec/13-expressions.md#expressions.try)
