# WYL0262

```
error[WYL0262]: untyped lambda parameter cannot be declared 'escaping'
```

An untyped lambda parameter takes its form from the lambda's function type and cannot be declared `escaping`.

## Example

```wyl
void main() {
    fn(escaping fn() -> void) -> void f = (escaping g) -> g();
}
```

## Fix

Give the parameter a type, or remove `escaping`.

Spec: [Typing lambdas](../spec/12-functions.md#functions.lambdas.typing)
