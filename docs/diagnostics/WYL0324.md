# WYL0324

```
error[WYL0324]: switch expression has no case that produces a value
```

A switch expression needs at least one case whose expression produces a value.

## Example

```wyl
import std::panic;

void main() {
    int n = 1;
    var x = switch (n) {
        default -> panic("no");
    };
}
```

## Fix

Give a case a value, or use a switch statement.

Spec: [Switch expressions](../spec/13-expressions.md#expressions.switch)
