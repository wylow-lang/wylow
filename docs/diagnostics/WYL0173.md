# WYL0173

```
error[WYL0173]: value does not fit in the enum's integer type 'byte'
```

The value of a variant is a number of the enum's integer type.

## Example

```wyl
@Repr(byte)
enum Color {
    Red = 300,
    Green
}

void main() { }
```

## Fix

Use a smaller value, or a larger integer type.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
