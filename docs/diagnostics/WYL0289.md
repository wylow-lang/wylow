# WYL0289

```
error[WYL0289]: struct 'Point' cannot be created with 'new'
```

A struct is a value. Its memberwise or declared constructor is called without `new`.

## Example

```wyl
struct Point { int x; }

void main() {
    var p = new Point();
}
```

## Fix

Write `Point(...)`.

Spec: [Construction](../spec/13-expressions.md#expressions.construction)
