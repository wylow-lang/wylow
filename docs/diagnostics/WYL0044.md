# WYL0044

```
error[WYL0044]: 'List' is already a name of this module
```

An import may not bring in a type or function under a name the file or its module declares, or a module under the name of one of its module's submodules, since the name would then mean two things in the file.

## Example

```wyl
import std::List;

struct List { }

void main() { }
```

## Fix

Import it under another name with `as`: `import std::List as StdList;`.

Spec: [Imports](../spec/03-programs.md#programs.imports)
