# WYL0481

```
warning[WYL0481]: cannot find warning 'unqualifed-call'
```

An argument of `@SuppressWarnings` names no warning that the compiler reports, so the annotation turns nothing off with it. The name is usually misspelled. This warning is named `unknown-warning`.

## Example

```wyl
@SuppressWarnings("unqualifed-call")
void main() { }
```

## Fix

Correct the name, or remove the argument. Each warning's page gives its name: `unqualified-call` is the name of [WYL0480](WYL0480.md).

Spec: [`@SuppressWarnings`](../spec/22-annotations.md#annotations.suppress-warnings)
