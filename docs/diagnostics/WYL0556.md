# WYL0556

```
error[WYL0556]: cannot read the downloaded file as an archive
note: End of Central Directory record could not be found.
```

A package's `fetch` entry names an archive when the URL's path ends with `.zip`, `.tar`, `.tar.gz`,
or `.tgz`. The compiler reports this error when the downloaded file is not an archive of that form,
or when the archive is damaged. The compiler also reports this error when the files that it
extracts are larger than 512 MiB together, or when reading the archive expands more than 1 GiB. A
note gives the reason.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "fetch_archive";

native {
    fetch {
        url = "https://badzip.test/x.zip";
        sha256 = "306dd75289584f36ed2491b76f151702d5535c722337074d638f62a0a63b572e";
        files = ["sample/value.h"];
    }
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Check that the URL names an archive of the kind that its path's extension gives, and that the file
at the URL is not damaged. If the download is one file rather than an archive, give it a URL whose
path does not end with an archive extension, and name the file in `files`.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
