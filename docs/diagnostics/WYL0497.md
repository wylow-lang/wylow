# WYL0497

```
error[WYL0497]: 'pub' cannot be used on an extern block
```

An extern block takes no modifiers. Each member of the block has the visibility written before the
member.

## Example

```wyl
@Include("version.h")
pub extern {
    int version();
}

void main() { }
```

## Fix

Remove the modifier from the block, and write the visibility before each member that needs it.

Spec: [Extern blocks](../spec/21-interop.md#interop.extern)
