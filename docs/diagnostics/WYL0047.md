# WYL0047

```
error[WYL0047]: cannot find module 'orders' in this scope
```

A path's first name is a module the file sees, and no module of that name exists.

## Example

```wyl
void main() {
    int n = orders::count();
}
```

## Fix

Correct the module's name, or create the module and import it.

Spec: [Paths](../spec/03-programs.md#programs.paths)
