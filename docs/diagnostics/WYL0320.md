# WYL0320

```
error[WYL0320]: '?:' cannot choose between two values of type 'Span<int>'
```

A view must come from one place, and a conditional would choose between two different views.

## Example

```wyl
void main() {
    mut int[2] a = [1, 2];
    Span<int> s = a;
    bool flag = true;
    var x = flag ? s : s;
}
```

## Fix

Use `if` with a variable for each branch.

Spec: [The conditional operator](../spec/13-expressions.md#expressions.conditional)
