# WYL0504

```
error[WYL0504]: field 'start' of a struct in an extern block cannot have an initializer
```

A struct or union in an extern block is the C++ type of its name. The default value of the type
has every field at its own default value, so a field takes no initializer.

## Example

```wyl
@Include("range.h")
extern {
    struct Range {
        pub int start = 1;
    }
}

void main() { }
```

## Fix

Remove the initializer, and set the field after the value is made.

Spec: [Structs and unions](../spec/21-interop.md#interop.extern.c-structs)
