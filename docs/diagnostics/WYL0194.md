# WYL0194

```
error[WYL0194]: generic methods cannot be 'virtual', 'override', or 'abstract'
```

A method that is `virtual`, `override`, or `abstract` has no type parameters of its own.

## Example

```wyl
class Shape {
    pub virtual void visit<T>(T value) { }
}

void main() { }
```

## Fix

Make the class generic instead, or remove `virtual`.

Spec: [Type parameters](../spec/11-generics.md#generics.parameters)
