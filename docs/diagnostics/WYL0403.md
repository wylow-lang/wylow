# WYL0403

```
error[WYL0403]: 'Weak' type argument: expected a class or interface type, found 'int'
```

`Weak<T>` refers to an object, so `T` is a class or interface type. A type parameter cannot be one,
since it may stand for a struct.

## Example

```wyl
import std::Weak;

void main() {
    Weak<int> number;
}
```

## Fix

Use a class or interface type as the type argument.

Spec: [Weak references](../spec/17-memory.md#memory.weak)
