# WYL0350

```
error[WYL0350]: cannot assign to this expression
```

The target of an assignment is a place: a variable, a field, an element, or a call that returns a reference.

## Example

```wyl
class Holder {
    int count() {
        return 0;
    }
}

void main() {
    var h = new Holder();
    h.count() = 3;
}
```

## Fix

Assign to a variable, a field, or an element, or call a method that returns a reference.

Spec: [Assignment](../spec/14-statements.md#statements.assignment)
