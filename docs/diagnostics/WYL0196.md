# WYL0196

```
error[WYL0196]: type arguments can only be used in a call
```

Type arguments are written on a call. On a field or other member they have no meaning.

## Example

```wyl
class Node {
    int x;

    pub void f() {
        var d = this.x<int>.y;
    }
}

void main() { }
```

## Fix

Remove the type arguments, or call the method: `this.m<int>(...)`.

Spec: [Type arguments](../spec/11-generics.md#generics.arguments)
