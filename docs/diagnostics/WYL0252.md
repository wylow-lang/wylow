# WYL0252

```
error[WYL0252]: 'operator []=' cannot be static
```

`operator []=` is an instance method and cannot be `static`.

## Example

```wyl
struct Shapes {
    int operator [](int i) {
        return 0;
    }

    static void operator []=(byte i, int value) { }
}

void main() { }
```

## Fix

Remove `static`.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
