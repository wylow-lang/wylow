# WYL0007

```
error[WYL0007]: number literal has no digits
```

A hexadecimal or binary literal has at least one digit after its `0x` or `0b`.

## Example

```wyl
void main() {
    int mask = 0x;
}
```

## Fix

Write the digits: `0x0`, `0xFF`.

Spec: [Integer literals](../spec/02-lexical.md#lexical.literals.integer)
