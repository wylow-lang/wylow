# WYL0236

```
error[WYL0236]: no overload of 'show' accepts (bool)
```

The arguments convert to the parameter types of one overload.

## Example

```wyl
void show(int x) { }

void show(String s) { }

void main() {
    show(true);
}
```

## Fix

Pass arguments that one overload accepts.

Spec: [Overload resolution](../spec/12-functions.md#functions.overloading.resolution)
