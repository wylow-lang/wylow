# WYL0152

```
error[WYL0152]: enums cannot have constructors
```

An enum value is made from one of its variants, so an enum has no constructors.

## Example

```wyl
enum Color {
    Red;

    pub Color() { }
}

void main() { }
```

## Fix

Remove the constructor. To keep data in a value, give a variant fields: `Rgb(int r, int g, int b)`.

Spec: [Enum declarations](../spec/09-enums.md#enums.declarations)
