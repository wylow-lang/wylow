# WYL0163

```
error[WYL0163]: enum methods cannot be 'mut'
```

An enum value is not changed in place, only replaced, so its methods are not `mut`.

## Example

```wyl
enum Color {
    Red;

    pub mut void reset() { }
}

void main() { }
```

## Fix

Remove `mut`. A method that returns the new value lets the caller assign it.
