# WYL0533

```
error[WYL0533]: dependency 'tool' is not a library
```

A package depends only on libraries. A package whose manifest has no `kind = "library";` entry is a program, and a program has an entry point that no other package can use.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    tool { path = "vendor/tool"; }
}
```

```wyl src/main.wyl
void main() { }
```

```wylcfg vendor/tool/package.wylcfg
name = "tool";
```

```wyl vendor/tool/src/main.wyl
void main() { }
```

## Fix

Move the code that the package needs into a library, and make the program depend on that library too.

Spec: [Dependencies](../spec/03-programs.md#programs.manifest.dependencies)
