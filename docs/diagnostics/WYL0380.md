# WYL0380

```
error[WYL0380]: pattern 'Car' can never match a value of type 'Animal'
```

A type pattern names a type that a value of the matched type can have. A class pattern names a class in the value's class hierarchy or an interface, and a pattern on a value type names that type.

## Example

```wyl
class Animal { }
class Car { }
void main() {
    Animal a = new Animal();
    if (a is Car c) { }
}
```

## Fix

Match a type the value can have, or remove the pattern.

Spec: [Matching](../spec/15-patterns.md#patterns.matching)
