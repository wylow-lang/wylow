# WYL0458

```
error[WYL0458]: only a 'unique' struct can have a destructor
```

A struct is declared `unique` when it has one owner. Only such a struct may declare a destructor.
A copyable struct can have many copies, so it has no single owner, and the language has no point
at which to run its destructor.

## Example

```wyl
struct Buffer {
    pub int length;

    ~Buffer() { }
}

void main() { }
```

## Fix

Declare the struct `unique`, or remove the destructor. If the struct cannot be unique, put the
resource in a class, whose destructor releases it when the last reference to the object goes.

Spec: [Destructors and `discard`](../spec/07-structs.md#structs.unique.destructors)
