# WYL0478

```
error[WYL0478]: 'Graph' is not 'sendable'
```

A sendable value converts to `Isolated<T>` by moving into the box
([Isolated object graphs](../spec/19-concurrency.md#concurrency.isolated)). A value that is not
sendable belongs to the current thread, so the box could not carry it to another thread, and the
objects it reaches would stay behind while the box moved.

## Example

```wyl
import std::isolated::Isolated;

class Node { }

struct Graph {
    pub Node? root;
}

void main() {
    var graph = Graph(null);
    Isolated<Graph> box = graph;
}
```

## Fix

Build the object graph inside the box's constructor, where it is isolated from the start:

```wyl
import std::isolated::Isolated;

class Node { }

class Graph {
    mut Node? root;
    pub Graph() { root = new Node(); }
}

void main() {
    Isolated<Graph> box = Isolated<Graph>(() -> new Graph());
}
```

Alternatively, give the value a sendable type, such as a primitive type, a `String`, a struct whose
fields are all sendable, or a unique value that owns only sendable values.

Spec: [Isolated object graphs](../spec/19-concurrency.md#concurrency.isolated)
