# WYL0226

```
error[WYL0226]: positional argument cannot follow a named argument
```

Positional arguments come before named arguments.

## Example

```wyl
void f(int a, int b) { }

void main() {
    f(b: 2, 1);
}
```

## Fix

Move the positional argument before the named arguments.

Spec: [Default values and named arguments](../spec/12-functions.md#functions.arguments)
