# WYL0195

```
error[WYL0195]: type arguments can only be used in a call or construction
```

Type arguments are written on a call, or on the type of a construction. On a name alone they have no meaning.

## Example

```wyl
class Node {
    int x;

    pub void f() {
        var c = x<int>.y;
    }
}

void main() { }
```

## Fix

Remove the type arguments, or call the function: `f<int>(...)`.

Spec: [Type arguments](../spec/11-generics.md#generics.arguments)
