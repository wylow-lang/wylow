# WYL0215

```
error[WYL0215]: default value of 'seed' depends on itself
```

A default value cannot depend on the parameter it belongs to.

## Example

```wyl
struct Loop {
    int v;

    Loop(int a, Loop seed = Loop(1)) {
        v = a;
    }
}

void main() { }
```

## Fix

Remove the reference to the parameter from its default value.

Spec: [Parameters](../spec/12-functions.md#functions.parameters)
