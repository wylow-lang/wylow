# WYL0333

```
error[WYL0333]: 'try' cannot be used in a lambda whose return type is inferred
```

A lambda whose return type is inferred provides no result type while its body is checked, and `try` needs one.

## Example

```wyl
Result<int, String> parse() {
    return Result.Ok(1);
}

U run<U>(fn() -> U f) {
    return f();
}

void main() {
    var x = run(() -> try parse());
}
```

## Fix

Specify the call's type arguments.

Spec: [`try`](../spec/13-expressions.md#expressions.try)
