# WYL0419

```
error[WYL0419]: 'beginBorrow' cannot be called directly
```

`Borrowable`'s `beginBorrow` and `endBorrow` are called by the implementation around every borrow,
not by the program.

## Example

```wyl
import std::List;

void main() {
    var list = new List<int>();
    list.beginBorrow();
}
```

## Fix

Remove the call. A reference or span taken into the container borrows it.

Spec: [`Borrowable`](../spec/17-memory.md#memory.borrows.borrowable)
