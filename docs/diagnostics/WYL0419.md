# WYL0419

```
error[WYL0419]: 'beginBorrow' can only be called in 'unsafe' code
```

The compiler calls `Borrowable`'s `beginBorrow` and `endBorrow` around every borrow. A call in safe
code could start a borrow that nothing ends, or end a borrow that the compiler started, so only
unsafe code may call them. Unsafe code must call `endBorrow` once for each call of `beginBorrow`.

## Example

```wyl
import std::collections::List;

void main() {
    var list = new List<int>();
    list.beginBorrow();
}
```

## Fix

Remove the call. A reference or span taken into the container borrows it. To borrow a container for
longer, such as for the lifetime of a value that refers to it, hold a `std::Borrow`, which calls
`beginBorrow` when it is made and `endBorrow` when it is released.

Spec: [`Borrowable`](../spec/17-memory.md#memory.borrows.borrowable)
