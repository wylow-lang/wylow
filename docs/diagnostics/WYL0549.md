# WYL0549

```
error[WYL0549]: non-escaping function argument of a constructor of 'Pair' must be a variable that is not 'mut'
help: declare the function in a local first
```

A constructor of a `ref struct` may keep a non-escaping function argument in a field, and the
field refers to the function for as long as the struct exists. A lambda or a function name written
as the argument makes a function that is gone after its statement. A `mut` variable may be assigned
another function while the struct still refers to the first one. The argument must therefore be a
parameter or a local that is not `mut`.

## Example

```wyl
ref struct Pair {
    fn(int) -> int first;
}

void main() {
    var pair = Pair((value) -> value + 1);
}
```

## Fix

Declare the function in a local first: `fn(int) -> int next = (value) -> value + 1;`, and pass
`next`.
