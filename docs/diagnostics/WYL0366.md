# WYL0366

```
error[WYL0366]: expected '->', found ':'
```

A case is written `case X -> ...`; there is no colon form and no fallthrough.

## Example

```wyl
void main() {
    int n = 1;
    switch (n) {
        case 1: std::print(1);
        default -> std::print(2);
    }
}
```

## Fix

Replace the colon with `->`.

Spec: [Switch statements](../spec/14-statements.md#statements.switch)
