# WYL0538

```
error[WYL0538]: 'PARSER_DEPTH' is defined as '8', and package 'parser' defines it as '4'
```

The generated program includes the headers of every package's extern blocks, and each header may need the definitions of its own package. The program's C++ therefore compiles with the definitions of every package. If two packages define one name with different values, that C++ has no single value to give the name. The compiler therefore reports the definition of the package that comes later in an order where every package comes after its dependencies. A definition without a value, such as `"PARSER_DEPTH"`, has the value `1`, so it agrees with `"PARSER_DEPTH=1"`.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    parser { path = "vendor/parser"; }
}

native {
    defines = ["PARSER_DEPTH=8"];
}
```

```wyl src/main.wyl
void main() { }
```

```wylcfg vendor/parser/package.wylcfg
name = "parser";
kind = "library";
version = "1.0.0";

native {
    defines = ["PARSER_DEPTH=4"];
}
```

```wyl vendor/parser/src/parser.wyl
pub int depth() { return 0; }
```

## Fix

Give the name one value in every package, or rename the definition in one of the packages.
