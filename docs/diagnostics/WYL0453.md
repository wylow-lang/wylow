# WYL0453

```
error[WYL0453]: 'Buffer' is not 'copyable'
```

A type parameter with the bound `copyable` copies its values, so a type argument must be copyable.

## Example

```wyl
unique struct Buffer {
    pub int length;
}

T firstCopy<T extends copyable>(T value) {
    return value;
}

void main() {
    var buffer = Buffer(2);
    var copy = firstCopy(buffer);
}
```

## Fix

Give the type argument a copyable type, such as a class over the unique value, or take the value
by `ref` or `in` instead.

Spec: [Bounds](../spec/11-generics.md#generics.bounds)
