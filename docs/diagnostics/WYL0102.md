# WYL0102

```
error[WYL0102]: 'Link' has no default value
```

`T()` needs every field to have an initializer or a type with a default value. A field of a class type has neither.

## Example

```wyl
class Node { }

struct Link {
    pub Node next;
}

void main() {
    var l = Link();
}
```

## Fix

Pass the fields that have no default, by name or by position: `Link(next: n)`.

Spec: [The default value](../spec/07-structs.md#structs.constructors.default)
