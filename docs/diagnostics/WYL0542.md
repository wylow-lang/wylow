# WYL0542

```
error[WYL0542]: static 'Codes.TWO' cannot be a pattern
note: a static is a pattern only if its initializer is a literal
```

A pattern may name a static, and the pattern then matches the static's value. The compiler must
know that value, so that it can report two cases of one value. The compiler knows the value of a
static whose type is an integer type, `char`, or `bool`, and whose initializer is a literal of that
type. An extern constant is a pattern only if its declaration gives its value, as in
`static int LIMIT = 8;`. The note says which of these rules the static breaks.

## Example

```wyl
class Codes {
    pub static int TWO = 1 + 1;
}

void main() {
    int code = 2;
    switch (code) {
        case Codes.TWO -> std::print("two");
        case _ -> std::print("other");
    }
}
```

## Fix

Write the static's initializer as a literal, such as `pub static int TWO = 2;`. For an extern
constant, give its value in the declaration. If the value cannot be a literal, compare with `==`
in an `if` or in a guard: `case _ when code == Codes.TWO`.
