# WYL0111

```
error[WYL0111]: 'super' cannot be used in 'Shape'
```

`super` names the base class, and this class has none.

## Example

```wyl
class Shape {
    pub int area() { return super.area(); }
}

void main() { }
```

## Fix

Remove the call, or give the class a base class.

Spec: [Inheritance](../spec/08-classes.md#classes.inheritance)
