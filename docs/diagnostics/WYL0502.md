# WYL0502

```
error[WYL0502]: 'first' cannot be generic
```

Only the standard library's extern blocks declare generic functions, methods, and structs. A
generic declaration would name a C++ template, and a program cannot name its type arguments in
C++.

## Example

```wyl
@Include("items.h")
extern {
    T* first<T>(T* items);
}

void main() { }
```

## Fix

Declare one function for each type that the C++ code supports. To bind a C++ template, write a
native shim that instantiates the template, and declare the shim's functions.

Spec: [The standard library's extern declarations](../spec/21-interop.md#interop.extern.std)
