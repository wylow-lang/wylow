# WYL0068

```
error[WYL0068]: index 4 is out of bounds for 'int[4]'
```

A constant index into a fixed array must be at least 0 and less than its length.

## Example

```wyl
import std::print;

void main() {
    int[4] a = [1, 2, 3, 4];
    print(a[4]);
}
```

## Fix

Use an index inside the array.

Spec: [Fixed arrays](../spec/04-types.md#types.fixed-arrays)
