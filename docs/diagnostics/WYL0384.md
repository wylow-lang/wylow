# WYL0384

```
error[WYL0384]: pattern type: expected 'float', found 'int'
```

The type in an `is ref` or `is in` pattern is the type the reference refers to.

## Example

```wyl
struct Mat2 {
    float x;

    mut ref? float at(int i) {
        return ref x;
    }
}
void main() {
    mut Mat2 m = Mat2();
    if (m.at(0) is ref int wrong) { }
}
```

## Fix

Write the type the reference refers to, or leave the type out and bind with `var`.

Spec: [Reference bindings](../spec/15-patterns.md#patterns.references)
