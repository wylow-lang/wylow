# WYL0155

```
error[WYL0155]: variant fields cannot be 'mut'
```

An enum value is replaced as a whole and its variant fields are not changed, so they are not `mut`.

## Example

```wyl
enum Shape {
    Circle(mut int radius),
    Empty
}

void main() { }
```

## Fix

Remove `mut`. To change the value, assign a new one to its variable.

Spec: [Variants](../spec/09-enums.md#enums.variants)
