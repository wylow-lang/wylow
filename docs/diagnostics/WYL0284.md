# WYL0284

```
error[WYL0284]: 'this' cannot be used here
```

Default values, field initializers, static methods, and arguments to `super(...)` and `this(...)` are evaluated without a receiver.

## Example

```wyl
class Order {
    int total;

    void apply(int by = this.total) { }
}

void main() { }
```

## Fix

Use a constant or a parameter, or move the expression into the method body.

Spec: [Names, literals, and `this`](../spec/13-expressions.md#expressions.primary)
