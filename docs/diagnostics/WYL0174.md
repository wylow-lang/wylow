# WYL0174

```
error[WYL0174]: interfaces cannot use 'implements'
```

An interface extends interfaces. It does not implement any: it has no bodies to implement them with.

## Example

```wyl
interface Named {
    String name();
}

interface Labeled implements Named { }

void main() { }
```

## Fix

Write `extends` and the interface.

Spec: [Interface declarations](../spec/10-interfaces.md#interfaces.declarations)
