# WYL0413

```
error[WYL0413]: 'ref? int' cannot be a type argument
```

Only a `ref?` or `in?` variable or parameter can hold a nullable reference. It cannot be a field,
a variant field, an array element, a type argument, or a pointer's target.

## Example

```wyl
struct Buffer {
    int[2] data;

    mut ref? int at(int index) {
        if (index >= 2) {
            return null;
        }
        return ref data[index];
    }
}

T identity<T>(T value) { return value; }

void main() {
    mut Buffer buffer = Buffer();
    identity(buffer.at(0));
}
```

## Fix

Copy the place with `!`, or keep the reference in a `ref?` local.

Spec: [Nullable references](../spec/17-memory.md#memory.nullable-references)
