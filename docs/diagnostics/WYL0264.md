# WYL0264

```
error[WYL0264]: parameter 'v' cannot be 'mut'
```

A parameter passed as `ref` or `in` cannot be declared `mut`.

## Example

```wyl
struct Vec {
    float x;
}

void main() {
    fn(ref Vec) -> void reset = (mut v) -> { };
}
```

## Fix

Remove `mut` from the parameter.

Spec: [Typing lambdas](../spec/12-functions.md#functions.lambdas.typing)
