# WYL0541

```
error[WYL0541]: enum 'Code' cannot declare a method named 'tryFrom'
note: an enum whose variants carry no data has a 'tryFrom' of its own
```

Every enum whose variants carry no data has a static method `tryFrom`, which converts an integer to
the variant with that value, or to null. If the enum declared a second `tryFrom`, the name
`Code.tryFrom` would have two meanings, so such an enum cannot declare a method of that name. An
enum whose variants carry data has no `tryFrom` of its own, so it may declare one.

## Example

```wyl
enum Code {
    Ok,
    Busy;

    static Code? tryFrom(int value) {
        return null;
    }
}

void main() { }
```

## Fix

Give the method another name, or call the enum's own `tryFrom`.
