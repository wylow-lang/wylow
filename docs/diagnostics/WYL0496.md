# WYL0496

```
error[WYL0496]: 'extern' can only begin an extern block
```

The word `extern` begins an extern block, which declares what C++ source provides. It is not a
modifier of a function, a method, or a struct.

## Example

```wyl
extern int version() {
    return 1;
}

void main() { }
```

## Fix

If C++ code provides the function, move its declaration into an extern block, and write an
`@Include` of the C++ header before the block. If the function is Wylow code, remove `extern`.

```
@Include("version.h")
extern {
    int version();
}
```
