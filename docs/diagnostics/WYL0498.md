# WYL0498

```
error[WYL0498]: 'unsafe' cannot be used on an extern constant
```

An extern constant is written `static T NAME;`. It takes no modifier besides `static` and its
visibility, and reading it needs no unsafe code.

## Example

```wyl
@Include("limits.h")
extern {
    unsafe static int LIMIT;
}

void main() { }
```

## Fix

Remove the modifier.

Spec: [Extern constants](../spec/21-interop.md#interop.extern.constants)
