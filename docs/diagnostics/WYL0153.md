# WYL0153

```
error[WYL0153]: enums cannot have fields
```

The data of an enum value belongs to its variant, so an enum has no fields.

## Example

```wyl
enum Color {
    Red;

    int code;
}

void main() { }
```

## Fix

Give the data to the variants that need it: `Red(int code)`.

Spec: [Enum declarations](../spec/09-enums.md#enums.declarations)
