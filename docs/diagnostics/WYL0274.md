# WYL0274

```
error[WYL0274]: escaping lambda cannot capture 'this' in a struct's method or constructor
```

An escaping lambda cannot capture `this` in a struct's method or constructor, since `this` is a reference to the struct.

## Example

```wyl
struct Point {
    int x;

    mut fn() -> int getter() {
        return () -> x;
    }
}

void main() { }
```

## Fix

Copy the needed value to a local before creating the lambda.

Spec: [Captures](../spec/12-functions.md#functions.lambdas.captures)
