# WYL0240

```
error[WYL0240]: 'bad' returns a reference, so 'return' must be 'return ref'
```

A method that returns `ref` or `in` places its result with `return ref`.

## Example

```wyl
struct Buffer {
    int[4] cells;

    mut ref int bad(int i) {
        return cells[i];
    }
}

void main() { }
```

## Fix

Write `return ref` before the place.

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
