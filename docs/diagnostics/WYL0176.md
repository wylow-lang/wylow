# WYL0176

```
error[WYL0176]: 'static' cannot be used on an interface method
```

A method of an interface is a signature that implementations match. Only `mut` applies to it.

## Example

```wyl
interface Named {
    static String name();
}

void main() { }
```

## Fix

Remove the modifier.

Spec: [Interface declarations](../spec/10-interfaces.md#interfaces.declarations)
