# WYL0330

```
error[WYL0330]: 'is' cannot test the type of a value of type 'int'
```

Only a class or interface value carries a type that `is` can test. A value of a value type cannot be another type.

## Example

```wyl
class Node { }

void main() {
    int n = 1;
    var b = n is Node;
}
```

## Fix

Test a class or interface value, or compare the value directly.

Spec: [`is`](../spec/13-expressions.md#expressions.is)
