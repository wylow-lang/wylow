# WYL0254

```
error[WYL0254]: 'operator []=' cannot have default values
```

`operator []=` takes no default values; an assignment uses those of the matching `operator []`.

## Example

```wyl
struct Defaults {
    int operator [](int i, int j = 0) {
        return i + j;
    }

    mut void operator []=(int i, int j = 0, int value) { }
}

void main() { }
```

## Fix

Remove the default values from `operator []=`.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
