# WYL0469

```
error[WYL0469]: 'shared' can only be used on a class
```

An object may be referred to from several threads only when its class is declared `shared`
([Shared classes](../spec/19-concurrency.md#concurrency.shared-classes)). A struct, an enum, and an
interface have no objects of their own, so `shared` cannot be written on one.

## Example

```wyl
shared struct Buffer {
    int size;
}

void main() { }
```

## Fix

Remove `shared` from the declaration. A value type whose fields are sendable can already reach
another thread by being copied.

Spec: [Shared classes](../spec/19-concurrency.md#concurrency.shared-classes)
