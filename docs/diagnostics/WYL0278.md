# WYL0278

```
error[WYL0278]: lambda chosen by a switch expression cannot use 'a'
```

A lambda chosen by a switch expression is created outside the cases and cannot use a name that a case declares.

## Example

```wyl
enum Op {
    Add(int amount),
    Stop,
}

void main() {
    Op op = Op.Add(1);
    fn(int) -> int f = switch (op) {
        case Add(var a) -> x -> x + a;
        case Stop -> x -> x;
    };
}
```

## Fix

Copy the case's value to a local outside the switch, or use a switch statement.

Spec: [Choosing between functions](../spec/12-functions.md#functions.choices)
