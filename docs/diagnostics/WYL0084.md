# WYL0084

```
error[WYL0084]: 'a' is already defined in this scope
```

A variable or parameter cannot take the name of one already visible in its scope.

## Example

```wyl
void main() {
    int a = 1;
    int a = 2;
}
```

## Fix

Rename one of them.

Spec: [Local variables](../spec/06-variables.md#variables.locals)
