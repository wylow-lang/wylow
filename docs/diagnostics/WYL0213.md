# WYL0213

```
error[WYL0213]: 'Dog.speak' cannot declare default values
```

A method that overrides or implements another takes that method's default values and declares none of its own.

## Example

```wyl
class Animal {
    virtual String speak(int times = 1) {
        return "...";
    }
}

class Dog extends Animal {
    override String speak(int times = 2) {
        return "woof";
    }
}

void main() { }
```

## Fix

Remove the default values from the override.
