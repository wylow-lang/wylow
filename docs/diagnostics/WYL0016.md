# WYL0016

```
error[WYL0016]: '\u{D800}' is not a Unicode scalar value
```

A `\u{...}` escape names a Unicode scalar value: a code point up to `10FFFF` that is not a surrogate, `D800` to `DFFF`.

## Example

```wyl
void main() {
    char c = '\u{D800}';
}
```

## Fix

Write the code point of the character itself. A character above `FFFF` is written directly, as in `\u{1F600}`, not as a surrogate pair.
