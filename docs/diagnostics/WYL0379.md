# WYL0379

```
error[WYL0379]: fields of 'Point': expected 2, found 1
```

A struct pattern or a variant pattern gives one subpattern for each field.

## Example

```wyl
struct Point { int x; int y; }
void main() {
    Point p = Point(1, 2);
    if (p is Point(1)) { }
}
```

## Fix

Give one subpattern per field, or use `_` for a field that is not needed.

Spec: [Kinds of patterns](../spec/15-patterns.md#patterns.kinds)
