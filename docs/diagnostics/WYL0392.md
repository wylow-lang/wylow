# WYL0392

```
error[WYL0392]: 'default' can never be reached
```

`default` matches every value left after the cases above it, and it is unreachable when those cases match every value already.

## Example

```wyl
enum Color { Red, Green }
void main() {
    Color c = Color.Red;
    switch (c) {
        case Red, Green -> { }
        default -> { }
    }
}
```

## Fix

Remove `default`, or remove the case above that covers its values.

Spec: [Exhaustiveness and unreachable cases](../spec/15-patterns.md#patterns.exhaustiveness)
