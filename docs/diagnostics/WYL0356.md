# WYL0356

```
error[WYL0356]: cannot loop over a temporary array by 'ref'
```

A `ref` loop variable borrows each element, so the array must outlive the loop; a temporary array does not.

## Example

```wyl
int[3] numbers() {
    return [1, 2, 3];
}

void main() {
    for (ref int n : numbers()) { }
}
```

## Fix

Store the array in a `mut` variable, then loop over it by `ref`.

Spec: [For-each](../spec/14-statements.md#statements.for-each)
