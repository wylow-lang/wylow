# WYL0106

```
error[WYL0106]: struct 'Node' contains itself
```

A struct is stored in full inside its fields, so it cannot contain itself. A nullable struct is stored inline too, so `?` does not help.

## Example

```wyl
struct Node {
    pub int value;
    pub Node? next;
}

void main() { }
```

## Fix

Make `Node` a class, or hold the link in a class.

Spec: [Recursive structs](../spec/07-structs.md#structs.recursive)
