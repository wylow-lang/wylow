# WYL0323

```
error[WYL0323]: case of a switch expression must produce a value
```

Every case of a switch expression supplies the expression's value, so each case must be an expression of that type.

## Example

```wyl
void nothing() { }

void main() {
    int n = 1;
    var x = switch (n) {
        case 1 -> nothing();
        default -> 2;
    };
}
```

## Fix

Produce a value in the case, or use a switch statement.

Spec: [Switch expressions](../spec/13-expressions.md#expressions.switch)
