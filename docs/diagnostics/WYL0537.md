# WYL0537

```
error[WYL0537]: library 'parser' has version '2.0.0', which does not satisfy '1.4'
```

An entry of `dependencies` may state the version of the library that the package needs. The library's version satisfies the stated version if it is not lower and has the same major number. If the stated major number is 0, the library's minor number must also be the same. A library with another major number may have changed in a way that breaks the package.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    parser { path = "vendor/parser"; version = "1.4"; }
}
```

```wyl src/main.wyl
void main() { }
```

```wylcfg vendor/parser/package.wylcfg
name = "parser";
kind = "library";
version = "2.0.0";
```

```wyl vendor/parser/src/parser.wyl
pub int depth() { return 0; }
```

## Fix

Update the package to the library's new version and state that version, or replace the library's directory with a copy of a version that satisfies the entry.

Spec: [Versions](../spec/03-programs.md#programs.manifest.versions)
