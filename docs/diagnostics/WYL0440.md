# WYL0440

```
error[WYL0440]: 'data' is used after being moved
```

A value of a unique type is moved where a copyable value is copied, and the variable it was
moved from holds no value afterwards. Using that variable is an error until it is assigned a
value again.

## Example

```wyl
unique struct Buffer {
    pub int length;
}

void main() {
    var data = Buffer(4);
    var kept = data;
    int length = data.length;
}
```

## Fix

Use the variable the value was moved into (`kept`), or assign `data` a new value before using it.

Spec: [Use after move](../spec/16-flow.md#flow.moves)
