# WYL0267

```
error[WYL0267]: non-escaping function cannot be 'mut'
```

A non-escaping function parameter or local keeps the function it was given and cannot be `mut`.

## Example

```wyl
void functions(mut fn() -> void f) { }

void main() { }
```

## Fix

Remove `mut`, or declare the parameter or local `escaping`.

Spec: [Escaping and non-escaping](../spec/12-functions.md#functions.lambdas.escaping)
