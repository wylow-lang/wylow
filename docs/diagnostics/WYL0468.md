# WYL0468

```
error[WYL0468]: static 'CURRENT' has no initializer and 'Choice' has no default value
```

Every static is initialized before `main` runs. A static without an initializer takes its type's
default value, and an enum whose first variant carries data has none.

## Example

```wyl
enum Choice {
    Filled(int value),
    Empty
}

class Settings {
    static Choice CURRENT;
}

void main() { }
```

## Fix

Give the static an initializer, as in `static Choice CURRENT = Choice.Empty;`.
