# WYL0143

```
error[WYL0143]: field 'next' of type 'Node' has no default value
```

A field whose type has no default value and that has no initializer gets its value in the constructor.

## Example

```wyl
class Node { }

class Link {
    Node next;
}

void main() { }
```

## Fix

Give the field an initializer, or assign it in every constructor.

Spec: [Order of construction](../spec/08-classes.md#classes.construction)
