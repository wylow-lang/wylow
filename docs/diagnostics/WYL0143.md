# WYL0143

```
error[WYL0143]: field 'next' of type 'Node' has no initial value
```

Every constructor assigns a field with no initializer whose type has no initial value, since empty storage holds no value to start from. A class that declares no constructor therefore cannot have such a field.

## Example

```wyl
class Node { }

class Link {
    Node next;
}

void main() { }
```

## Fix

Give the field an initializer, or assign it in every constructor.

Spec: [Order of construction](../spec/08-classes.md#classes.construction)
