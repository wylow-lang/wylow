# WYL0171

```
error[WYL0171]: value of 'Green' does not fit in the enum's integer type 'byte'
```

A variant without a value is one more than the variant before it, and that number is a value of the integer type.

## Example

```wyl
@Repr(byte)
enum Color {
    Red = 255,
    Green
}

void main() { }
```

## Fix

Give the variant a value, or a larger integer type.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
