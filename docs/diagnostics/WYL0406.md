# WYL0406

```
error[WYL0406]: 'ref' variable cannot refer into nullable 'point'
```

A reference cannot refer into the value of a nullable local that can be assigned again: assigning
the local null would destroy the value.

## Example

```wyl
struct Point { pub int x; }

void main() {
    mut Point? point = Point(1);
    if (point != null) {
        ref int x = point.x;
    }
}
```

## Fix

Copy the value to a variable first, or declare the local without `mut`.
