# WYL0438

```
error[WYL0438]: 'for' needs a condition
```

A `for` loop tests a condition before each iteration. A loop that tests nothing is a `loop`.

## Example

```wyl
void main() {
    for (mut int i = 0; ; i++) {
        break;
    }
}
```

## Fix

Write the condition, or use `loop { ... }` and update the variable in its body.

Spec: [`while`, `loop`, and `for`](../spec/14-statements.md#statements.loops)
