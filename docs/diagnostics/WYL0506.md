# WYL0506

```
error[WYL0506]: parameter 'text' has type 'String', which is not blittable
```

An extern declaration describes memory that C++ code reads and writes, so every type in it must
have the same memory representation in Wylow and in C++. Such a type is blittable. A parameter, a
result, a constant, and a field of a struct or union in an extern block each need a blittable type.
A `String`, a class reference, a `List<T>`, and a `ref` parameter are not blittable.

## Example

```wyl
@Include("text.h")
extern {
    nuint text_length(String text);
}

void main() { }
```

## Fix

Pass the data in a blittable form. A string crosses as the `byte*` that `cstr()` returns:
`nuint text_length(byte* text);`.
