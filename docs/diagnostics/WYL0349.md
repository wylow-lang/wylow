# WYL0349

```
error[WYL0349]: cannot assign to an element of a temporary array
```

An element of a temporary array is gone after the statement, so an assignment to it would be lost.

## Example

```wyl
int[3] makeArray() {
    return [1, 2, 3];
}

void main() {
    makeArray()[0] = 5;
}
```

## Fix

Store the array in a `mut` variable, then assign to its element.

Spec: [Assignment](../spec/14-statements.md#statements.assignment)
