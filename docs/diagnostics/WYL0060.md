# WYL0060

```
error[WYL0060]: 'main' must return 'void' or 'int'
```

The entry point returns nothing, or an `int` that is the program's exit status.

## Example

```wyl
float main() {
    return 1.0;
}
```

## Fix

Return `void` or `int`.

Spec: [The entry point](../spec/03-programs.md#programs.entry)
