# WYL0272

```
error[WYL0272]: cannot assign to 'n' in a lambda
```

A lambda may run more than once, so it assigns only a variable declared `mut`.

## Example

```wyl
void run(fn() -> void f) {
    f();
}

void main() {
    int n;
    run(() -> { n = 1; });
}
```

## Fix

Declare the variable `mut`, or assign it outside the lambda.

Spec: [Captures](../spec/12-functions.md#functions.lambdas.captures)
