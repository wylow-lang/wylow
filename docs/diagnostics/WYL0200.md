# WYL0200

```
error[WYL0200]: type arguments of 'Pair': expected 2, found 1
```

A generic type is written with one type argument for each type parameter, in a variable's type as everywhere.

## Example

```wyl
struct Pair<A, B> {
    pub A first;
    pub B second;
}

void main() {
    Pair<int> p;
}
```

## Fix

Write all the type arguments: `Pair<int, int>`.

Spec: [Type arguments](../spec/11-generics.md#generics.arguments)
