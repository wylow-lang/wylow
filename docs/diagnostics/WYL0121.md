# WYL0121

```
error[WYL0121]: 'area()' hides inherited method 'Shape.area()'
```

A method that has the signature of an inherited method which is not `virtual` would hide it, and methods are not hidden.

## Example

```wyl
class Shape {
    pub int area() { return 0; }
}

class Square extends Shape {
    pub int area() { return 1; }
}

void main() { }
```

## Fix

Rename the method, or declare the inherited one `virtual` and write `override`.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
