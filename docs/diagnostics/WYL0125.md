# WYL0125

```
error[WYL0125]: 'area' does not match the parameter and return types of 'Shape.area'
```

An override has the parameter types (nullability included) and the return type of the method it overrides, exactly.

## Example

```wyl
class Shape {
    pub virtual int area() { return 0; }
}

class Square extends Shape {
    pub override long area() { return 1; }
}

void main() { }
```

## Fix

Give the override the signature of the method it overrides.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
