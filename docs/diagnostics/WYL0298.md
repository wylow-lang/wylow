# WYL0298

```
error[WYL0298]: method 'Counter.count' is used as a field
```

A method is called. Its name without parentheses is not a field value.

## Example

```wyl
struct Counter {
    int total;

    int count() {
        return total;
    }
}

void main() {
    var c = Counter(1);
    var n = c.count;
}
```

## Fix

Call it with `count()`.

Spec: [Member access](../spec/13-expressions.md#expressions.members)
