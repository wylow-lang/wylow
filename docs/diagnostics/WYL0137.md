# WYL0137

```
error[WYL0137]: 'this(...)' must be the first statement of a constructor
```

The call to another constructor of the class is the first thing a constructor does.

## Example

```wyl
class Box {
    int size;

    pub Box() {
        size = 0;
        this(1);
    }

    pub Box(int size) {
        this.size = size;
    }
}

void main() { }
```

## Fix

Move `this(...)` to the start of the constructor body.

Spec: [Constructors](../spec/08-classes.md#classes.constructors)
