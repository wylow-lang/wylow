# WYL0512

```
error[WYL0512]: field 'value' of struct 'Wide' does not match the C++ type 'Wide'
```

A struct or union declared with fields in an extern block is the C++ type of its name, and the
compiler compares the declaration's layout with the C++ type's layout. The declaration must have
the C++ type's size and alignment, and each field must have the C++ field's offset and size. A
field that is declared with a type of another size, or in another order, does not match.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "records";
```

```cpp native/records.h
#pragma once
#include <cstdint>
struct Wide { int32_t tag; int64_t value; };
```

```wyl src/main.wyl
@Include("records.h")
extern {
    struct Wide {
        pub int tag;
        pub int value;
    }
}

void main() { }
```

## Fix

Declare each field with the C++ field's type, in the C++ order: `pub long value;`.

Spec: [Layout checks](../spec/21-interop.md#interop.blittable.layout)
