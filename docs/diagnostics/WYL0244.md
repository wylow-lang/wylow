# WYL0244

```
error[WYL0244]: static method cannot return 'ref'
```

Only an instance method returns a reference, since the returned reference points into the receiver.

## Example

```wyl
struct Buffer {
    unsafe static ref int first(int* p) {
        return ref p[0];
    }
}

void main() { }
```

## Fix

Remove `static`, or return the value by value.

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
