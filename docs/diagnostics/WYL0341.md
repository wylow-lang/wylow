# WYL0341

```
error[WYL0341]: body of 'if' is not enclosed in braces
```

The body of an `if` statement is a block, written in braces, even when it holds one statement.

## Example

```wyl
void main() {
    if (true) std::print(1);
}
```

## Fix

Write the statement inside braces.

Spec: [Blocks and scopes](../spec/14-statements.md#statements.blocks)
