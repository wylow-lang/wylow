# WYL0187

```
error[WYL0187]: 'Box.name' must have no visibility
```

A method that implements an interface method has the visibility of the interface, which is the visibility of its methods.

## Example

```wyl
interface Named {
    String name();
}

class Box implements Named {
    pub String name() { return "b"; }
}

void main() { }
```

## Fix

Write the visibility the message names.

Spec: [Implementing an interface](../spec/10-interfaces.md#interfaces.implementing)
