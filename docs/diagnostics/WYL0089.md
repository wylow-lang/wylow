# WYL0089

```
error[WYL0089]: 'ref' parameter cannot be 'mut'
```

A `ref` or `in` variable refers to the same place for its whole scope, so `mut` has no meaning on it.

## Example

```wyl
void take(mut ref int v) { }

void main() { }
```

## Fix

Remove `mut`.

Spec: [`ref` and `in` variables](../spec/06-variables.md#variables.references)
