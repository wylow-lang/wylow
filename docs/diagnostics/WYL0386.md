# WYL0386

```
error[WYL0386]: case with 'default' cannot have a guard
```

`default` matches every value the cases above do not. A guard is not allowed on it.

## Example

```wyl
enum Shape { Circle(int r), Rect(int w, int h) }
void main() {
    Shape s = Shape.Circle(1);
    bool flag = true;
    switch (s) {
        case Circle(_) -> { }
        default when flag -> { }
    }
}
```

## Fix

Remove the guard and test the condition inside the case.
