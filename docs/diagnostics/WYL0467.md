# WYL0467

```
error[WYL0467]: static field 'LIMIT' cannot be read through a value
```

A static belongs to its type, not to any one value of it, so code names a static through the type.

## Example

```wyl
import std::print;

class Settings {
    static int LIMIT = 5;
}

void main() {
    var settings = new Settings();
    print(settings.LIMIT);
}
```

## Fix

Name the type instead of the value: `Settings.LIMIT`.

Spec: [Member access](../spec/13-expressions.md#expressions.members)
