# WYL0345

```
error[WYL0345]: assignment cannot be used as an expression
```

An assignment is a statement, and its value cannot be used by an enclosing expression.

## Example

```wyl
void main() {
    mut int x = 0;
    int y = (x = 1);
}
```

## Fix

Write the assignment as its own statement, then use the variable.
