# WYL0378

```
error[WYL0378]: variant 'Red' carries no data
```

A variant with no fields is matched by its name alone, without parentheses.

## Example

```wyl
enum Color { Red, Green }
void main() {
    Color c = Color.Red;
    switch (c) {
        case Red() -> { }
        case Green -> { }
    }
}
```

## Fix

Match the variant without parentheses.

Spec: [Kinds of patterns](../spec/15-patterns.md#patterns.kinds)
