# WYL0305

```
error[WYL0305]: indexing 'int[4]' takes a single index
```

A fixed array has one index. An indexer takes the number of indices its `operator []` declares.

## Example

```wyl
void main() {
    int[4] a = [1, 2, 3, 4];
    var x = a[0, 1];
}
```

## Fix

Write one index, as in `a[i]`.

Spec: [Indexing](../spec/13-expressions.md#expressions.indexing)
