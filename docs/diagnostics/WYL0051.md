# WYL0051

```
error[WYL0051]: 'private' is not a visibility
```

The visibilities are `module`, `package`, and `pub`, and a declaration without one is private to its file. `public`, `private`, and `protected` are reserved words.

## Example

```wyl
class Account {
    private int balance;
}

void main() { }
```

## Fix

Remove `private`. For `public`, write `pub`; for `protected`, the `pub` level that the subclasses in other files need.

Spec: [Visibility](../spec/03-programs.md#programs.visibility)
