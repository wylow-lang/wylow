# WYL0008

```
error[WYL0008]: integer literal does not fit in 64 bits
```

An integer literal's value is less than 2<sup>64</sup>, whatever its type.

## Example

```wyl
void main() {
    ulong n = 18446744073709551616uL;
}
```

## Fix

Write a smaller value. The largest is `18446744073709551615uL`.

Spec: [Integer literals](../spec/02-lexical.md#lexical.literals.integer)
