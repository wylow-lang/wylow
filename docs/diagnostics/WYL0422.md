# WYL0422

```
error[WYL0422]: pointer arithmetic can only be used in 'unsafe' code
```

`p + n` and `p - n` move a pointer by a number of elements. The move is not checked, so it is an
unsafe operation.

## Example

```wyl
struct Buffer {
    int* data;
}

void main() {
    Buffer buffer = Buffer(null);
    int* next = buffer.data + 1;
}
```

## Fix

Do the arithmetic in an `unsafe` block, or index an array, a span, or a list, whose indexing is
bounds-checked.

Spec: [Pointers](../spec/20-unsafe.md#unsafe.pointers)
