# WYL0224

```
error[WYL0224]: argument 1 of 'bump' must be passed with 'ref'
```

An argument for a `ref` parameter is written with `ref`.

## Example

```wyl
void bump(ref int x) { }

void main() {
    mut int n = 1;
    bump(n);
}
```

## Fix

Write `ref` before the argument.

Spec: [Parameter modes](../spec/12-functions.md#functions.parameters.modes)
