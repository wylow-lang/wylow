# WYL0307

```
error[WYL0307]: operator '-' cannot be applied to 'bool'
```

A unary operator applies only to the operand types it is defined for. `-` applies to signed integers and floating-point values.

## Example

```wyl
void main() {
    var x = -true;
}
```

## Fix

Apply it to a numeric value, or remove it.

Spec: [Operand and result types](../spec/13-expressions.md#expressions.arithmetic.operands)
