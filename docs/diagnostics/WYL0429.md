# WYL0429

```
error[WYL0429]: struct in an extern block cannot declare constructors
```

A struct or union in an extern block is the C++ type of its name. A struct has the memberwise
constructor, and a union has no constructor.

## Example

```wyl
@Include("range.h")
extern {
    struct Range {
        pub int start;
        pub int length;

        Range(int start) { }
    }
}

void main() { }
```

## Fix

Remove the constructor. Build the struct with its memberwise constructor, or write a function that
returns one.

Spec: [Structs and unions](../spec/21-interop.md#interop.extern.c-structs)
