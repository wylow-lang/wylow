# WYL0074

```
error[WYL0074]: parentheses around this function type are not needed
```

A function type is parenthesized only where it is followed by `?`, `[`, or `*`.

## Example

```wyl
void run((fn() -> void) f) { }

void main() { }
```

## Fix

Remove the parentheses.

Spec: [Function types](../spec/04-types.md#types.functions)
