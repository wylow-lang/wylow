# WYL0511

```
error[WYL0511]: type 'int' of constant 'CODEC_LIMIT' does not match the type of C++ 'CODEC_LIMIT'
```

An extern constant names a C++ constant, variable, or macro, and the compiler compares the declared
type with the type of the C++ expression. A macro's type is the type of the literal that it expands
to. The literal `10u` is an `unsigned int`, which matches `uint` and does not match `int`.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "codec";
```

```cpp native/codec.h
#pragma once
#define CODEC_LIMIT 10u
```

```wyl src/main.wyl
@Include("codec.h")
extern {
    static int CODEC_LIMIT;
}

void main() { }
```

## Fix

Declare the constant with its C++ type: `static uint CODEC_LIMIT;`.

Spec: [Extern constants](../spec/21-interop.md#interop.extern.constants)
