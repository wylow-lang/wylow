# WYL0409

```
error[WYL0409]: 'ref' cannot be used with type 'Node'
```

A class object and a function value are already passed without copying, so a reference to one adds
nothing.

## Example

```wyl
class Node { }

void main() {
    Node node = new Node();
    ref Node alias = node;
}
```

## Fix

Use the class reference or function value directly.
