# WYL0409

```
error[WYL0409]: 'ref' cannot be used with type 'fn() -> void'
```

A function value is already passed without copying, so a reference to one adds nothing.

## Example

```wyl
void run(ref fn() -> void action) {
}

void main() {
}
```

## Fix

Pass the function value directly.
