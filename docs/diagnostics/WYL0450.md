# WYL0450

```
error[WYL0450]: a method with a by-value receiver cannot be 'mut'
```

A by-value receiver is the method's own copy, so there is no caller's value to change: `mut` and
`static` do not apply.

## Example

```wyl
struct Counter {
    int value;

    mut void reset(this Counter counter) {
    }
}

void main() { }
```

## Fix

Remove the modifier, or take the receiver in place with `mut`.

Spec: [By-value receivers](../spec/07-structs.md#structs.methods.by-value)
