# WYL0142

```
error[WYL0142]: argument to 'super(...)' for a reference or view parameter must be a parameter, a field of one, or 'null'
```

A `ref` or view argument in `super(...)` or `this(...)` is a parameter of the constructor, a field of one, or `null`.

## Example

```wyl
class Shape {
    pub Shape(Span<int> view) { }
}

class Square extends Shape {
    pub Square(int[] items) {
        super(items);
    }
}

void main() { }
```

## Fix

Take the view as a parameter of the constructor, and pass it on.

Spec: [Order of construction](../spec/08-classes.md#classes.construction)
