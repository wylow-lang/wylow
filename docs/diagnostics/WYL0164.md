# WYL0164

```
error[WYL0164]: ':' cannot give an enum's integer type
```

The integer type of an enum is given by `@Repr`, not by a `:` after the name.

## Example

```wyl
enum Color : uint {
    Red,
    Green
}

void main() { }
```

## Fix

Write `@Repr(uint)` before `enum`.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
