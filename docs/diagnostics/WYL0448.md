# WYL0448

```
error[WYL0448]: 'this' parameter cannot be 'ref' or 'in'
```

A by-value receiver is an ordinary parameter that the method takes by value, so it cannot also be
`ref` or `in`. `mut` is how a struct method changes its receiver in place.

## Example

```wyl
struct Counter {
    int value;

    void reset(this ref Counter counter) {
    }
}

void main() { }
```

## Fix

Write `this T name`, or declare the method `mut`.

Spec: [By-value receivers](../spec/07-structs.md#structs.methods.by-value)
