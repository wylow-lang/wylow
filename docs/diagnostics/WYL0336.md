# WYL0336

```
error[WYL0336]: cannot interpolate a value of type 'Plain'
```

Interpolation calls a value's `toString`, which exists only for a type that implements `Printable`.

## Example

```wyl
struct Plain {
    int x;
}

void main() {
    var p = Plain(1);
    std::print($"{p}");
}
```

## Fix

Implement `Printable` on the type, or format the value another way.

Spec: [String interpolation](../spec/13-expressions.md#expressions.interpolation)
