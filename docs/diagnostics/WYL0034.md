# WYL0034

```
error[WYL0034]: 'Order' is already defined in this module
```

A file sees its own declarations and its module's names, and may not see two declarations of one name unless both are functions, which are then overloads. A file-private declaration may share its name with a file-private one in another file of the module.

## Example

```wyl
struct Order { }

void Order() { }

void main() { }
```

## Fix

Rename one of the declarations, or make both file-private in different files.

Spec: [A module's names](../spec/03-programs.md#programs.names)
