# WYL0365

```
error[WYL0365]: variable cannot be declared directly in a case
```

A case's body is a single statement or a block; a declaration directly in a case would have the whole switch as its scope.

## Example

```wyl
void main() {
    int n = 1;
    switch (n) {
        case 1 -> int y = 2;
        default -> { }
    }
}
```

## Fix

Write the case body as a block.

Spec: [Switch statements](../spec/14-statements.md#statements.switch)
