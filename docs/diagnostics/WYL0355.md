# WYL0355

```
error[WYL0355]: cannot loop over 'values' by 'ref'
```

A `ref` loop variable borrows each element, which requires a mutable sequence.

## Example

```wyl
void readOnly(in int[2] values) {
    for (ref int v : values) { }
}

void main() { }
```

## Fix

Loop with `in`, or over a mutable variable.

Spec: [For-each](../spec/14-statements.md#statements.for-each)
