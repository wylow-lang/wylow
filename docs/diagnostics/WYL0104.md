# WYL0104

```
error[WYL0104]: cannot call 'mut' method 'reset' on a temporary value
```

A temporary is a value that is gone after its statement, so a change to it is lost.

## Example

```wyl
struct Point {
    pub int x;

    pub mut void reset() { x = 0; }
}

Point make() { return Point(1); }

void main() {
    make().reset();
}
```

## Fix

Store the value in a `mut` variable first, and call the method on the variable.

Spec: [`mut` methods](../spec/07-structs.md#structs.methods.mut)
