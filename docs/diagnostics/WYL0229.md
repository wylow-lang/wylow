# WYL0229

```
error[WYL0229]: parameter 'a' is given more than one argument
```

A parameter is given at most one argument.

## Example

```wyl
void f(int a, int b = 0) { }

void main() {
    f(1, a: 2);
}
```

## Fix

Remove one of the two arguments.

Spec: [Default values and named arguments](../spec/12-functions.md#functions.arguments)
