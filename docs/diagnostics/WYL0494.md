# WYL0494

```
error[WYL0494]: interface 'Widened' extends unsafe interface 'Checked' without being 'unsafe'
```

A type that implements an interface also implements every interface that the interface extends.
If an interface that is not unsafe could extend an unsafe one, a type could implement the unsafe
interface through it without writing `unsafe`, and so without marking its promise. An interface
that extends an unsafe interface is therefore declared `unsafe` itself.

## Example

```wyl
unsafe interface Checked {
    void check();
}

interface Widened extends Checked { }

void main() { }
```

## Fix

Declare the interface `unsafe interface Widened`, and state in its documentation the promise that
it passes on from `Checked`.

Spec: [Unsafe interfaces](../spec/10-interfaces.md#interfaces.unsafe)
