# WYL0474

```
error[WYL0474]: shared lambda cannot capture 'changing'
```

A non-escaping shared lambda refers to what it captures in place, and another thread reads that
place while the lambda runs
([Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)). A `mut` local may
change during that time, so a shared lambda may not capture one.

## Example

```wyl
void run(shared fn() -> int f) { }

void main() {
    mut int changing = 1;
    run(() -> changing);
}
```

## Fix

Copy the value into a variable that is not `mut` before the lambda is created.

Spec: [Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)
