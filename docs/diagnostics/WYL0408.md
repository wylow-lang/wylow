# WYL0408

```
error[WYL0408]: cannot bind 'ref' to read-only 'value'
```

`ref` needs a mutable place. The place is read-only because the variable holding it is not `mut`,
because it is rooted at an `in` parameter or variable, or because it is a `mut` method's `this`.

## Example

```wyl
void main() {
    int value = 1;
    ref int other = value;
}
```

## Fix

Make the place mutable, or bind with `in` instead.
