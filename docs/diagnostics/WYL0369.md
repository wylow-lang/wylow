# WYL0369

```
error[WYL0369]: cannot switch on a value of type 'ref? float'
```

A nullable reference may refer to nothing, which a pattern cannot match.

## Example

```wyl
struct Mat2 {
    float[4] m;

    mut ref? float at(int i) {
        if (i < 0) {
            return null;
        }
        return ref m[i];
    }
}

void main() {
    mut Mat2 m = Mat2();
    switch (m.at(0)) {
        default -> { }
    }
}
```

## Fix

Check the reference for null, then switch on it with `!`.

Spec: [Switch statements](../spec/14-statements.md#statements.switch)
