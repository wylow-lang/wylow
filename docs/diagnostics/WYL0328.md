# WYL0328

```
error[WYL0328]: 'is' cannot test a 'void' value
```

`is` tests a value's type, and a call that returns nothing provides no value to test.

## Example

```wyl
void nothing() { }

void main() {
    nothing() is var value;
}
```

## Fix

Call the function without `is`.

Spec: [`is`](../spec/13-expressions.md#expressions.is)
