# WYL0179

```
error[WYL0179]: interface methods cannot have a body
```

A method of an interface has no body; the types that implement it provide one.

## Example

```wyl
interface Named {
    String name() { return "n"; }
}

void main() { }
```

## Fix

Replace the body with `;`.

Spec: [Interface declarations](../spec/10-interfaces.md#interfaces.declarations)
