# WYL0233

```
error[WYL0233]: no overload of 'show' takes 0 arguments
```

An overload is selected only when an overload takes the number of arguments written.

## Example

```wyl
void show(int x) { }

void show(String s) { }

void main() {
    show();
}
```

## Fix

Pass the number of arguments that one overload takes.

Spec: [Overload resolution](../spec/12-functions.md#functions.overloading.resolution)
