# WYL0531

```
error[WYL0531]: 'vendor/parser' does not hold a package
```

The `path` of an entry of `dependencies` names a directory relative to the manifest's own directory. That directory must hold a package, which is a directory with a `package.wylcfg`.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    parser { path = "vendor/parser"; }
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Correct the path, or put the library's directory where the path names it.

Spec: [Dependencies](../spec/03-programs.md#programs.manifest.dependencies)
