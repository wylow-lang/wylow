# WYL0062

```
error[WYL0062]: 'void' cannot be used here
```

`void` is what a function that returns nothing returns. It is not the type of a value, so it cannot be a type argument, a field, a variable, or a parameter.

## Example

```wyl
import std::List;

void main() {
    List<void> items;
}
```

## Fix

Use a type that has values.

Spec: [Kinds of types](../spec/04-types.md#types.kinds)
