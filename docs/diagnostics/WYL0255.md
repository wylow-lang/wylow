# WYL0255

```
error[WYL0255]: value of 'operator []=' cannot be 'ref'
```

The value parameter of `operator []=` is passed by value or `in` and cannot be `ref`.

## Example

```wyl
struct Shapes {
    int operator [](int i) {
        return 0;
    }

    mut void operator []=(int i, ref long value) { }
}

void main() { }
```

## Fix

Remove `ref` from the value parameter.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
