# WYL0372

```
error[WYL0372]: 'missingValue' must return a value of type 'int'
```

A function that returns a type produces a value on every path, and a bare `return` produces none.

## Example

```wyl
int missingValue() {
    return;
}

void main() { }
```

## Fix

Return a value of the function's type.

Spec: [`return`](../spec/14-statements.md#statements.return)
