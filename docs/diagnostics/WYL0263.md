# WYL0263

```
error[WYL0263]: type of parameter 'x': expected 'int', found 'long'
```

A typed lambda parameter has the type and mode of the function type's parameter.

## Example

```wyl
void main() {
    fn(int) -> int f = (long x) -> 1;
}
```

## Fix

Write the parameter's type as the function type gives it.

Spec: [Typing lambdas](../spec/12-functions.md#functions.lambdas.typing)
