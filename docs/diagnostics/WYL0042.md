# WYL0042

```
error[WYL0042]: cannot find 'Config' as a top-level module, a package, or a name of the root module
```

An import of a single name brings in a module directly in `src/`, the package `std`, or a name of the root module.

## Example

```wyl
import Config;

void main() { }
```

## Fix

Declare the name in the root module, or give the module it is in: `import settings::Config;`.

Spec: [Imports](../spec/03-programs.md#programs.imports)
