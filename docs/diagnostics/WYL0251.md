# WYL0251

```
error[WYL0251]: 'operator []=' must return 'void'
```

`operator []=` returns `void`.

## Example

```wyl
struct Shapes {
    int[4] cells;

    int operator [](int i) {
        return cells[i];
    }

    int operator []=(int i, int value) {
        return 0;
    }
}

void main() { }
```

## Fix

Declare the return type as `void`.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
