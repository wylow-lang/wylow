# WYL0211

```
error[WYL0211]: 'pending' has no body
```

A function that is not `extern` needs a body.

## Example

```wyl
void pending(int x);

void main() { }
```

## Fix

Add a body, or declare the function `extern` in the standard library.

Spec: [Function declarations](../spec/12-functions.md#functions.declarations)
