# WYL0211

```
error[WYL0211]: 'pending' has no body
```

A function needs a body, unless it is declared in an extern block. C++ provides the functions of an
extern block.

## Example

```wyl
void pending(int x);

void main() { }
```

## Fix

Add a body, or declare the function in an extern block if C++ code defines it.

Spec: [Function declarations](../spec/12-functions.md#functions.declarations)
