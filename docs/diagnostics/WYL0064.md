# WYL0064

```
error[WYL0064]: 'memory::collectCycles' is a function, not a type
```

The name in a type position is a function. A function's type is written `fn(...) -> ...`; its name is not a type.

## Example

```wyl
import std::memory;

void collect(memory::collectCycles cycles) { }

void main() { }
```

## Fix

Write a function type such as `fn() -> void`, or the name of a type.

Spec: [Writing types](../spec/04-types.md#types.syntax)
