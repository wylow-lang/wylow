# WYL0273

```
error[WYL0273]: escaping lambda cannot capture 'n'
```

An escaping lambda captures its values by copy, so it cannot capture a `ref` or `in` variable, a span or other `ref struct`, a non-escaping function, or a `mut` local.

## Example

```wyl
void keep(escaping fn() -> int f) { }

void main() {
    mut int n = 1;
    keep(() -> n);
}
```

## Fix

Copy the captured value to a local that is not `mut` before the lambda.

Spec: [Captures](../spec/12-functions.md#functions.lambdas.captures)
