# WYL0013

```
error[WYL0013]: string literal is not closed
```

A string literal ends with a `"` on its own line. A line break in a string is written `\n`.

## Example

```wyl
void main() {
    String s = "unfinished
        ;
}
```

## Fix

Close the string on its line, and write a line break in it as `\n`.
