# WYL0407

```
error[WYL0407]: 'ref' variable must refer to a variable, field, or element
```

A reference must refer to a place, not to a temporary value.

## Example

```wyl
void main() {
    ref int value = 1;
}
```

## Fix

Store the value in a variable, then refer to that variable.
