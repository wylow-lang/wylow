# WYL0451

```
error[WYL0451]: a method with a by-value receiver cannot return a reference or a view
```

A returned reference or view points into the method's receiver, which a by-value receiver does not
keep.

## Example

```wyl
struct Store {
    int value;

    ReadOnlySpan<byte> bytes(this Store store) {
        return "a".bytes();
    }
}

void main() { }
```

## Fix

Return the value, or reach the receiver in place.

Spec: [By-value receivers](../spec/07-structs.md#structs.methods.by-value)
