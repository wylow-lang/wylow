# WYL0231

```
error[WYL0231]: call to 'f' has no argument for parameter 'a'
```

A call gives an argument for every parameter that has no default value.

## Example

```wyl
void f(int a, int b = 1) { }

void main() {
    f();
}
```

## Fix

Pass an argument for the parameter.

Spec: [Default values and named arguments](../spec/12-functions.md#functions.arguments)
