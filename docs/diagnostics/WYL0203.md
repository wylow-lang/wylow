# WYL0203

```
error[WYL0203]: cannot infer type argument 'T' of 'keep' from 'null'
```

`null` has no type of its own, so it determines no type argument.

## Example

```wyl
void keep<T>(T value) { }

void main() {
    keep(null);
}
```

## Fix

Write the type argument: `keep<int?>(null)`.

Spec: [Inferring type arguments](../spec/11-generics.md#generics.arguments.inference)
