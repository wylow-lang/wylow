# WYL0361

```
error[WYL0361]: range bounds must be integers, found 'float' and 'int'
```

The bounds of a range are integers.

## Example

```wyl
void main() {
    for (var i : 0.5..2) { }
}
```

## Fix

Use integer bounds, converting a float bound to an integer first.

Spec: [Ranges](../spec/14-statements.md#statements.for-each.ranges)
