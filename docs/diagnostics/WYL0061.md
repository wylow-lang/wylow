# WYL0061

```
error[WYL0061]: program already has a 'main' function
```

The root module has one `main`. Two files of it may each declare a file-private one, which is still two.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

```wyl src/main.wyl
void main() { }
```

```wyl src/tools.wyl
void main() { }
```

## Fix

Rename or remove one of them.

Spec: [The entry point](../spec/03-programs.md#programs.entry)
