# WYL0190

```
error[WYL0190]: 'Tag.name' cannot be 'mut'
```

A `mut` method changes its value, and the interface method does not allow that.

## Example

```wyl
interface Named {
    String name();
}

struct Tag implements Named {
    mut String name() { return "t"; }
}

void main() { }
```

## Fix

Remove `mut`, or declare the interface method `mut`.

Spec: [`mut` interface methods](../spec/10-interfaces.md#interfaces.mut)
