# WYL0536

```
error[WYL0536]: dependency 'orders' has the name of a module directly in 'src/'
```

A dependency's name is the first name of a path in every file of the package, and so is the name of a module directly in `src/`. If a dependency and such a module had one name, a path that starts with that name could mean either one.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    orders { path = "vendor/orders"; }
}
```

```wyl src/main.wyl
void main() { }
```

```wyl src/orders/order.wyl
pub struct Order { }
```

```wylcfg vendor/orders/package.wylcfg
name = "orders";
kind = "library";
version = "1.0.0";
```

```wyl vendor/orders/src/orders.wyl
pub int depth() { return 0; }
```

## Fix

Rename the module's directory.

Spec: [Dependencies](../spec/03-programs.md#programs.manifest.dependencies)
