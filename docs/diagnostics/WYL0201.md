# WYL0201

```
error[WYL0201]: cannot infer type argument 'T' of 'make'
```

No argument of the call determines the type argument.

## Example

```wyl
T make<T>() {
    return make<T>();
}

void main() {
    var x = make();
}
```

## Fix

Write the type argument: `make<int>()`.

Spec: [Inferring type arguments](../spec/11-generics.md#generics.arguments.inference)
