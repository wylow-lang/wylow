# WYL0316

```
error[WYL0316]: '?.' is used on a value of non-nullable type 'Node'
```

`?.` accesses a member only when the receiver is not null, so the receiver must be nullable.

## Example

```wyl
class Node { int value; }

void main() {
    var n = new Node();
    var v = n?.value;
}
```

## Fix

Write `.`.

Spec: [Null operators](../spec/13-expressions.md#expressions.null)
