# WYL0088

```
error[WYL0088]: 'var' cannot hold 'row.at(0)', which might refer to nothing
```

The result of a function returning `ref?` might refer to nothing, and `var` holds a value rather than referring to a place.

## Example

```wyl
struct Row {
    float[4] cells;

    mut ref? float at(int i) {
        if (i < 0) {
            return null;
        }
        return ref cells[i];
    }
}

void main() {
    mut Row row = Row();
    var copy = row.at(0);
}
```

## Fix

Write `ref? var copy = row.at(0);` to refer to it, or use `!` to copy what it refers to.

Spec: [Inferred types](../spec/06-variables.md#variables.locals.var)
