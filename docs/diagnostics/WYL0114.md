# WYL0114

```
error[WYL0114]: cannot extend 'Point', which is not a class
```

Only a class is extended. A struct, an enum, and a primitive type are not classes.

## Example

```wyl
struct Point {
    pub int x;
}

class Shape extends Point { }

void main() { }
```

## Fix

Remove `extends`, or make the base type a class.

Spec: [Inheritance](../spec/08-classes.md#classes.inheritance)
