# WYL0420

```
error[WYL0420]: only classes can be 'Borrowable'
```

A value is borrowed through whatever holds it, so only a class, whose object is shared, can keep
the borrow count. A struct or an enum cannot be `Borrowable`, through an interface that extends it
either.

## Example

```wyl
struct Counter implements Borrowable {
    pub void beginBorrow() { }
    pub void endBorrow() { }
}

void main() { }
```

## Fix

Make the type a class, or remove `Borrowable` from its interfaces.

Spec: [`Borrowable`](../spec/17-memory.md#memory.borrows.borrowable)
