# WYL0500

```
error[WYL0500]: extern block has more than one '@Include'
```

An extern block names exactly one C++ header.

## Example

```wyl
@Include("version.h")
@Include("build.h")
extern {
    int version();
}

void main() { }
```

## Fix

Keep one `@Include`, and declare the members of the other header in an extern block of their own.

Spec: [Extern blocks](../spec/21-interop.md#interop.extern)
