# WYL0426

```
error[WYL0426]: extern functions can only be declared in the standard library
```

An extern function is declared in a package other than `std`. The compiler currently accepts extern
declarations only in the standard library.

## Example

```wyl
extern int nativeVersion(int capacity);

void main() { }
```

## Fix

Declare the function in the standard library, or call a function of the standard library that wraps
it.

Spec: [Extern declarations](../spec/21-interop.md#interop.extern)
