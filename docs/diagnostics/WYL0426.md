# WYL0426

The compiler no longer emits this code, and no other diagnostic will take it.

The code reported an extern function declared outside the standard library. Every package may now
declare extern functions, in an extern block
([decision 0084](../design/decisions/0084-extern-blocks-are-the-one-extern-form.md)).

Spec: [Extern blocks](../spec/21-interop.md#interop.extern)
