# WYL0097

```
error[WYL0097]: 'x' is already defined as a field
```

A field and a method of a struct cannot have the same name.

## Example

```wyl
struct Point {
    pub int x;
    pub int x() { return 1; }
}

void main() { }
```

## Fix

Rename one of them.

Spec: [Struct declarations](../spec/07-structs.md#structs.declarations)
