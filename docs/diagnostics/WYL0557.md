# WYL0557

```
error[WYL0557]: opaque struct 'Parser' can only be used through a pointer
```

A struct declared in an extern block with a semicolon in place of its body is **opaque**: the header
declares the C++ type, and the program never sees its size or its fields. A value of an opaque type
therefore has no representation in the generated C++, and a program uses the type only through a
pointer to it.

## Example

```wyl
@Include("<stddef.h>")
extern {
    struct Parser;
}

void main() {
    mut var parser = Parser();
}
```

## Fix

Declare the variable, parameter, field, or result as a pointer to the struct. A C++ function that
returns a `Parser*` gives the program the pointer.

```wyl
@Include("<stddef.h>")
extern {
    struct Parser;
    Parser* parser_create();
}

void main() {
    unsafe {
        var parser = parser_create();
    }
}
```

The rule is in [Extern blocks](../spec/21-interop.md#interop.extern).
