# WYL0314

```
error[WYL0314]: '??' is used on a value of non-nullable type 'Node'
```

`??` supplies a value when its left operand is null, so the left operand must be nullable.

## Example

```wyl
class Node { }

void main() {
    var n = new Node();
    var m = n ?? n;
}
```

## Fix

Remove the `??`, or make the value nullable.

Spec: [Null operators](../spec/13-expressions.md#expressions.null)
