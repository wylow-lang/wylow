# WYL0057

```
error[WYL0057]: 'Result' cannot be declared
```

Every file sees `String`, `Array`, `Span`, `ReadOnlySpan`, `Result`, `Spannable`, `ReadOnlySpannable`, `Borrowable`, `Printable`, `Comparable`, and `Copyable` without importing them, and no package but `std` declares their names.

## Example

```wyl
struct Result { }

void main() { }
```

## Fix

Choose another name.

Spec: [Names every file sees](../spec/03-programs.md#programs.builtin-names)
