# WYL0057

```
error[WYL0057]: 'Result' cannot be declared
```

Every file sees `String`, `Array`, `Span`, `ReadOnlySpan`, `Result`, `Spannable`, `ReadOnlySpannable`, `Borrowable`, `Printable`, and `Comparable` without importing them, and they always mean those declarations. So no declaration outside `std` takes one of their names: not a type or function, and not a method, field, variant, type parameter, parameter, local, or pattern binding.

## Example

```wyl
struct Result { }

void main() { }
```

## Fix

Choose another name.

Spec: [Names every file sees](../spec/03-programs.md#programs.builtin-names)
