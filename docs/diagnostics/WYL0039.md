# WYL0039

```
error[WYL0039]: cannot find module 'text' in the root module of 'std'
```

Each name of an import's path before the last is a module within the one before it.

## Example

```wyl
import std::text::Parser;

void main() { }
```

## Fix

Correct the path.

Spec: [Imports](../spec/03-programs.md#programs.imports)
