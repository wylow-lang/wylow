# WYL0041

```
error[WYL0041]: 'List' is already re-exported by this module
```

A re-export makes a name one of its module's names, so two files of a module may not both re-export a name.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

```wyl src/main.wyl
pub import std::collections::List;

void main() { }
```

```wyl src/lists.wyl
pub import std::collections::List;
```

## Fix

Re-export the name in one file of the module; the module's other files see it without importing it.

Spec: [Imports](../spec/03-programs.md#programs.imports)
