# WYL0288

```
error[WYL0288]: enum 'Color' cannot be constructed
```

An enum value is one of its variants. The enum type itself has no construction.

## Example

```wyl
enum Color { Red }

void main() {
    var c = Color();
}
```

## Fix

Name a variant, as in `Color.Red`.

Spec: [Construction](../spec/13-expressions.md#expressions.construction)
