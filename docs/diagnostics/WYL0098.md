# WYL0098

```
error[WYL0098]: struct fields cannot be 'mut'
```

The fields of a struct value can be assigned wherever the value is a mutable place, so `mut` on a field of a struct has no meaning.

## Example

```wyl
struct Point {
    pub mut int x;
}

void main() { }
```

## Fix

Remove `mut`. Declare the variable that holds the struct `mut` to assign its fields.

Spec: [Fields](../spec/07-structs.md#structs.fields)
