# WYL0491

```
error[WYL0491]: 'Word' writes 'equals' without 'hash'
```

Two values that `equals` finds equal must hash alike. If a struct or enum that implements
`Hashable` writes its own `equals`, a `hash` that the compiler wrote from the fields could disagree
with it: two words that the written `equals` treats as equal could hash apart. The compiler
therefore writes both methods or neither.

## Example

```wyl
import std::Hashable;

struct Word implements Hashable<Word> {
    String text;

    pub bool equals(in Word other) {
        return text.byteLength() == other.text.byteLength();
    }
}

void main() { }
```

## Fix

Write `hash` too, and add to the hasher only what `equals` compares. Otherwise, remove the `equals`
that the struct writes, so that the compiler writes both methods from the fields.
