# WYL0160

```
error[WYL0160]: cannot infer type argument 'T' of 'Option' from 'Empty'
```

The type arguments of a generic enum come from the expected type, from the values of the variant, or from the program. `Empty` has no values and no expected type here.

## Example

```wyl
enum Option<T> {
    Some(T value),
    Empty
}

void main() {
    var s = Option.Empty;
}
```

## Fix

Write the type arguments, `Option<int>.Empty`, or use the variant where an `Option<int>` is expected.

Spec: [Leaving out the enum](../spec/09-enums.md#enums.variants.implicit)
