# WYL0066

```
error[WYL0066]: pointer type 'int*' cannot be nullable
```

A pointer type already has a null value, so `?` adds nothing.

## Example

```wyl
void main() {
    unsafe {
        int*? p = null;
    }
}
```

## Fix

Remove the `?`, and compare the pointer with `null`.

Spec: [Nullable types](../spec/04-types.md#types.nullable)
