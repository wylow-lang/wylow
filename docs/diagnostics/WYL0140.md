# WYL0140

```
error[WYL0140]: constructor must start with 'super(...)'
```

A constructor that does not start with `super(...)` or `this(...)` calls the parameterless constructor of the base class. Without one, it starts with a call that names the constructor to use.

## Example

```wyl
class Shape {
    pub Shape(int id) { }
}

class Square extends Shape {
    pub Square() { }
}

void main() { }
```

## Fix

Start the constructor with `super(...)` and the arguments.
