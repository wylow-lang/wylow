# WYL0188

```
error[WYL0188]: 'Box.name' does not match the parameter and return types of 'Named.name()'
```

A method that implements an interface method has its parameter types and return type exactly.

## Example

```wyl
interface Named {
    String name();
}

class Box implements Named {
    int name() { return 1; }
}

void main() { }
```

## Fix

Give the method the signature of the interface method.

Spec: [Implementing an interface](../spec/10-interfaces.md#interfaces.implementing)
