# WYL0129

```
error[WYL0129]: abstract methods cannot have a body
```

An abstract method is implemented by subclasses, so it has no body.

## Example

```wyl
abstract class Shape {
    pub abstract int area() { return 0; }
}

void main() { }
```

## Fix

Replace the body with `;`, or remove `abstract`.

Spec: [Abstract and final classes](../spec/08-classes.md#classes.abstract)
