# WYL0444

```
error[WYL0444]: cannot copy a value of type 'Buffer'
```

A value of a unique type has no copies: it is moved, not copied. This expression would copy one, as a pattern's binding by value does.

## Example

```wyl
unique struct Buffer {
    pub int length;
}

unique enum Message {
    Data(Buffer buffer),
    Empty,
}

void main() {
    var message = Message.Data(Buffer(1));
    switch (message) {
        case Message.Data(var buffer) -> { }
        default -> { }
    }
}
```

## Fix

Bind a copyable part of the matched value, or use the unique value where it is.

Spec: [Moves](../spec/17-memory.md#memory.moves)
