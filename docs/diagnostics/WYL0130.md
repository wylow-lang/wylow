# WYL0130

```
error[WYL0130]: cannot create an instance of abstract class 'Shape'
```

An abstract class is not complete, so no object is made of it.

## Example

```wyl
abstract class Shape { }

void main() {
    var s = new Shape();
}
```

## Fix

Create an object of a subclass.

Spec: [Abstract and final classes](../spec/08-classes.md#classes.abstract)
