# WYL0490

```
error[WYL0490]: field 'text' has type 'String?', which does not implement 'Hashable<String?>'
```

A struct or enum that implements `Equatable` or `Hashable` of itself, and does not write the
interface's methods, gets methods that the compiler writes from its fields. The written `equals`
calls each field's `equals`, and the written `hash` calls each field's `hash`. Each field's type
must therefore implement the same interface of itself. A nullable type, a fixed array, a function
type, and a type parameter whose bounds do not require the interface implement neither interface.

## Example

```wyl
import std::Hashable;

struct Label implements Hashable<Label> {
    String? text;
}

void main() { }
```

## Fix

Change the field to a type that implements the interface, such as `String` in place of `String?`.
For a field of a type parameter, add the interface to the parameter's bounds, as in
`struct Holder<T extends Hashable<T>>`. Otherwise, write `equals`, and `hash` for `Hashable`, in the
struct or enum, and compare the field there as it needs.

Spec: [`Equatable` and `Hashable`](../spec/a-library.md#library.equatable)
