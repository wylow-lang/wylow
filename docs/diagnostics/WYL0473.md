# WYL0473

```
error[WYL0473]: shared lambda cannot capture 'owned'
```

A shared lambda may run on another thread, so each captured value must be copyable as well as
sendable ([Sendable types](../spec/19-concurrency.md#concurrency.sendable)). A unique value has one
owner, and another thread cannot hold a copy of it.

## Example

```wyl
unique struct Owned {
    int n;
}

void keep(escaping shared fn() -> int f) { }

void main() {
    var owned = Owned(1);
    keep(() -> owned.n);
}
```

## Fix

Pass the unique value to the lambda as an argument, where the calling function decides which thread
receives it.

Spec: [Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)
