# WYL0185

```
error[WYL0185]: 'Box' does not implement 'Named.name()'
```

A type that implements an interface has a method for each method of the interface.

## Example

```wyl
interface Named {
    String name();
}

class Box implements Named { }

void main() { }
```

## Fix

Declare the method with the signature and visibility of the interface.

Spec: [Implementing an interface](../spec/10-interfaces.md#interfaces.implementing)
