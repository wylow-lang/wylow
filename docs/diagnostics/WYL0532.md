# WYL0532

```
error[WYL0532]: dependency 'text' names package 'parser'
```

The key of an entry of `dependencies` is the library's name, as the library's own manifest gives it. A package therefore names a library the same way in every program. A file that wants a shorter or a different name for the library imports it under that name.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    text { path = "vendor/parser"; }
}
```

```wyl src/main.wyl
void main() { }
```

```wylcfg vendor/parser/package.wylcfg
name = "parser";
kind = "library";
version = "1.0.0";
```

```wyl vendor/parser/src/parser.wyl
pub int depth() { return 0; }
```

## Fix

Write the entry with the library's name, `parser { path = "vendor/parser"; }`. A file that wants the name `text` writes `import parser as text;`.
