# WYL0515

```
error[WYL0515]: cannot take the address of a temporary value
```

`&` takes the address of a place: a variable, a field, or an element that an assignment could
write. The value of a call or an operator is a temporary. The temporary ends with its statement,
so a pointer to it would point to nothing.

## Example

```wyl
void main() {
    mut int count = 1;
    unsafe {
        int* p = &(count + 1);
    }
}
```

## Fix

Store the value in a `mut` variable first, and take the address of the variable.

Spec: [Pointers](../spec/20-unsafe.md#unsafe.pointers)
