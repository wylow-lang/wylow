# WYL0158

```
error[WYL0158]: variant 'Shape.Empty' carries no data
```

A variant that carries no data is written without parentheses.

## Example

```wyl
enum Shape {
    Circle(int radius),
    Empty
}

void main() {
    var s = Shape.Empty();
}
```

## Fix

Remove the parentheses.

Spec: [Variants](../spec/09-enums.md#enums.variants)
