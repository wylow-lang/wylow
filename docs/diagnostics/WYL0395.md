# WYL0395

```
error[WYL0395]: 'count' might already have been assigned
```

A local declared without an initializer and not `mut` is assigned once. An assignment may be a
second one on this path, or an earlier branch or iteration may have assigned it.

## Example

```wyl
void main() {
    int count;
    count = 1;
    count = 2;
}
```

## Fix

Declare the local `mut` to assign it more than once, or assign it once.

Spec: [Single assignment](../spec/16-flow.md#flow.assign-once)
