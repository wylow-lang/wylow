# WYL0139

```
error[WYL0139]: cannot call 'super(...)' in 'Box'
```

`super(...)` calls the constructor of the base class, and this class has none.

## Example

```wyl
class Box {
    pub Box() {
        super();
    }
}

void main() { }
```

## Fix

Remove the call, or give the class a base class.

Spec: [Constructors](../spec/08-classes.md#classes.constructors)
