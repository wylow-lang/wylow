# WYL0363

```
error[WYL0363]: loop index cannot be borrowed
```

A loop index is a copy of the position, not a place in the sequence, so it cannot be borrowed.

## Example

```wyl
void main() {
    int[3] cells = [1, 2, 3];
    for (ref int i, int v : cells) { }
}
```

## Fix

Declare the index without `ref` or `in`.

Spec: [Indices and keys](../spec/14-statements.md#statements.for-each.indices)
