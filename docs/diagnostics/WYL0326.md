# WYL0326

```
error[WYL0326]: switch expression cannot produce a value of type 'Span<int>'
```

A view type cannot be the result of a switch expression, because the result would view one of its cases.

## Example

```wyl
void main() {
    mut int[2] a = [1, 2];
    Span<int> view = switch (1) {
        case 1 -> a;
        default -> a;
    };
}
```

## Fix

Use a switch statement.

Spec: [Switch expressions](../spec/13-expressions.md#expressions.switch)
