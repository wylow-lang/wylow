# WYL0553

```
error[WYL0553]: 'abc' is not a SHA-256 hash
help: write 64 lowercase hexadecimal digits
```

A package's `fetch` entry gives the SHA-256 hash of the downloaded file. The compiler reports this
error when the `sha256` entry is not 64 lowercase hexadecimal digits.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "fetch_hash_form";

native {
    fetch {
        url = "https://files.test/sample.zip";
        sha256 = "abc";
        files = ["sample/value.h"];
    }
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Write the hash as 64 lowercase hexadecimal digits, such as
`"3806927d8ed43dea85666325770b2a572b1dcc6e355127eaa87938ec1d85ab11"`.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
