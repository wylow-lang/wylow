# WYL0122

```
error[WYL0122]: 'area()' overrides nothing
```

`override` names a method of a base class, and none has these parameters.

## Example

```wyl
class Shape { }

class Square extends Shape {
    pub override int area() { return 1; }
}

void main() { }
```

## Fix

Remove `override`, or correct the name or the parameters.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
