# WYL0454

```
error[WYL0454]: a 'where' clause cannot bound a free function's type parameter
```

A `where` clause bounds the type parameters of the type a member belongs to. A free function has
none, and its own type parameters are bounded where they are declared.

## Example

```wyl
void show<T>(T value) where T extends copyable {
}

void main() {
}
```

## Fix

Write the bound on the type parameter, as `show<T extends copyable>(T value)`.

Spec: [Bounds](../spec/11-generics.md#generics.bounds)
