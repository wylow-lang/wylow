# WYL0006

```
error[WYL0006]: 'lu' is not a number literal suffix
```

The letters and digits directly after a number literal's digits are its suffix, and this one is not a suffix the literal can have. An integer literal takes `u`, `L`, or `uL` (in either case); a decimal one also `f` or `d`.

## Example

```wyl
void main() {
    long n = 5lu;
}
```

## Fix

Write the suffix the type needs, as in `5uL` for a `ulong`, or separate the literal from a name that follows it.

Spec: [Literals](../spec/02-lexical.md#lexical.literals)
