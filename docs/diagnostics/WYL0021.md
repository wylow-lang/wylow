# WYL0021

```
error[WYL0021]: expected ';'
```

The manifest does not have the form of a list of entries, each `key = value;` or `key { entries }`, where a value is a string or a list of strings.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop"
```

```wyl src/main.wyl
void main() { }
```

## Fix

Write what the message expects: here, end the entry with `;`.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
