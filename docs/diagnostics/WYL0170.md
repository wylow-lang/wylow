# WYL0170

```
error[WYL0170]: 'Green' has the same value as 'Red'
```

Two variants of an enum have different values.

## Example

```wyl
enum Color {
    Red = 1,
    Green = 1
}

void main() { }
```

## Fix

Give them different values.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
