# WYL0534

```
error[WYL0534]: dependencies form a cycle: 'shop' -> 'parser' -> 'shop'
```

A package must not depend on itself, directly or through other libraries. The error is reported at the entry that closes the cycle, and the message lists the packages of the cycle in order.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
kind = "library";
version = "1.0.0";

dependencies {
    parser { path = "vendor/parser"; }
}
```

```wyl src/shop.wyl
pub int orders() { return 0; }
```

```wylcfg vendor/parser/package.wylcfg
name = "parser";
kind = "library";
version = "1.0.0";

dependencies {
    shop { path = "../.."; }
}
```

```wyl vendor/parser/src/parser.wyl
pub int depth() { return 0; }
```

## Fix

Move the code that both libraries need into a third library that both depend on.

Spec: [Dependencies](../spec/03-programs.md#programs.manifest.dependencies)
