# WYL0480

```
warning[WYL0480]: function 'replace' is called without its module
```

A function that an import brings in is called by its bare name, so the call does not say which module the function comes from. Code imports types by name and calls functions through their module. This warning is named `unqualified-call`. Like every warning, it never stops a program from compiling and running.

The warning is not given for a function of the file's own module, which the file sees without an import, or for a function of a package's root module other than `std`'s, which no path can name.

## Example

```wyl
import std::replace;

void main() {
    mut int count = 1;
    replace(ref count, 2);
}
```

## Fix

Call the function through its module, as the message's help line shows, and remove the import: `std::replace(ref count, 2)`. Every file sees the package `std` as the start of a path. For a function of another module, import the module and name it in the call: `import std::threading;`, and then `threading::startThread(...)`.

Where a bare call is intended, `@SuppressWarnings("unqualified-call")` turns the warning off. On the import, it turns the warning off wherever the file uses a name that the import brings in. On a declaration, it turns the warning off inside that declaration.

Spec: [Paths](../spec/03-programs.md#programs.paths), [`@SuppressWarnings`](../spec/22-annotations.md#annotations.suppress-warnings)
