# WYL0025

```
error[WYL0025]: 'dependencies' takes a block of entries
```

Each key of the manifest takes one kind of value: `name` and `path` a string, `include` and `link` a list of strings, and `dependencies`, its entries, and `native` a block of entries.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
dependencies = "../lib";
```

```wyl src/main.wyl
void main() { }
```

## Fix

Write the value the key takes, as the message's help shows.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
