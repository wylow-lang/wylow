# WYL0199

```
error[WYL0199]: type 'Plain' takes no type arguments
```

Type arguments are written for a type that declares type parameters.

## Example

```wyl
class Plain { }

void main() {
    Plain<int> p;
}
```

## Fix

Remove the type arguments.

Spec: [Type arguments](../spec/11-generics.md#generics.arguments)
