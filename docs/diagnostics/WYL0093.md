# WYL0093

```
error[WYL0093]: variables cannot be declared at the top level
```

A file declares types, functions, and imports; a variable is declared inside a function or a type.

## Example

```wyl
int counter = 0;

void main() { }
```

## Fix

Declare the variable inside a function or type.

Spec: [Statics](../spec/06-variables.md#variables.statics)
