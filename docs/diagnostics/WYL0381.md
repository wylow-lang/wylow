# WYL0381

```
error[WYL0381]: cannot match a value of type 'Span<int>' against patterns
```

A value of a ref struct type is a view, and a switch keeps the matched value alive while its patterns bind parts of it. A ref struct cannot be matched against patterns.

## Example

```wyl
void main() {
    mut int[2] a = [1, 2];
    Span<int> s = a;
    switch (s) {
        default -> { }
    }
}
```

## Fix

Match a value that is not a view, or copy the elements into another value first.
