# WYL0124

```
error[WYL0124]: cannot override 'Shape.area'
```

Only a `virtual`, `abstract`, or `override` method is overridden.

## Example

```wyl
class Shape {
    pub int area() { return 0; }
}

class Square extends Shape {
    pub override int area() { return 1; }
}

void main() { }
```

## Fix

Declare the inherited method `virtual`.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
