# WYL0280

```
error[WYL0280]: function 'inc' is used as a value
```

A function name in a value position is converted to a function type only where one is expected.

## Example

```wyl
int inc(int x) {
    return x + 1;
}

void main() {
    var f = inc;
}
```

## Fix

Call the function, or use it only where a function type is expected.

Spec: [Names, literals, and `this`](../spec/13-expressions.md#expressions.primary)
