# WYL0525

```
error[WYL0525]: 'escaping' cannot be declared on 'extern fn() -> void'
```

`escaping` chooses between the two forms of a function type: a non-escaping function, which may
refer to the caller's locals, and an escaping one, which may be stored. An `extern fn` value is a C
function pointer and captures nothing, so it has one form, which may always be stored.

## Example

```wyl
void keep(escaping extern fn() -> void callback) { }

void main() { }
```

## Fix

Remove `escaping`:

```wyl
void keep(extern fn() -> void callback) { }

void main() { }
```

Spec: [Callbacks](../spec/21-interop.md#interop.callbacks)
