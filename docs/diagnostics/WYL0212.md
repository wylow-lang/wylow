# WYL0212

```
error[WYL0212]: struct constructor cannot give every parameter a default value
```

A struct constructor leaves at least one parameter without a default value, because `T()` is already the struct's default value.

## Example

```wyl
struct Tag {
    int id;

    Tag(int value = 1) {
        id = value;
    }
}

void main() { }
```

## Fix

Remove one default value, or add a parameter without one.

Spec: [Parameters](../spec/12-functions.md#functions.parameters)
