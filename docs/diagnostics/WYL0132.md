# WYL0132

```
error[WYL0132]: 'Shape' must be declared 'abstract'
```

A class with an abstract method, its own or inherited and not implemented, is itself abstract.

## Example

```wyl
class Shape {
    pub abstract int area();
}

void main() { }
```

## Fix

Declare the class `abstract`, or implement the method.

Spec: [Abstract and final classes](../spec/08-classes.md#classes.abstract)
