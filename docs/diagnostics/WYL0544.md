# WYL0544

```
error[WYL0544]: value 12 of constant 'CODEC_LIMIT' does not match the value of C++ 'CODEC_LIMIT'
```

An extern constant that gives its value names a C++ constant, variable, or macro, and the build
checks that the C++ value equals the declared one. A pattern that names the constant matches the
declared value, and a read of the constant gives the C++ value. The check keeps the two equal, so
the build fails at the declaration when the header gives another value.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "codec";
```

```cpp native/codec.h
#pragma once
#define CODEC_LIMIT 10
```

```wyl src/main.wyl
@Include("codec.h")
extern {
    static int CODEC_LIMIT = 12;
}

void main() { }
```

## Fix

Give the value that the header gives: `static int CODEC_LIMIT = 10;`.

Spec: [Extern constants](../spec/21-interop.md#interop.extern.constants)
