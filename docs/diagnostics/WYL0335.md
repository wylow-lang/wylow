# WYL0335

```
error[WYL0335]: error type of 'try': expected 'String', found 'int'
```

The operand of `try` has a different error type from the enclosing function's `Result`.

## Example

```wyl
Result<int, int> read() {
    return Result.Ok(1);
}

Result<int, String> parse() {
    return Result.Ok(try read());
}

void main() { }
```

## Fix

Convert the error first.

Spec: [`try`](../spec/13-expressions.md#expressions.try)
