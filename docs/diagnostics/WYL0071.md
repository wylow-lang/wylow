# WYL0071

```
error[WYL0071]: elements of the array have incompatible types 'int', 'bool'
```

The elements of an array literal must all have one type.

## Example

```wyl
void main() {
    var mixed = [1, true];
}
```

## Fix

Make the elements the same type.

Spec: [Fixed arrays](../spec/04-types.md#types.fixed-arrays)
