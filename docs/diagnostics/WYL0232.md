# WYL0232

```
error[WYL0232]: function 'add(int)' is already defined
```

Two functions of one name cannot have the same parameter types; their return types do not distinguish them.

## Example

```wyl
void add(int x) { }

void add(int x) { }

void main() { }
```

## Fix

Change one signature's parameter types, or rename one function.

Spec: [Overloading](../spec/12-functions.md#functions.overloading)
