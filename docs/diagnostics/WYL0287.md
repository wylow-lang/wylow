# WYL0287

```
error[WYL0287]: class 'Order' cannot be created without 'new'
```

A class value is a reference. A reference is created with `new` and a constructor call.

## Example

```wyl
class Order { }

void main() {
    var o = Order();
}
```

## Fix

Write `new Order(...)`.

Spec: [Construction](../spec/13-expressions.md#expressions.construction)
