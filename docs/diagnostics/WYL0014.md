# WYL0014

```
error[WYL0014]: '\q' is not an escape sequence
```

A `\` in a character or string literal starts an escape, and only these exist: `\n`, `\t`, `\r`, `\0`, `\\`, `\"`, `\'`, and `\u{...}`. A brace in an interpolated string is written `{{` or `}}`, not `\{`.

## Example

```wyl
void main() {
    String s = "\q";
}
```

## Fix

Write `\\` for a backslash, or use one of the escapes above.
