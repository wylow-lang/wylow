# WYL0295

```
error[WYL0295]: fields of a variant can only be read with a pattern
```

A variant's fields exist only while the value is that variant. A pattern establishes which variant a value is.

## Example

```wyl
enum Named { Label(String text) }

void main() {
    var label = Named.Label("a");
    var text = label.text;
}
```

## Fix

Match the variant with `is` or a `case`, and bind the fields there.

Spec: [Member access](../spec/13-expressions.md#expressions.members)
