# WYL0476

```
error[WYL0476]: shared lambda cannot capture 'view'
```

A `Span<T>` lets its holder change the elements it views, and another thread reads what a
non-escaping shared lambda captured while the lambda runs
([Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)). A shared lambda may
capture a `ReadOnlySpan<T>` instead, which allows no change.

## Example

```wyl
void run(shared fn() -> int f) { }

void read(Span<int> view) {
    run(() -> view[0]);
}

void main() { }
```

## Fix

Capture a `ReadOnlySpan<T>` of the same elements.

Spec: [Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)
