# WYL0077

```
error[WYL0077]: function type cannot return 'Span<int>'
```

A function type cannot return a view such as a `Span`: there is nothing it could view once the call has returned.

## Example

```wyl
void run(fn() -> Span<int> f) { }

void main() { }
```

## Fix

Return a type that owns its elements.

Spec: [Function types](../spec/04-types.md#types.functions)
