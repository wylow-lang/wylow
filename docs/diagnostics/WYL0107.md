# WYL0107

```
error[WYL0107]: struct 'Grow' has field types that nest without end
```

The field types of the struct contain a bigger instance of the same generic struct, again and again, so no value could be stored.

## Example

```wyl
struct Pair<A, B> {
    pub A first;
    pub B second;
}

struct Grow<T> {
    pub Grow<Pair<T, T>> next;
}

void main() { }
```

## Fix

Hold the nested value in a class, or stop the nesting.

Spec: [Recursive structs](../spec/07-structs.md#structs.recursive)
