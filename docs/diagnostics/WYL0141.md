# WYL0141

```
error[WYL0141]: constructor 'Box(int)' calls itself through 'this(...)'
```

Constructors that call each other through `this(...)` never reach a body that makes the object.

## Example

```wyl
class Box {
    pub Box(int size) {
        this(size);
    }
}

void main() { }
```

## Fix

Break the chain: one constructor does the work, and the others call it.
