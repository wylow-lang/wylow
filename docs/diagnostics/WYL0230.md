# WYL0230

```
error[WYL0230]: argument 'a' must come before 'b'
```

Named arguments follow the order in which the parameters are declared.

## Example

```wyl
void f(int a, int b) { }

void main() {
    f(b: 2, a: 1);
}
```

## Fix

Write the named arguments in the order of the parameters.

Spec: [Default values and named arguments](../spec/12-functions.md#functions.arguments)
