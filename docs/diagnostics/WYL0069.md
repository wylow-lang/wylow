# WYL0069

```
error[WYL0069]: array element cannot be a 'void' value
```

The elements of an array literal are values. A call to a function that returns nothing has none.

## Example

```wyl
void nothing() { }

void main() {
    var blank = [nothing()];
}
```

## Fix

Call the function in a statement of its own, and put a value in the array.

Spec: [Fixed arrays](../spec/04-types.md#types.fixed-arrays)
