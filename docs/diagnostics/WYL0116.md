# WYL0116

```
error[WYL0116]: cannot extend final class 'Shape'
```

A class declared `final` has no subclasses.

## Example

```wyl
final class Shape { }

class Square extends Shape { }

void main() { }
```

## Fix

Remove `final` from the base class, or do not extend it.

Spec: [Inheritance](../spec/08-classes.md#classes.inheritance)
