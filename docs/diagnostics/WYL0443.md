# WYL0443

```
error[WYL0443]: cannot move 'a' while it is passed by 'in'
```

A unique value passed by `ref` or `in` is referred to where it is. Moving it in another operand of the same call would leave that reference pointing at a value that holds nothing.

## Example

```wyl
unique struct Counter {
    pub int value;
}

void choose(in Counter counter, Counter moved) { }

void main() {
    var a = Counter(1);
    choose(a, a);
}
```

## Fix

Move the value in a separate call, or pass a copyable part of it.

Spec: [Moves](../spec/17-memory.md#memory.moves)
