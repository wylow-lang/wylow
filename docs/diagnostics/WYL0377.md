# WYL0377

```
error[WYL0377]: cannot find variant 'Blue' in enum 'Color'
```

An unqualified name in a pattern over an enum names one of that enum's variants.

## Example

```wyl
enum Color { Red, Green }
void main() {
    Color c = Color.Red;
    switch (c) {
        case Blue -> { }
        default -> { }
    }
}
```

## Fix

Use a variant of the enum, or qualify the name with the enum that declares it.

Spec: [Kinds of patterns](../spec/15-patterns.md#patterns.kinds)
