# WYL0001

```
error[WYL0001]: expected an expression
```

The parser reached a token that the grammar doesn't allow there. The message names what the grammar
allows, here an expression after the `=`.

## Example

```wyl
void main() {
    int x = ;
}
```

## Fix

Write what the message asks for at that place, or remove what is left over from an earlier edit.
