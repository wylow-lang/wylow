# WYL0308

```
error[WYL0308]: operator '+' cannot be applied to 'int' and 'float'
```

A binary operator requires operands of the types it is defined for. `+` applies to two operands of the same numeric type.

## Example

```wyl
void main() {
    int i = 1;
    float f = 1.5;
    var x = i + f;
}
```

## Fix

Convert one operand to the other's type with an explicit cast.

Spec: [Operand and result types](../spec/13-expressions.md#expressions.arithmetic.operands)
