# WYL0219

```
error[WYL0219]: 'ref' parameter 'x' cannot have a default value
```

A `ref` parameter has no default value, because a `ref` argument is a variable.

## Example

```wyl
void byRef(ref int x = 1) { }

void main() { }
```

## Fix

Remove the default value and pass an argument at each call.
