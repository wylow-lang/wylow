# WYL0260

```
error[WYL0260]: lambda has no function type to take
```

A lambda takes its function type from the place where it is used.

## Example

```wyl
void main() {
    var a = x -> x;
}
```

## Fix

Use the lambda where a function type is expected.

Spec: [Typing lambdas](../spec/12-functions.md#functions.lambdas.typing)
