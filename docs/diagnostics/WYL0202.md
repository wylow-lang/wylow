# WYL0202

```
error[WYL0202]: cannot infer type argument 'T' of 'same' from a 'void' value
```

The type argument would be the type of a call that returns nothing, which is not a type.

## Example

```wyl
void log(int x) { }

void same<T>(T a, T b) { }

void main() {
    same(log(1), log(2));
}
```

## Fix

Pass values that have a type.

Spec: [Inferring type arguments](../spec/11-generics.md#generics.arguments.inference)
