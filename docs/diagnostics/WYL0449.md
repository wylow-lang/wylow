# WYL0449

```
error[WYL0449]: receiver type: expected 'Box<T>', found 'Box<int>'
```

A method's receiver has the type that declares it, with that type's own type parameters as its
type arguments.

## Example

```wyl
struct Box<T> {
    T value;

    void copy(this Box<int> other) {
    }
}

void main() { }
```

## Fix

Write the declaring type's own name and type parameters.

Spec: [By-value receivers](../spec/07-structs.md#structs.methods.by-value)
