# WYL0181

```
error[WYL0181]: interface methods cannot have type parameters
```

A method of an interface has no type parameters.

## Example

```wyl
interface Visitor {
    void visit<T>(T value);
}

void main() { }
```

## Fix

Make the interface generic: `interface Visitor<T> { void visit(T value); }`.

Spec: [Interface declarations](../spec/10-interfaces.md#interfaces.declarations)
