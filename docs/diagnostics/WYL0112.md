# WYL0112

```
error[WYL0112]: 'super' can only be used in instance methods and constructors of a class
```

`super` refers to the base class part of an object, so it is used where there is an object: in an instance method or a constructor.

## Example

```wyl
class Shape {
    pub virtual int area() { return 0; }
}

class Square extends Shape {
    pub static int make() { return super.area(); }
}

void main() { }
```

## Fix

Use `super` in an instance method, or call the method on an object.

Spec: [Inheritance](../spec/08-classes.md#classes.inheritance)
