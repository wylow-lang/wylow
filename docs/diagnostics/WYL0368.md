# WYL0368

```
error[WYL0368]: cannot switch on 'null'
```

`null` has no type of its own, so no case can describe the values it matches.

## Example

```wyl
void main() {
    switch (null) {
        default -> { }
    }
}
```

## Fix

Switch on a value of a known type, and test for null with `case null`.

Spec: [Switch statements](../spec/14-statements.md#statements.switch)
