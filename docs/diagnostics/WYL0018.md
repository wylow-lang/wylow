# WYL0018

```
error[WYL0018]: conditional expression in an interpolated string is not parenthesized
```

In a hole, a `:` outside brackets starts the format specifier, so a conditional expression's `:` would end the value.

## Example

```wyl
void main() {
    bool ok = true;
    std::print($"{ok ? 1 : 2}");
}
```

## Fix

Put the conditional in parentheses: `$"{(ok ? 1 : 2)}"`.

Spec: [Interpolated strings](../spec/02-lexical.md#lexical.literals.interpolated)
