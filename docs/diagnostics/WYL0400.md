# WYL0400

```
error[WYL0400]: 'this' cannot be used until every field is assigned
```

Until every field that needs a value is assigned, `this` may be used only to assign a field and to
read a field that is assigned.

## Example

```wyl
class Node { }

class Link {
    Node next;

    Link() {
        use(this);
        next = new Node();
    }
}

void use(Link link) { }

void main() { }
```

## Fix

Assign the fields that need a value before `this` is used for anything else.

Spec: [Fields in constructors](../spec/16-flow.md#flow.constructors)
