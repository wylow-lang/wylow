# WYL0046

```
error[WYL0046]: module 'std' is not imported here
```

A path in code starts with a module the file sees: a submodule of its own module, or a module it imports or its module re-exports. A module directly in `src/` and the package `std` are not among them unless imported.

## Example

```wyl
void main() {
    std::memory::collectCycles();
}
```

## Fix

Import the module the path starts with: `import std::memory;` and then `memory::collectCycles();`.

Spec: [Paths](../spec/03-programs.md#programs.paths)
