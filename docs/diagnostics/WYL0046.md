# WYL0046

```
error[WYL0046]: module 'orders' is not imported here
```

A path in code starts with a module the file sees: a submodule of the file's own module, a module the file imports, a module that the file's module re-exports, or the package `std`. A module directly in `src/` is not among them unless the file imports it. A file in the root module sees each module directly in `src/` as a submodule, so this error occurs in a file of another module.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

```wyl src/main.wyl
void main() { }
```

```wyl src/orders/order.wyl
package int count() { return 0; }
```

```wyl src/reports/report.wyl
package int total() {
    return orders::count();
}
```

## Fix

Import the module that the path starts with: `import orders;`, and then `orders::count()`.

Spec: [Paths](../spec/03-programs.md#programs.paths)
