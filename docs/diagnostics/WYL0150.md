# WYL0150

```
error[WYL0150]: enums cannot extend a type
```

An enum has no base type. It can implement interfaces, which is written with `implements`.

## Example

```wyl
class Base { }

enum Color extends Base { Red, Green }

void main() { }
```

## Fix

Remove `extends`. To use an interface, write `implements` and its name.

Spec: [Enum declarations](../spec/09-enums.md#enums.declarations)
