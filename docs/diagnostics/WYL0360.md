# WYL0360

```
error[WYL0360]: values of a range cannot be borrowed with 'ref'
```

A range produces values, not places, so they cannot be borrowed.

## Example

```wyl
void main() {
    for (ref int v : 0..2) { }
}
```

## Fix

Loop without `ref` or `in`.

Spec: [Ranges](../spec/14-statements.md#statements.for-each.ranges)
