# WYL0216

```
error[WYL0216]: default value must be a constant or a struct constructor call
```

A default value is a constant expression or a struct constructor call with constant arguments.

## Example

```wyl
int compute() {
    return 1;
}

void notConstant(int x = compute()) { }

void main() { }
```

## Fix

Use a constant or a struct constructor call.

Spec: [Parameters](../spec/12-functions.md#functions.parameters)
