# WYL0362

```
error[WYL0362]: range variable type: expected an integer type, found 'float'
```

The loop variable of a range has an integer type.

## Example

```wyl
void main() {
    for (float f : 0..2) { }
}
```

## Fix

Declare the loop variable with an integer type.

Spec: [Ranges](../spec/14-statements.md#statements.for-each.ranges)
