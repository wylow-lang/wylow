# WYL0026

```
error[WYL0026]: manifest does not give the package's 'name'
```

A manifest gives the package's name, which is how messages name the package.

## Example

A package, file by file:

```wylcfg package.wylcfg
// shop's manifest
```

```wyl src/main.wyl
void main() { }
```

## Fix

Add a `name` entry: `name = "shop";`.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
