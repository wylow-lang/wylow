# WYL0004

```
error[WYL0004]: 'const' is a reserved word and cannot be used
```

A reserved word has no meaning, and a program may not use it, as a name or otherwise: `const`, `defer`, `discard`, `package` (except in `pub(package)`), `private`, `protected`, `public`, `shared`, and `unique`.

## Example

```wyl
void main() {
    const int limit = 10;
}
```

## Fix

Leave the word out (`int limit = 10;`), or choose another name.

Spec: [Keywords](../spec/02-lexical.md#lexical.keywords)
