# WYL0322

```
error[WYL0322]: cases of a switch expression cannot be blocks
```

A case of a switch expression is an expression that produces the expression's value. A block is a statement.

## Example

```wyl
import std::print;

void main() {
    int n = 1;
    var x = switch (n) {
        case 1 -> { print(1); }
        default -> 2;
    };
}
```

## Fix

Use a switch statement, or write an expression in the case.

Spec: [Switch expressions](../spec/13-expressions.md#expressions.switch)
