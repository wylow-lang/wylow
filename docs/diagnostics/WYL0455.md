# WYL0455

```
error[WYL0455]: 'B' is not a type parameter of 'Pair'
```

A `where` clause names a type parameter of the type the member belongs to.

## Example

```wyl
struct Pair<A> {
    A first;

    A copy() where B extends copyable {
        return first;
    }
}

void main() {
}
```

## Fix

Name one of the type's parameters, or put the bound on a type parameter of the member where it is
declared.

Spec: [Bounds](../spec/11-generics.md#generics.bounds)
