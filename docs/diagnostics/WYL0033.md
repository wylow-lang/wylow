# WYL0033

```
error[WYL0033]: top-level module cannot be named 'std'
```

An import's first name is a module directly in `src/` or the package `std`, so no module directly in `src/` is named `std`.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

```wyl src/main.wyl
void main() { }
```

```wyl src/std/text.wyl
pub struct Text { }
```

## Fix

Rename the directory.

Spec: [Modules](../spec/03-programs.md#programs.modules)
