# WYL0256

```
error[WYL0256]: 'operator []=' has no matching 'operator [](long)'
```

Each `operator []=` pairs with an `operator []` whose index parameters have the same types and modes.

## Example

```wyl
struct Shapes {
    int operator [](int i) {
        return 0;
    }

    mut void operator []=(long i, int value) { }
}

void main() { }
```

## Fix

Declare the matching `operator []`, or change the indices.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
