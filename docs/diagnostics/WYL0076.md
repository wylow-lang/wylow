# WYL0076

```
error[WYL0076]: expected '(' after 'fn'
```

The parameters of a function type are always in parentheses, even when there are none.

## Example

```wyl
void run(fn -> void f) { }

void main() { }
```

## Fix

Write `fn() -> void`.

Spec: [Function types](../spec/04-types.md#types.functions)
