# WYL0043

```
error[WYL0043]: cannot find 'Nothing' in the root module of 'std'
```

The name an import brings in is a name of the module before it: a declaration visible beyond its file, a submodule, or a re-export.

## Example

```wyl
import std::Nothing;

void main() { }
```

## Fix

Correct the name, or the module it is looked for in.

Spec: [Imports](../spec/03-programs.md#programs.imports)
