# WYL0412

```
error[WYL0412]: 'value' might refer to nothing
```

A `ref?` or `in?` reference is used as a place or a value where it might refer to nothing.

## Example

```wyl
import std::print;

void main() {
    ref? int value = null;
    print(value + 1);
}
```

## Fix

Check it with `if (value != null)`, test it with `is ref`, or use `!`.

Spec: [Nullable references](../spec/17-memory.md#memory.nullable-references)
