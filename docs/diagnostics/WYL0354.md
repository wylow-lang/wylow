# WYL0354

```
error[WYL0354]: loop variable cannot be 'ref?'
```

The loop variable of a for-each loop refers to an element that always exists, so it cannot be nullable.

## Example

```wyl
struct Vec {
    int x;
}

void main() {
    mut Vec[1] vecs = [Vec(x: 1)];
    for (ref? Vec each : vecs) { }
}
```

## Fix

Write `ref` instead of `ref?`.

Spec: [For-each](../spec/14-statements.md#statements.for-each)
