# WYL0184

```
error[WYL0184]: interface 'Named' is listed more than once
```

A class or struct lists each interface once.

## Example

```wyl
interface Named {
    String name();
}

class Box implements Named, Named {
    String name() { return "b"; }
}

void main() { }
```

## Fix

Remove the second.

Spec: [Implementing an interface](../spec/10-interfaces.md#interfaces.implementing)
