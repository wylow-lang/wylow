# WYL0343

```
error[WYL0343]: only calls can be used as statements
```

An expression statement is a call; another expression that produces a value has no effect.

## Example

```wyl
void main() {
    1 + 1;
}
```

## Fix

Remove the expression, or use its value in an assignment or a declaration.

Spec: [Expression statements](../spec/14-statements.md#statements.expressions)
