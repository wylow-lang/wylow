# WYL0277

```
error[WYL0277]: function 'inc' can only be used as a value where a function type is expected
```

A function or static method is used as a value only where a function type is expected.

## Example

```wyl
int inc(int x) {
    return x + 1;
}

void main() {
    var chosen = true ? inc : inc;
}
```

## Fix

Use the function where a function type is expected, or write a lambda that calls it.

Spec: [Function references](../spec/12-functions.md#functions.references)
