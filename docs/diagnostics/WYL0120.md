# WYL0120

```
error[WYL0120]: 'area()' must be marked 'override'
```

A method with the signature of an inherited `virtual` or `abstract` method that the class sees overrides it, and says so.

## Example

```wyl
class Shape {
    pub virtual int area() { return 0; }
}

class Square extends Shape {
    pub int area() { return 1; }
}

void main() { }
```

## Fix

Write `override` before the return type.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
