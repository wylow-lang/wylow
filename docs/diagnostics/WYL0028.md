# WYL0028

```
error[WYL0028]: package name 'std' is reserved for the standard library
```

`std` is the standard library's package, which every program is compiled with.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "std";
```

```wyl src/main.wyl
void main() { }
```

## Fix

Choose another name.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
