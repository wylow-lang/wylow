# WYL0493

```
error[WYL0493]: 'Plain' is not an unsafe interface
```

The word `unsafe` before an interface in an `implements` list marks a promise that an unsafe
interface asks for. An interface that is not declared `unsafe` asks for no such promise, so the
word marks nothing there.

## Example

```wyl
interface Plain {
    void run();
}

class Extra implements unsafe Plain {
    void run() { }
}

void main() { }
```

## Fix

Remove `unsafe` before the interface's name.

Spec: [Unsafe interfaces](../spec/10-interfaces.md#interfaces.unsafe)
