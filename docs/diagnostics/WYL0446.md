# WYL0446

```
error[WYL0446]: 'this' parameter must come first
```

A method's receiver is its first parameter.

## Example

```wyl
struct Counter {
    int value;

    int read(int extra, this Counter counter) {
        return extra;
    }
}

void main() { }
```

## Fix

Move the receiver to the start of the parameter list.

Spec: [Parameters](../spec/12-functions.md#functions.parameters)
