# WYL0208

```
error[WYL0208]: 'int' does not implement 'Named'
```

A type argument implements every interface of its type parameter's bounds.

## Example

```wyl
interface Named {
    String name();
}

void show<T extends Named>(T value) { }

void main() {
    show(1);
}
```

## Fix

Pass a type that implements the interface, or implement it.

Spec: [Bounds](../spec/11-generics.md#generics.bounds)
