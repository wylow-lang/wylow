# WYL0183

```
error[WYL0183]: cannot implement 'Shape', which is not an interface
```

Only an interface is implemented. A class is extended.

## Example

```wyl
class Shape { }

class Square implements Shape { }

void main() { }
```

## Fix

Use `extends` for a class.

Spec: [Implementing an interface](../spec/10-interfaces.md#interfaces.implementing)
