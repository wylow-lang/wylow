# WYL0427

```
error[WYL0427]: only the standard library can declare a struct backed by a C++ class
```

A struct in an extern block that has a body and no fields is a value type that a C++ class
implements. Only the standard library declares such a struct, such as `String`.

## Example

```wyl
@Include("parser.h")
extern {
    struct Parser { }
}

void main() { }
```

## Fix

Declare the fields of the C++ struct, which the compiler checks against the C++ type. If the program
uses the type only through pointers, write `;` in place of the body to declare the struct opaque.

Spec: [Structs backed by a C++ class](../spec/21-interop.md#interop.extern.extern-structs)
