# WYL0427

```
error[WYL0427]: extern structs can only be declared in the standard library
```

An `extern struct` is a value type backed by a C++ class. Only the standard library declares one.

## Example

```wyl
extern struct Parser { }

void main() { }
```

## Fix

Declare the type in the standard library, or declare a struct in an extern block, whose fields are
checked against the C++ type.

Spec: [Extern structs](../spec/21-interop.md#interop.extern.extern-structs)
