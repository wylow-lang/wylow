# WYL0548

```
error[WYL0548]: non-escaping field 'second' can only be assigned a parameter of the constructor
```

A non-escaping function field of a `ref struct` refers to a function that the struct's creator
keeps alive. The constructor's caller passes the function as an argument and keeps it alive, so a
constructor assigns the field only from one of its own parameters. A function that the constructor
makes itself is gone when the constructor returns.

## Example

```wyl
ref struct Pair {
    fn(int) -> int first;
    fn(int) -> int second;

    Pair(fn(int) -> int first) {
        fn(int) -> int same = (value) -> value;
        this.first = first;
        this.second = same;
    }
}

void main() { }
```

## Fix

Take the function as a parameter of the constructor, and assign the field from that parameter.

Spec: [`ref struct`s](../spec/07-structs.md#structs.ref)
