# WYL0514

```
error[WYL0514]: '&' can only be used in 'unsafe' code
```

`&place` makes a pointer to a place. The compiler does not check how long the place stays alive
or what the pointer is used for, so taking an address is an unsafe operation.

## Example

```wyl
void main() {
    mut int count = 0;
    int* p = &count;
}
```

## Fix

Take the address in an `unsafe` block or an unsafe function. To let a function change a variable,
pass the variable by `ref` instead, which needs no unsafe code.

Spec: [Pointers](../spec/20-unsafe.md#unsafe.pointers)
