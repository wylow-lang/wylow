# WYL0310

```
error[WYL0310]: operator '==' cannot be applied to 'Callback'
```

A struct value is equal only when every field's type supports `==`. A function type does not.

## Example

```wyl
struct Callback {
    (fn() -> int)? run;
}

void main() {
    var a = Callback(null);
    var b = Callback(null);
    std::print(a == b);
}
```

## Fix

Compare the fields that support `==` individually.

Spec: [Comparison and equality](../spec/13-expressions.md#expressions.comparison)
