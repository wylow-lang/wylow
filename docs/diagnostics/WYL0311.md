# WYL0311

```
error[WYL0311]: operator '==' cannot be applied to 'Weak<Node>' and 'Weak<Node>'
```

Equality applies to a type that supports `==`, and `Weak<T>` does not.

## Example

```wyl
import std::{Weak, print};

class Node { }

void main() {
    var n = new Node();
    Weak<Node> w = n;
    print(w == w);
}
```

## Fix

Compare the values the type provides, such as the result of `get()`.

Spec: [Comparison and equality](../spec/13-expressions.md#expressions.comparison)
