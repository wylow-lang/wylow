# WYL0119

```
error[WYL0119]: 'final' can only be used on an 'override' method
```

`final` on a method stops further overriding, so it applies to a method that overrides.

## Example

```wyl
class Shape {
    pub final int area() { return 0; }
}

void main() { }
```

## Fix

Remove `final`, or make the method an `override`.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
