# WYL0010

```
error[WYL0010]: character literal is empty
```

A character literal holds exactly one character or escape.

## Example

```wyl
void main() {
    char c = '';
}
```

## Fix

Write the character, or use an empty string literal `""` if a string is meant.

Spec: [Character literals](../spec/02-lexical.md#lexical.literals.char)
