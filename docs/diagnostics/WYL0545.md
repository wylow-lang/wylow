# WYL0545

```
error[WYL0545]: cannot find header 'codec.h' in package 'codec'
note: searched 'native/'
help: write '@Include("<codec.h>")' if it is a system header
```

An extern block's `@Include("path")` names a header of the block's own package. The compiler
searches for the path in the package's `native/` directory, and then in each directory of the
`include` list of the package's manifest. The compiler reports this error if none of those
directories holds the header. The notes name each directory that the compiler searched. The
compiler does not search another package of the program, so a header of a library is not found
from the program that depends on the library. A source file compiled on its own has no `native/`
directory, so the compiler finds no header that the file names in quotes.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "codec";
```

```wyl src/main.wyl
@Include("codec.h")
extern {
    static int CODEC_LEVEL;
}

void main() { }
```

## Fix

Put the header in the package's `native/` directory, or add the directory that holds it to the
`include` list of the package's `native` block. If the header belongs to a library that the
operating system installs, write the path in angle brackets, as in `@Include("<codec.h>")`, and the
C++ compiler searches its own directories for it. If the header belongs to another package, call
the functions that the other package declares instead.
