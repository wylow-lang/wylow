# WYL0257

```
error[WYL0257]: value of 'operator []=': expected 'int', found 'long'
```

The value parameter of `operator []=` has the element type of its matching `operator []`.

## Example

```wyl
struct Shapes {
    int operator [](int i) {
        return 0;
    }

    mut void operator []=(int i, long value) { }
}

void main() { }
```

## Fix

Change the value parameter's type to the element type.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
