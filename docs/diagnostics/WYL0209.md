# WYL0209

```
error[WYL0209]: 'static' cannot be used on a function
```

A function is declared with only `unsafe` or `extern` among modifiers; `static` marks a method of a type.

## Example

```wyl
static void g() { }

void main() { }
```

## Fix

Remove `static`, or declare the function as a method inside a type.

Spec: [Function declarations](../spec/12-functions.md#functions.declarations)
