# WYL0456

```
error[WYL0456]: 'Buffer' is not 'copyable'
```

A member's `where` clause is checked for the type arguments the member is called with.

## Example

```wyl
unique struct Buffer {
    pub int length;
}

void main() {
    var buffer = Buffer(2);
    var array = new Array<Buffer>(2, buffer);
}
```

## Fix

Call the member with a type that satisfies its clause, or use the overload or form that does not
require it.

Spec: [Bounds](../spec/11-generics.md#generics.bounds)
