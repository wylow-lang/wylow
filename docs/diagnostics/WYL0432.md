# WYL0432

```
error[WYL0432]: '@Acyclic' can only be used on classes
```

Each annotation applies to the declarations the specification names for it. `@Acyclic` marks a
class, since it is a class whose objects the cycle collector buffers.

## Example

```wyl
@Acyclic
struct Point {
    int x;
}

void main() { }
```

## Fix

Move the annotation to a class, or remove it.

Spec: [The annotations](../spec/22-annotations.md#annotations.list)
