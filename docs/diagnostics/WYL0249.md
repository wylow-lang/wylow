# WYL0249

```
error[WYL0249]: cannot assign an element of 'Grid'
```

An element whose `operator []` returns a value or `in` is assignable only through a matching `operator []=`.

## Example

```wyl
struct Grid {
    int[4] cells;

    int operator [](int i) {
        return cells[i];
    }

    int operator [](String key) {
        return 0;
    }

    mut void operator []=(int i, int value) {
        cells[i] = value;
    }
}

void main() {
    mut Grid g = Grid();
    g["key"] = 1;
}
```

## Fix

Declare `operator []=` for the element's index types.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
