# WYL0127

```
error[WYL0127]: 'area' cannot be 'unsafe'
```

A call through the base class needs no `unsafe` code, so no override can require it.

## Example

```wyl
class Shape {
    pub virtual int area() { return 0; }
}

class Square extends Shape {
    pub override unsafe int area() { return 1; }
}

void main() { }
```

## Fix

Remove `unsafe`, and put the unsafe code of the body in an `unsafe` block.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
