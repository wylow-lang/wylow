# WYL0418

```
error[WYL0418]: 'Span<int>' cannot be the type of a field
```

A `ref struct` may be only a local variable or a parameter. It cannot be a field, a variant field,
an array element, or a type argument. A pointer may point to a `ref struct`.

## Example

```wyl
struct Holder {
    Span<int> view;
}

void main() { }
```

## Fix

Keep the view in a local or a parameter, and store what it views instead.

Spec: [Second-class values](../spec/17-memory.md#memory.second-class)
