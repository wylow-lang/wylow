# WYL0110

```
error[WYL0110]: field 'size' is already defined in base class 'Shape'
```

A field has the name of a field of a base class that the class can see, which would hide it.

## Example

```wyl
class Shape {
    pub int size;
}

class Square extends Shape {
    pub int size;
}

void main() { }
```

## Fix

Rename the field, or use the inherited one.

Spec: [Fields](../spec/08-classes.md#classes.fields)
