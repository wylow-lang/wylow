# WYL0296

```
error[WYL0296]: cannot find member 'first' in 'int'
```

A member access names a field or method that the value's type declares.

## Example

```wyl
struct Wrap<T> {
    T value;
}

void main() {
    var w = Wrap<int>(1);
    var x = w.value.first;
}
```

## Fix

Use a member that the type declares, or correct the expression before the access.

Spec: [Member access](../spec/13-expressions.md#expressions.members)
