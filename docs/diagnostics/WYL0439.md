# WYL0439

```
error[WYL0439]: struct 'Holder' has a field of unique type 'Buffer'
```

A value type that holds a unique value is itself unique, since a copy of it would copy that value. A struct or enum with such a field must say so with `unique`; only a class may hold one without, since its copies share the object.

## Example

```wyl
unique struct Buffer {
    pub int length;
}

struct Holder {
    pub Buffer buffer;
}

void main() { }
```

## Fix

Declare the type `unique`, or hold the value in a class.

Spec: [Unique structs](../spec/07-structs.md#structs.unique)
