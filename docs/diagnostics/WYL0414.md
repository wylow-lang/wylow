# WYL0414

```
error[WYL0414]: variable of type 'Span<int>' must be initialized where it is declared
```

A second-class value views storage that must be known where it is declared, and it cannot be
assigned again.

## Example

```wyl
void main() {
    Span<int> view;
}
```

## Fix

Initialize the variable where it is declared.

Spec: [Second-class values](../spec/17-memory.md#memory.second-class)
