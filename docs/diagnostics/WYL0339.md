# WYL0339

```
error[WYL0339]: cannot find format specifier 'Q'
```

A format specifier is one of the letters the format supports: `D`, `X`, and `B` for integers, and `F` and `E` for floating point.

## Example

```wyl
import std::print;

void main() {
    int x = 1;
    print($"{x:Q}");
}
```

## Fix

Use `D`, `X`, or `B` for an integer, or `F` or `E` for a floating-point value.

Spec: [Format specifiers and alignment](../spec/13-expressions.md#expressions.interpolation.format)
