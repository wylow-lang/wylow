# WYL0404

```
error[WYL0404]: fields cannot be references
```

A field cannot be a reference. Only a method returns a reference, and only into its receiver.

## Example

```wyl
struct Buffer {
    ref int first;
}

void main() { }
```

## Fix

Make the reference a local or a parameter, or return it from a method.
