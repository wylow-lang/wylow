# WYL0520

```
error[WYL0520]: cannot index a 'void*', which does not say what type it points to
```

A `void*` points to storage of any type. Indexing a pointer reads or writes an element, and adding
an integer to a pointer moves it by a number of elements. Both operations need the element's type,
and a `void*` does not give one. The compiler reports this error in unsafe code as well as in safe
code.

## Example

```wyl
void main() {
    mut int count = 3;
    unsafe {
        void* any = &count;
        std::print(any[0]);
    }
}
```

## Fix

Cast the `void*` to a pointer to the type of the storage it points to, in unsafe code, and index
the result:

```wyl
void main() {
    mut int count = 3;
    unsafe {
        void* any = &count;
        int* p = (int*) any;
        std::print(p[0]);
    }
}
```
