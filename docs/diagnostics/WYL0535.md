# WYL0535

```
error[WYL0535]: another package of the program is named 'parser'
```

A name means one package in a whole program, so a panic location or a message that names a package names exactly one directory. Two directories that hold packages of the same name are an error, even when different packages depend on them. Two paths that reach the same directory name the same package, and are not an error.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    parser { path = "vendor/parser"; }
    format { path = "vendor/format"; }
}
```

```wyl src/main.wyl
void main() { }
```

```wylcfg vendor/parser/package.wylcfg
name = "parser";
kind = "library";
version = "1.0.0";
```

```wyl vendor/parser/src/parser.wyl
pub int depth() { return 0; }
```

```wylcfg vendor/format/package.wylcfg
name = "format";
kind = "library";
version = "1.0.0";

dependencies {
    parser { path = "parser"; }
}
```

```wyl vendor/format/src/format.wyl
pub int width() { return 0; }
```

```wylcfg vendor/format/parser/package.wylcfg
name = "parser";
kind = "library";
version = "1.0.0";
```

```wyl vendor/format/parser/src/parser.wyl
pub int depth() { return 0; }
```

## Fix

Make every package of the program use one copy of the library, by giving each entry a path to the same directory.

Spec: [Dependencies](../spec/03-programs.md#programs.manifest.dependencies)
