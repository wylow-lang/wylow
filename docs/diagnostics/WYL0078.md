# WYL0078

```
error[WYL0078]: cannot fill a new array with default values of 'Enemy'
```

`new T[n]` fills the array with the default value of `T`, and a class has none.

## Example

```wyl
class Enemy {
    int health;
}

void main() {
    Enemy[] squad = new Enemy[3];
}
```

## Fix

Write `new Array<Enemy>(length, value)` to give every element a value.

Spec: [Default values](../spec/04-types.md#types.defaults)
