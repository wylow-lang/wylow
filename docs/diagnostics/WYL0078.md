# WYL0078

```
error[WYL0078]: cannot fill a new array with default values of 'Order'
```

`new T[n]` fills the array with the default value of `T`, and a class has none.

## Example

```wyl
class Order {
    int id;
}

void main() {
    Order[] orders = new Order[3];
}
```

## Fix

Write `new Array<Order>(length, value)` to give every element a value.

Spec: [Default values](../spec/04-types.md#types.defaults)
