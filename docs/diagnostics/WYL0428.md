# WYL0428

The compiler no longer emits this code, and no other diagnostic will take it.

The code reported a field declared in an extern struct. A struct with fields in an extern block is
now the C++ struct of its name, so a C++ class never backs a struct that has fields
([decision 0085](../design/decisions/0085-c-structs-unions-and-enums.md)).

Spec: [Structs and unions](../spec/21-interop.md#interop.extern.c-structs)
