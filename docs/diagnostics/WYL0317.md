# WYL0317

```
error[WYL0317]: '?.' would call 'mut' method 'move' on a copy of 'v'
```

`?.` copies a nullable value before the member access, so a `mut` method would change the copy.

## Example

```wyl
struct Vec {
    int x;

    mut void move(int by) {
        x += by;
    }
}

void main() {
    mut Vec? v = Vec(x: 1);
    v?.move(1);
}
```

## Fix

Check the value for null, then call the method on the variable.

Spec: [Null operators](../spec/13-expressions.md#expressions.null)
