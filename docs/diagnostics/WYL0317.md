# WYL0317

```
error[WYL0317]: '?.' would call 'move', which changes its receiver, on a copy of 'v'
```

`?.` copies a nullable value before the member access. A `mut` method, or an extension method
that takes its receiver as `this ref`, would therefore change the copy.

## Example

```wyl
struct Vec {
    int x;

    mut void move(int by) {
        x += by;
    }
}

void main() {
    mut Vec? v = Vec(x: 1);
    v?.move(1);
}
```

## Fix

Check the value for null, then call the method on the variable.

Spec: [Null operators](../spec/13-expressions.md#expressions.null)
