# WYL0197

```
error[WYL0197]: type arguments belong to the enum, not its variant
```

The type parameters of a generic enum are the enum's, so its type arguments follow its name, not a variant's.

## Example

```wyl
enum Option<T> {
    None,
    Some(T value)
}

void main() {
    var o = Option.Some<int>(1);
}
```

## Fix

Write the type arguments after the enum: `Option<int>.Some(1)`.

Spec: [Type arguments](../spec/11-generics.md#generics.arguments)
