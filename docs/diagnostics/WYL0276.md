# WYL0276

```
error[WYL0276]: 'add' can only be used as a value where a function type is expected
```

An overloaded function is used as a value only where the expected function type selects one overload.

## Example

```wyl
int add(int a, int b) {
    return a + b;
}

int add(int a) {
    return a;
}

int pair(int a, fn(int, int) -> int f) {
    return f(a, a);
}

int pair(long a, fn(int) -> int f) {
    return f(1);
}

void main() {
    pair(1, add);
}
```

## Fix

Use a lambda that calls the intended overload.

Spec: [Function references](../spec/12-functions.md#functions.references)
