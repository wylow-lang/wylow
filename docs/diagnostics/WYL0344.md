# WYL0344

```
error[WYL0344]: '_ =' has no value to discard
```

`_ =` discards the value a call returns, and a call that returns nothing has none.

## Example

```wyl
void log() { }

void main() {
    _ = log();
}
```

## Fix

Call the function without `_ =`.

Spec: [Discarding a value](../spec/14-statements.md#statements.expressions.discard)
