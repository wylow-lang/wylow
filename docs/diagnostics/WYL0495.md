# WYL0495

```
error[WYL0495]: only a class can implement 'ElementOwner<int>'
```

The cycle collector visits objects, and it calls `visitElements` of each object of a class that
implements `memory::ElementOwner`. A struct or enum value is not an object, so the collector would
never call its `visitElements`, and the values the struct reports would never be visited.

## Example

```wyl
import std::memory;

struct Buffer implements unsafe memory::ElementOwner<int> {
    pub void visitElements(ref memory::ElementVisitor<int> visitor) { }
}

void main() { }
```

## Fix

Keep the values in raw memory in a class that implements `ElementOwner`, and hold that class from
the struct.

Spec: [`std::memory`](../spec/a-library.md#library.memory)
