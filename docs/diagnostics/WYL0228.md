# WYL0228

```
error[WYL0228]: argument count of 'inc': expected 1, found 2
```

A call passes one argument for each parameter and no more.

## Example

```wyl
void main() {
    fn(int) -> int inc = x -> x;
    int j = inc(1, 2);
}
```

## Fix

Pass the number of arguments the function takes.

Spec: [Default values and named arguments](../spec/12-functions.md#functions.arguments)
