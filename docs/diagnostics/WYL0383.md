# WYL0383

```
error[WYL0383]: 'is ref' cannot test 'x' of type 'int'
```

An `is ref` or `is in` pattern tests whether a nullable reference refers to a place. The value tested must have a nullable reference type.

## Example

```wyl
void main() {
    int x = 1;
    if (x is ref int place) { }
}
```

## Fix

Test a `ref?` or `in?` value, or remove `ref` to test the value's type.

Spec: [Reference bindings](../spec/15-patterns.md#patterns.references)
