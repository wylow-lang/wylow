# WYL0472

```
error[WYL0472]: shared lambda cannot capture 'node'
```

A shared lambda may run on another thread, and that thread reads what the lambda captured, so each
captured value must be sendable ([Sendable types](../spec/19-concurrency.md#concurrency.sendable)).
A reference to a normal class belongs to one thread.

## Example

```wyl
class Node {
    int value;
}

void keep(escaping shared fn() -> int f) { }

void main() {
    var node = new Node();
    keep(() -> node.value);
}
```

## Fix

Copy what the lambda needs into a sendable value, such as a primitive type, a `String`, or a
reference to a `shared class`.

Spec: [Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)
