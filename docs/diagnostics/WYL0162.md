# WYL0162

```
error[WYL0162]: 'virtual' cannot be used on an enum member
```

Enums are not inherited, so no member of an enum is `virtual`, `override`, `abstract`, or `final`.

## Example

```wyl
enum Color {
    Red;

    pub virtual int code() { return 1; }
}

void main() { }
```

## Fix

Remove the modifier.

Spec: [Methods](../spec/09-enums.md#enums.methods)
