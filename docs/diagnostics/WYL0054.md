# WYL0054

```
error[WYL0054]: method 'List.grow' is not visible here
```

A declaration is used where its visibility doesn't reach: by its name, by an import, as a member, or as a field a pattern matches. The note says how far it reaches.

## Example

```wyl
import std::collections::List;

void main() {
    var list = new List<int>();
    list.grow(4);
}
```

## Fix

Use a declaration that is visible here, or widen the declaration's visibility if it is your own.

Spec: [Visibility](../spec/03-programs.md#programs.visibility)
