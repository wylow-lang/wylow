# WYL0096

```
error[WYL0096]: 'virtual' cannot be used on a struct member
```

Structs are not inherited, so no member of a struct is `virtual`, `override`, `abstract`, or `final`.

## Example

```wyl
struct Point {
    pub virtual void show() { }
}

void main() { }
```

## Fix

Remove the modifier.

Spec: [Struct declarations](../spec/07-structs.md#structs.declarations)
