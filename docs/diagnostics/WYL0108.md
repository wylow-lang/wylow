# WYL0108

```
error[WYL0108]: 'size' cannot have a property body
```

A class has fields and methods. A name followed by a body, as a property is written elsewhere, declares neither.

## Example

```wyl
class Box {
    pub int size { return 1; }
}

void main() { }
```

## Fix

Declare a field `size`, or a method `size()`.

Spec: [Fields](../spec/08-classes.md#classes.fields)
