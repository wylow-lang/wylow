# WYL0539

```
error[WYL0539]: 'copy' names a file 'settings.txt', and package 'parser' copies another file of that name
```

Each file that the `copy` list of any package names goes into the directory of the program's executable, under its own file name. If two packages copy two different files of one name, the second file would replace the first. The compiler therefore reports the `copy` list of the package that comes later in an order where every package comes after its dependencies. Two packages may both name one file, by a path from each one's own directory, because that file is copied once.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    parser { path = "vendor/parser"; }
}

native {
    copy = ["data/settings.txt"];
}
```

```wyl src/main.wyl
void main() { }
```

```text data/settings.txt
mode = shop
```

```wylcfg vendor/parser/package.wylcfg
name = "parser";
kind = "library";
version = "1.0.0";

native {
    copy = ["settings.txt"];
}
```

```wyl vendor/parser/src/parser.wyl
pub int depth() { return 0; }
```

```text vendor/parser/settings.txt
mode = parser
```

## Fix

Rename one of the two files.

Spec: [Dependencies](../spec/03-programs.md#programs.manifest.dependencies)
