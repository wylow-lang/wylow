# WYL0250

```
error[WYL0250]: 'Both' cannot have both 'operator []=' and an 'operator []' that returns 'ref'
```

A type cannot declare both `operator []=` and an `operator []` that returns `ref`, because an assignment would have two meanings.

## Example

```wyl
struct Both {
    int[4] cells;

    mut ref int operator [](int i) {
        return ref cells[i];
    }

    mut void operator []=(int i, int value) {
        cells[i] = value;
    }
}

void main() { }
```

## Fix

Return a value or `in` from the `operator []`, or remove `operator []=`.

Spec: [`operator []=`](../spec/12-functions.md#functions.indexers.setters)
