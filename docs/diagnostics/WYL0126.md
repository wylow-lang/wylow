# WYL0126

```
error[WYL0126]: 'area' must have 'pub'
```

An override has the visibility of the method it overrides, so the method reaches the same places in every subclass.

## Example

```wyl
class Shape {
    pub virtual int area() { return 0; }
}

class Square extends Shape {
    override int area() { return 1; }
}

void main() { }
```

## Fix

Write the same visibility as the overridden method.

Spec: [Virtual methods and overriding](../spec/08-classes.md#classes.overriding)
