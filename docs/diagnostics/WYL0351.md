# WYL0351

```
error[WYL0351]: cannot assign to 'x'
```

A variable that is not `mut` is read-only after its initialization, and so are its fields and elements.

## Example

```wyl
void main() {
    int x = 0;
    x = 1;
}
```

## Fix

Declare the variable with `mut`, or assign only to a mutable variable.

Spec: [Assignment](../spec/14-statements.md#statements.assignment)
