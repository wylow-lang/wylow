# WYL0167

```
error[WYL0167]: enum whose variants carry data cannot have '@Repr'
```

The value of an enum whose variants carry data is not an integer, so it has no integer type.

## Example

```wyl
@Repr(uint)
enum Shape {
    Circle(int radius),
    Empty
}

void main() { }
```

## Fix

Remove `@Repr`, or the data of the variants.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
