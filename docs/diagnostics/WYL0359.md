# WYL0359

```
error[WYL0359]: range has no index
```

A range produces values, not places, so it provides no index.

## Example

```wyl
void main() {
    for (int i, int v : 0..2) { }
}
```

## Fix

Loop over the range's values without an index.

Spec: [Ranges](../spec/14-statements.md#statements.for-each.ranges)
