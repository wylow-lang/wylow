# WYL0038

```
error[WYL0038]: cannot find top-level module or package 'orders'
```

An import's path starts with a module directly in `src/` or the package `std`, never with a module relative to the file.

## Example

```wyl
import orders::Order;

void main() { }
```

## Fix

Start the path at `src/`, or create the module: a directory `src/orders/` with source files in it.

Spec: [Imports](../spec/03-programs.md#programs.imports)
