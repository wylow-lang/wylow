# WYL0464

```
error[WYL0464]: the type of static 'CURRENT' is not sendable
```

Every thread reads a static, so the type of a static must be sendable, and a static is never
written, so its type must also be copyable. A class reference belongs to one thread, and a unique
value has one owner that a static cannot be.

## Example

```wyl
class Node { }

class Settings {
    static Node CURRENT = new Node();
}

void main() { }
```

## Fix

Give the static a value type, such as a struct of primitives, an enum, or `String`. A struct or
fixed array is allowed when every field or element is itself sendable and copyable.

Spec: [Statics](../spec/06-variables.md#variables.statics)
