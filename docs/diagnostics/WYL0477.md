# WYL0477

```
error[WYL0477]: shared lambda cannot capture 'this' outside a shared class's method
```

A shared lambda may run on another thread, so what it captures must belong to no thread
([Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)). A `shared class`'s
object may be read by every thread, so its methods may capture `this`. A normal class's object
belongs to one thread, and a struct's `this` refers to the struct.

## Example

```wyl
class Plain {
    int limit = 0;

    shared fn() -> int reader() {
        return () -> limit;
    }
}

void main() { }
```

## Fix

Copy what the lambda needs to a local first.

Spec: [Shared functions](../spec/19-concurrency.md#concurrency.shared-functions)
