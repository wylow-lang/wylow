# WYL0293

```
error[WYL0293]: cannot find static member 'Up' in 'Direction'
```

Only members the type declares can be reached through the type's name.

## Example

```wyl
enum Direction { North, East }

void main() {
    Direction d = Direction.Up;
}
```

## Fix

Use a member that the type declares.

Spec: [Member access](../spec/13-expressions.md#expressions.members)
