# WYL0327

```
error[WYL0327]: switch expression cannot produce a reference
```

A reference must be bound to a place, and a switch expression produces a value.

## Example

```wyl
struct Bag {
    int[2] items;

    mut ref? int at(int i) {
        return ref items[i];
    }
}

void main() {
    mut Bag bag = Bag();
    var x = switch (1) {
        case 1 -> bag.at(0);
        default -> bag.at(1);
    };
}
```

## Fix

Use a switch statement with a variable for each case.

Spec: [Switch expressions](../spec/13-expressions.md#expressions.switch)
