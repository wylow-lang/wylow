# WYL0135

```
error[WYL0135]: 'super(...)' must be the first statement of a constructor
```

The call to the base class constructor is the first thing a constructor does.

## Example

```wyl
class Shape {
    pub Shape() { }
    pub Shape(int id) { }
}

class Square extends Shape {
    pub Square() {
        int x = 1;
        super(x);
    }
}

void main() { }
```

## Fix

Move `super(...)` to the start of the constructor body.

Spec: [Constructors](../spec/08-classes.md#classes.constructors)
