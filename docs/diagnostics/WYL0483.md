# WYL0483

```
error[WYL0483]: values of an iterator cannot be borrowed with 'ref'
```

The `current` method of an `Iterator<T>` returns a value, not a reference to an element. A loop
over an iterator binds its variable to a copy of that value, so the variable cannot be declared
`ref` or `in`.

## Example

```wyl
import std::collections::List;
import std::iteration::*;

void main() {
    var values = new List<int>();
    for (ref int value : values.iterator().map(v -> v * 2)) { }
}
```

## Fix

Declare the variable without `ref` or `in`. To change the elements of a list in place, loop over
the list, or over its `iterator()`, which is a `RefIterator`, with a `ref` variable:
`for (ref int value : values)`.
