# WYL0554

```
error[WYL0554]: 'files' must list one or more relative paths inside the archive
help: write a path such as 'sqlite-amalgamation-3540100/sqlite3.h'
```

A package's `fetch` entry names the files of the download that the package uses. The compiler
reports this error when the `files` list is empty, or when a path in it is not a relative path
inside the archive, such as an absolute path or a path that holds `..`. A path must also be one
that Windows can write: no segment ends with `.` or a space, no segment is a name that Windows
reserves for a device such as `con`, and the path holds no backslash and no character that a
Windows file name cannot hold.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "fetch_files_form";

native {
    fetch {
        url = "https://files.test/sample.zip";
        sha256 = "3806927d8ed43dea85666325770b2a572b1dcc6e355127eaa87938ec1d85ab11";
        files = [];
    }
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

List one or more paths, each relative to the archive's root, such as
`"sqlite-amalgamation-3540100/sqlite3.h"`. A path has one or more segments separated by `/`, and no
segment is empty, `.`, or `..`. A segment is a file name that every platform accepts, and the path
holds no backslash and no character that a Windows file name cannot hold.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
