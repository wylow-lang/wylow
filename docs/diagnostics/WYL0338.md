# WYL0338

```
error[WYL0338]: 'F123' is not a format specifier
```

A format specifier is one letter followed by an optional precision of at most two digits.

## Example

```wyl
void main() {
    int x = 1;
    std::print($"{x:F123}");
}
```

## Fix

Write a specifier such as `F2`.

Spec: [Format specifiers and alignment](../spec/13-expressions.md#expressions.interpolation.format)
