# WYL0390

```
error[WYL0390]: cannot switch on a value of nullable type 'Direction?' without a 'case null'
```

A switch over a nullable value handles the null value only with a `case null`. Without one, the value must not be nullable.

## Example

```wyl
enum Direction { North, East }

Direction? heading() {
    return null;
}

void main() {
    switch (heading()) {
        case North -> { }
        case East -> { }
    }
}
```

## Fix

Add a `case null`, or check the value for null first and switch on the non-nullable value.

Spec: [`case null`](../spec/15-patterns.md#patterns.cases.null)
