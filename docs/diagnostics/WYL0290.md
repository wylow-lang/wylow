# WYL0290

```
error[WYL0290]: enum 'Color' cannot be created with 'new'
```

An enum value is one of its variants, which is created by naming it.

## Example

```wyl
enum Color { Red }

void main() {
    var c = new Color();
}
```

## Fix

Name a variant, as in `Color.Red`.
