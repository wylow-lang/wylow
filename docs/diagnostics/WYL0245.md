# WYL0245

```
error[WYL0245]: methods returning 'ref' cannot be virtual or abstract
```

A method that returns `ref` or `in` cannot be `virtual` or `abstract`, since the reference points into the receiver.

## Example

```wyl
class Holder {
    mut int size;

    virtual ref int sizeRef() {
        return ref size;
    }
}

void main() { }
```

## Fix

Remove `virtual` or `abstract`, or return the value by value.

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
