# WYL0245

The compiler no longer emits this code, and no other diagnostic will take it.

The code reported a method that returns `ref` or `in` and is `virtual` or `abstract`. Such a
method was refused because the caller held only the receiver, and an override could return a
reference into another object. A reference that a method returns now holds and borrows the object
that it points into, so a virtual method, an abstract method, and an interface method may return a
reference
([decision 0076](../design/decisions/0076-element-iterators.md)).

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
