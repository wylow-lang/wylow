# WYL0117

```
error[WYL0117]: 'A' inherits from itself
```

A class is its own ancestor: following `extends` from it comes back to it.

## Example

```wyl
class A extends B { }

class B extends A { }

void main() { }
```

## Fix

Break the cycle by removing one `extends`.
