# WYL0441

```
error[WYL0441]: cannot move a field out of 'holder'
```

Only a whole local variable or by-value parameter is moved, or a temporary. A field, an element, and what a reference refers to are not moved out of, so a unique value in one cannot be used by value.

## Example

```wyl
unique struct Buffer {
    pub int length;
}

unique struct Holder {
    pub Buffer buffer;
}

void main() {
    var holder = Holder(Buffer(1));
    var taken = holder.buffer;
}
```

## Fix

Use the value in place: bind a reference to it with `in`, or pass it to a `ref` or `in` parameter.

Spec: [Moves](../spec/17-memory.md#memory.moves)
