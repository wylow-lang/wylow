# WYL0526

```
error[WYL0526]: package kind 'app' is neither 'program' nor 'library'
```

A manifest's `kind` entry says whether the package is a program or a library. Its value must be `"program"` or `"library"`. A manifest without a `kind` entry describes a program.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
kind = "app";
```

```wyl src/main.wyl
void main() { }
```

## Fix

Write `kind = "program";` or `kind = "library";`, or remove the entry if the package is a program.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
