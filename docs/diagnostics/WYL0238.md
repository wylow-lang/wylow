# WYL0238

```
error[WYL0238]: static method cannot be 'virtual'
```

A static method has no receiver and cannot be `virtual`, `override`, `abstract`, `mut`, or `final`.

## Example

```wyl
class C {
    static virtual void f() { }
}

void main() { }
```

## Fix

Remove the modifier, or declare the method without `static`.

Spec: [Instance and static methods](../spec/12-functions.md#functions.methods)
