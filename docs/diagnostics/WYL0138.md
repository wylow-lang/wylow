# WYL0138

```
error[WYL0138]: 'this(...)' can only be used in a constructor
```

`this(...)` calls another constructor of the same type, so it is written in a constructor.

## Example

```wyl
class Box {
    pub void reset() {
        this(1);
    }

    pub Box(int size) { }
}

void main() { }
```

## Fix

Remove the call.

Spec: [Constructors](../spec/08-classes.md#classes.constructors)
