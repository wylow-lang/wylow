# WYL0058

```
error[WYL0058]: program has no 'main' function
```

A program's entry point is the function `main` at the top level of its root module. A `main` in another module is an ordinary function.

## Example

```wyl
void start() { }
```

## Fix

Declare `void main()` or `int main()` in a file of the root module: directly in `src/`, or the file compiled on its own.

Spec: [The entry point](../spec/03-programs.md#programs.entry)
