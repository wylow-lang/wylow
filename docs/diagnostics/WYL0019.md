# WYL0019

```
error[WYL0019]: package has no 'src/' directory
```

A package is a directory with a manifest, `package.wylcfg`, and a directory `src/` holding its source files.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";
```

## Fix

Put the source files in `src/`, with `main` in a file directly in it.

Spec: [Packages](../spec/03-programs.md#programs.packages)
