# WYL0205

```
error[WYL0205]: cannot infer type argument 'U' of 'collect' from a lambda that returns no value
```

The lambda's result type contains a type parameter, and a lambda with no value as its result gives
that parameter no type. If the result type is the type parameter itself, the lambda gives it `Unit`
instead, and the call has no error.

## Example

```wyl
U[] collect<U>(fn() -> U[] f) {
    return f();
}

void main() {
    collect(() -> { });
}
```

## Fix

Return a value from the lambda, or write the type argument.

Spec: [Inferring type arguments](../spec/11-generics.md#generics.arguments.inference)
