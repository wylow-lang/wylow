# WYL0205

```
error[WYL0205]: cannot infer type argument 'U' of 'run' from a lambda that returns no value
```

The result type of the function is a type argument, and a lambda with no value as its result gives it no type.

## Example

```wyl
U run<U>(fn() -> U f) {
    return f();
}

void main() {
    run(() -> run(() -> { }));
}
```

## Fix

Return a value from the lambda, or write the type argument.

Spec: [Inferring type arguments](../spec/11-generics.md#generics.arguments.inference)
