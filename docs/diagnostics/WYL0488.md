# WYL0488

```
error[WYL0488]: cannot call 'shift' on 'fixed'
```

An extension method that declares its receiver as `this ref` may change the receiver, so the
receiver must be a place that the caller may change. A variable that is not `mut`, a field reached
through a read-only reference, and an `in` parameter are places the caller may not change.

## Example

```wyl
struct Point {
    pub int x;
}

void shift(this ref Point p) {
    p.x += 1;
}

void main() {
    Point fixed = Point(1);
    fixed.shift();
}
```

## Fix

Declare the variable `mut`, or declare the receiver `this in` or `this` if the extension method
does not change it.

Spec: [Extension methods](../spec/12-functions.md#functions.extensions)
