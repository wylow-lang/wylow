# WYL0466

```
error[WYL0466]: static fields cannot be 'mut'
```

Every static is read-only, so a static field cannot be declared `mut`, which would promise that it
may be assigned after it is initialized.

## Example

```wyl
class Settings {
    static mut int LIMIT = 5;
}

void main() { }
```

## Fix

Remove `mut`.
