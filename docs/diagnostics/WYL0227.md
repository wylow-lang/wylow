# WYL0227

```
error[WYL0227]: cannot find parameter 'b' in 'f'
```

A named argument names a parameter of the function called.

## Example

```wyl
void f(int a) { }

void main() {
    f(b: 1);
}
```

## Fix

Use a parameter's name, or correct the spelling.

Spec: [Default values and named arguments](../spec/12-functions.md#functions.arguments)
