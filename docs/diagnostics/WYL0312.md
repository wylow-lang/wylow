# WYL0312

```
error[WYL0312]: '!' is used on a value of non-nullable type 'Node'
```

`!` removes nullability, so its operand must be nullable.

## Example

```wyl
class Node { int value; }

void main() {
    var n = new Node();
    var v = n!.value;
}
```

## Fix

Remove the `!`.

Spec: [Null operators](../spec/13-expressions.md#expressions.null)
