# WYL0555

```
error[WYL0555]: 'http://files.test/sample.zip' is not an 'https' URL
help: write an absolute URL whose scheme is 'https'
```

A package's `fetch` entry downloads a file from an URL that uses `https`. The compiler reports this
error when the `url` entry is not an absolute URL whose scheme is `https`.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "fetch_url_form";

native {
    fetch {
        url = "http://files.test/sample.zip";
        sha256 = "3806927d8ed43dea85666325770b2a572b1dcc6e355127eaa87938ec1d85ab11";
        files = ["sample/value.h"];
    }
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Write an absolute URL that begins with `https://`.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
