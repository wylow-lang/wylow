# WYL0241

```
error[WYL0241]: returned 'ref' must point into the method's receiver
```

A method returns a reference to a place in its receiver, or to a place reached through the
receiver: a field or element of an object that the receiver refers to. The caller holds the
receiver, and the returned reference holds the object that it points into. A place in a local or a
parameter is neither. A local is gone once the method returns, and nothing holds the storage of a
parameter for the caller.

## Example

```wyl
struct Buffer {
    int[4] cells;

    mut ref int other(ref Buffer o) {
        return ref o.cells[0];
    }
}

void main() { }
```

## Fix

Return a place in `this`, or in an object that a field of `this` refers to. In the example,
return `ref cells[0]`, or have the caller take the reference into `o` itself.

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
