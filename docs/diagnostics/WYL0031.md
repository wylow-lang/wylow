# WYL0031

```
error[WYL0031]: manifest key 'dependencies' cannot be used
```

A manifest may not have a `dependencies` entry. The compiler still checks the entry's contents against the keys that it takes.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

dependencies {
    orders { path = "../orders"; }
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Remove the entry.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
