# WYL0031

The compiler no longer emits this code, and no other diagnostic will take it.

The code reported a manifest's `dependencies` entry, which the compiler read but could not use.
The compiler now reads the libraries that the entry names and compiles them with the program
([decision 0101](../design/decisions/0101-dependencies-libraries-and-versions.md)).

Spec: [Dependencies](../spec/03-programs.md#programs.manifest.dependencies)
