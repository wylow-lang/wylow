# WYL0031

```
error[WYL0031]: manifest key 'native' cannot be used
```

A manifest may not have a `dependencies` or a `native` entry. Their contents are still checked against the keys they take.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "shop";

native {
    link = ["sqlite3"];
}
```

```wyl src/main.wyl
void main() { }
```

## Fix

Remove the entry.

Spec: [The manifest](../spec/03-programs.md#programs.manifest)
