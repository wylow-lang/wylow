# WYL0393

```
error[WYL0393]: switch does not handle every value of type 'Color'
```

A switch must handle every value of the type it matches, either with cases for each value or with a `default` case.

## Example

```wyl
enum Color { Red, Green }
void main() {
    Color c = Color.Red;
    switch (c) {
        case Red -> { }
    }
}
```

## Fix

Add a case for every value, or add a `default` case.

Spec: [Exhaustiveness and unreachable cases](../spec/15-patterns.md#patterns.exhaustiveness)
