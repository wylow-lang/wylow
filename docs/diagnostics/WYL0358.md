# WYL0358

```
error[WYL0358]: cannot loop over the elements of a temporary value
```

The elements of a temporary value are gone after the statement, so a loop cannot view them.

## Example

```wyl
struct Samples {
    int[2] values;

    ReadOnlySpan<int> view() {
        return values;
    }
}

Samples makeSamples() {
    return Samples();
}

void main() {
    for (int x : makeSamples().view()) { }
}
```

## Fix

Store the value in a variable, then loop over the view of it.

Spec: [For-each](../spec/14-statements.md#statements.for-each)
