# WYL0259

```
error[WYL0259]: arguments to 'callback' cannot be named
```

An argument to a function value is positional, since a function type's parameters have no names.

## Example

```wyl
void main() {
    fn(int) -> void callback = (int x) -> { };
    callback(x: 1);
}
```

## Fix

Pass the argument without a name.
