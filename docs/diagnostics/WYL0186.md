# WYL0186

```
error[WYL0186]: static method 'Box.name' cannot implement 'Named.name()'
```

A call through an interface is made on an object or a value, so a static method implements nothing.

## Example

```wyl
interface Named {
    String name();
}

class Box implements Named {
    static String name() { return "b"; }
}

void main() { }
```

## Fix

Make the method an instance method.

Spec: [Implementing an interface](../spec/10-interfaces.md#interfaces.implementing)
