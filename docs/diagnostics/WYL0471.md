# WYL0471

```
error[WYL0471]: the type of field 'root' of shared class 'Tree' is not sendable
```

A shared class's fields are read by every thread that refers to the object, and a copy of the object
is shared rather than moved ([Shared classes](../spec/19-concurrency.md#concurrency.shared-classes)).
So the type of each field must be sendable and copyable, as the type of a static must be
([Statics](../spec/06-variables.md#variables.statics)). A normal class reference belongs to one
thread, and a unique value has one owner.

## Example

```wyl
class Node { }

shared class Tree {
    Node? root;
}

void main() { }
```

## Fix

Give the field a sendable type, such as a primitive type, a `String`, a reference to another shared
class, or `Weak<T>` of a shared class. A struct or fixed array is allowed when every field or element
is sendable and copyable.

Spec: [Shared classes](../spec/19-concurrency.md#concurrency.shared-classes)
