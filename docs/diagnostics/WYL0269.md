# WYL0269

```
error[WYL0269]: variable of nullable function type must be declared 'escaping'
```

A local of nullable function type is declared `escaping`; only a parameter holds a nullable non-escaping function.

## Example

```wyl
void main() {
    (fn(int) -> int)? maybe = null;
}
```

## Fix

Add `escaping` to the declaration.

Spec: [Escaping and non-escaping](../spec/12-functions.md#functions.lambdas.escaping)
