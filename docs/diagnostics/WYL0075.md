# WYL0075

```
error[WYL0075]: function type is missing 'fn'
```

A function type starts with `fn`; a parenthesized list of types is not a type.

## Example

```wyl
void run((int) -> int f) { }

void main() { }
```

## Fix

Write `fn(int) -> int`.

Spec: [Function types](../spec/04-types.md#types.functions)
