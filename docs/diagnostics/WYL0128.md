# WYL0128

```
error[WYL0128]: class cannot be both 'abstract' and 'final'
```

An abstract class exists to be extended, and a final class cannot be.

## Example

```wyl
abstract final class Shape { }

void main() { }
```

## Fix

Remove one of the modifiers.

Spec: [Abstract and final classes](../spec/08-classes.md#classes.abstract)
