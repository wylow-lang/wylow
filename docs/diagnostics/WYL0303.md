# WYL0303

```
error[WYL0303]: static method 'origin' cannot be called through a value
```

A static method belongs to the type and is called through the type's name.

## Example

```wyl
struct Point {
    int x;

    static int origin() { return 0; }
}

void main() {
    var p = Point(1);
    p.origin();
}
```

## Fix

Write `Point.origin(...)`.

Spec: [Calls](../spec/13-expressions.md#expressions.calls)
