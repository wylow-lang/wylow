# WYL0509

```
error[WYL0509]: cannot match union 'Cell' with a pattern
```

A pattern reads the fields of the value that it matches. A union holds only one of its fields, and
the union does not record which one, so no pattern can read a union's fields safely.

## Example

```wyl
@Include("cell.h")
extern {
    union Cell {
        pub int whole;
        pub float real;
    }
}

void main() {
    var cell = Cell();
    if (cell is Cell(var whole, var real)) {
        std::print(1);
    }
}
```

## Fix

Read the field that the union holds inside an `unsafe` block.

Spec: [Structs and unions](../spec/21-interop.md#interop.extern.c-structs)
