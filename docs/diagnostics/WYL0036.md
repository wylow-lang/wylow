# WYL0036

```
error[WYL0036]: imports must come before the file's declarations
```

A file's imports come first, before any of its declarations.

## Example

```wyl
struct Point { }

import std::List;

void main() { }
```

## Fix

Move the import to the top of the file.

Spec: [Imports](../spec/03-programs.md#programs.imports)
