# WYL0431

```
error[WYL0431]: '@Acyclic' takes no arguments
```

`@Acyclic` marks a class and takes nothing. An annotation's arguments are the ones its form gives, as
`@Align(16)` and `@Repr(uint)` do.

## Example

```wyl
@Acyclic(1)
class Tree { }

void main() { }
```

## Fix

Remove the arguments.

Spec: [Annotation syntax](../spec/22-annotations.md#annotations.syntax)
