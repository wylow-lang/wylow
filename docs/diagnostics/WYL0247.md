# WYL0247

```
error[WYL0247]: only 'operator []' and 'operator []=' can be declared
```

The only operators a type can declare are `operator []` and `operator []=`.

## Example

```wyl
class C {
    int operator +(int a) {
        return a;
    }
}

void main() { }
```

## Fix

Remove the operator, or use a method of another name.

Spec: [Indexers](../spec/12-functions.md#functions.indexers)
