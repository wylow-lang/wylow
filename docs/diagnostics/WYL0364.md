# WYL0364

```
error[WYL0364]: loop index type: expected 'int', found 'long'
```

A loop index is an `int`.

## Example

```wyl
void main() {
    int[3] a = [1, 2, 3];
    for (long i, int v : a) { }
}
```

## Fix

Declare the index as `int`.

Spec: [Indices and keys](../spec/14-statements.md#statements.for-each.indices)
