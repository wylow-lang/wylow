# WYL0547

```
error[WYL0547]: non-escaping field 'reset' cannot have an initializer
note: a constructor sets it from one of its parameters
```

A function field of a `ref struct` is non-escaping unless it is declared `escaping`. A non-escaping
field refers to a function that a variable of the struct's creator keeps alive, so the field gets
its value only from a parameter of a constructor. An initializer would make a function that nothing
keeps alive.

## Example

```wyl
ref struct Visitor {
    fn() -> void reset = () -> { };
}

void main() { }
```

## Fix

Remove the initializer and pass the function to the constructor, or declare the field `escaping`
if the struct may own the function.

Spec: [`ref struct`s](../spec/07-structs.md#structs.ref)
