# WYL0169

```
error[WYL0169]: only enums whose variants carry no data can give variants values
```

Only the variants of an enum that carries no data have integer values.

## Example

```wyl
enum Shape {
    Square = 4,
    Circle(int radius)
}

void main() { }
```

## Fix

Remove the value, or the data of the variants.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
