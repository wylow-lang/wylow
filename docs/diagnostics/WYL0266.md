# WYL0266

```
error[WYL0266]: 'mut' must come before 'escaping'
```

`mut` comes before `escaping`.

## Example

```wyl
void main() {
    escaping mut fn() -> void late = () -> { };
}
```

## Fix

Write `mut escaping`.

Spec: [Escaping and non-escaping](../spec/12-functions.md#functions.lambdas.escaping)
