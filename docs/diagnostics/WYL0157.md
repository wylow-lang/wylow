# WYL0157

```
error[WYL0157]: variant 'Shape.Circle' carries data
```

A variant that carries data is created with the values of its fields, in parentheses.

## Example

```wyl
enum Shape {
    Circle(int radius),
    Empty
}

void main() {
    var s = Shape.Circle;
}
```

## Fix

Write the values: `Shape.Circle(2)`.

Spec: [Variants](../spec/09-enums.md#enums.variants)
