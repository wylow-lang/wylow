# WYL0192

```
error[WYL0192]: type parameter 'T' is already defined
```

The type parameters of a declaration have different names.

## Example

```wyl
struct Pair<T, T> {
    pub T first;
}

void main() { }
```

## Fix

Rename one of them.

Spec: [Type parameters](../spec/11-generics.md#generics.parameters)
