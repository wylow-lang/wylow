# WYL0302

```
error[WYL0302]: instance method 'Point.reset' cannot be called through its type
```

An instance method operates on an instance. The type's name provides no instance.

## Example

```wyl
struct Point {
    int x;

    mut void reset() { x = 0; }
}

void main() {
    Point.reset();
}
```

## Fix

Call the method on a value of the type.

Spec: [Calls](../spec/13-expressions.md#expressions.calls)
