# WYL0417

```
error[WYL0417]: cannot reassign 'view'
```

A `ref struct` variable views what it is initialized with for its whole scope, so it cannot be
assigned again.

## Example

```wyl
void main() {
    mut int[2] first = [1, 2];
    mut int[2] second = [3, 4];
    Span<int> view = first;
    view = second;
}
```

## Fix

Declare a new variable for the other view.

Spec: [Second-class values](../spec/17-memory.md#memory.second-class)
