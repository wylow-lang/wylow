# WYL0507

```
error[WYL0507]: the result of 'mode' has enum type 'Mode', which only a parameter of an extern function can have
```

An enum declared with `@Repr` crosses into C++ as its integer type, but only as a parameter of an
extern function. C++ code can return or store an integer that is not a value of the enum. If the
program received such an integer as an enum, the enum would hold a value that it has no variant
for. A result, a constant, and a field therefore take the integer type instead.

## Example

```wyl
@Repr(uint)
enum Mode {
    Read,
    Write,
}

@Include("files.h")
extern {
    Mode mode();
}

void main() { }
```

## Fix

Declare the integer type, as in `uint mode();`. The program then converts the integer to the enum
with `as`, which panics on a value that the enum does not have.

Spec: [Blittable types](../spec/21-interop.md#interop.blittable)
