# WYL0507

```
error[WYL0507]: field 'mode' has enum type 'Mode', which only a parameter or the result of an extern function can have
```

An enum declared with `@Repr` crosses into C++ as its integer type, but only as a parameter or the
result of an extern function. The call of an extern function checks the integer that C++ returns,
and it panics if the enum has no variant with that value. C++ code can write an integer into a
field or a constant at any time, and the program would read the integer with no check. If the
program read an unchecked integer as an enum, the enum would hold a value that it has no variant
for. A field and a constant therefore take the integer type instead. A `@CCallback` function
receives its parameters from C++ and returns its result to C++, so it takes the integer type for
both as well.

## Example

```wyl
@Repr(uint)
enum Mode {
    Read,
    Write,
}

@Include("files.h")
extern {
    struct File {
        pub Mode mode;
    }
}

void main() { }
```

## Fix

Declare the integer type, as in `pub uint mode;`. The program then converts the integer to the enum
with a cast, as in `(Mode)file.mode`, which panics on a value that the enum does not have.

Spec: [Blittable types](../spec/21-interop.md#interop.blittable)
