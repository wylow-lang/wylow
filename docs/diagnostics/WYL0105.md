# WYL0105

```
error[WYL0105]: cannot call 'mut' method 'reset' on 'p'
```

A `mut` method changes the value it is called on, so it is called on a mutable place. A variable that is not `mut`, an `in` parameter, and an element of a `ReadOnlySpan` are read-only.

## Example

```wyl
struct Point {
    pub int x;

    pub mut void reset() { x = 0; }
}

void main() {
    Point p = Point(1);
    p.reset();
}
```

## Fix

Declare the variable `mut`, or call the method on a different place.

Spec: [`mut` methods](../spec/07-structs.md#structs.methods.mut)
