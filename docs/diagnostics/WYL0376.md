# WYL0376

```
error[WYL0376]: only integer, character, and 'bool' literals can be patterns
```

A constant pattern is an integer, character, or `bool` literal. No other literal is a pattern.

## Example

```wyl
void main() {
    switch (1.5) {
        case 1.5 -> { }
        default -> { }
    }
}
```

## Fix

Use an integer, character, or `bool` literal, or bind the value with `var` and test it in a guard.

Spec: [Kinds of patterns](../spec/15-patterns.md#patterns.kinds)
