# WYL0415

```
error[WYL0415]: 'ReadOnlySpan<int>' cannot view a temporary value
```

A `ref struct` cannot view a temporary struct, which is gone after the statement.

## Example

```wyl
struct Samples {
    int[2] values;

    ReadOnlySpan<int> view() {
        return values;
    }
}

Samples make() { return Samples(); }

void main() {
    ReadOnlySpan<int> view = make().view();
}
```

## Fix

Store the value in a variable first, then view it.

Spec: [Second-class values](../spec/17-memory.md#memory.second-class)
