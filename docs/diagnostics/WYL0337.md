# WYL0337

```
error[WYL0337]: alignment is too large
```

An alignment is held in an `int`, so its magnitude must fit in that type.

## Example

```wyl
void main() {
    int x = 1;
    std::print($"{x,9999999999}");
}
```

## Fix

Use an alignment below 2147483648.

Spec: [Format specifiers and alignment](../spec/13-expressions.md#expressions.interpolation.format)
