# WYL0090

```
error[WYL0090]: 'ref' variable cannot be declared 'escaping'
```

`escaping` is for variables that hold a function; a `ref` variable refers to a place.

## Example

```wyl
void main() {
    mut int n = 1;
    ref escaping int alias = n;
}
```

## Fix

Remove `escaping`.

Spec: [`ref` and `in` variables](../spec/06-variables.md#variables.references)
