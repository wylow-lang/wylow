# WYL0239

```
error[WYL0239]: 'return ref' can only be used in a method that returns 'ref' or 'in'
```

`return ref` is written only in a method whose return type is `ref` or `in`.

## Example

```wyl
struct Buffer {
    int[4] cells;

    int plain() {
        return ref cells[0];
    }
}

void main() { }
```

## Fix

Return the value with `return`, or declare the method's return type as `ref` or `in`.

Spec: [Returning references](../spec/12-functions.md#functions.ref-returns)
