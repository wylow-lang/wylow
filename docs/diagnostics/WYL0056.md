# WYL0056

```
error[WYL0056]: return type 'Ticket' is less visible than function 'next'
```

A declaration's signature names only types visible as far as the declaration reaches, so that code that may use the declaration may name the types in it: parameter and return types, field types, variant field types, base classes and interfaces, bounds, and their type arguments.

## Example

```wyl
struct Ticket {
    int id;
}

pub Ticket next() { return Ticket(1); }

void main() { }
```

## Fix

Make the type as visible as the declaration (`pub struct Ticket`), or the declaration as visible as the type.

Spec: [Visible signatures](../spec/03-programs.md#programs.visibility.signatures)
