# WYL0270

```
error[WYL0270]: 'escaping' cannot be declared on a parameter of non-function type 'int'
```

`escaping` is written on a parameter or local of function type.

## Example

```wyl
void wrongType(escaping int x) { }

void main() { }
```

## Fix

Remove `escaping`, or change the declaration to a function type.

Spec: [Escaping and non-escaping](../spec/12-functions.md#functions.lambdas.escaping)
