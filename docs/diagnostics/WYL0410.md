# WYL0410

```
error[WYL0410]: 'ref' variable cannot refer to nullable variable 'value'
```

A `ref` or `ref?` variable cannot refer to a nullable local: a null check could narrow the local,
and the reference could then set it to null.

## Example

```wyl
void main() {
    mut int? value = 1;
    ref int? alias = value;
}
```

## Fix

Pass the local by `ref` to a function instead, or copy it.
