# WYL0220

```
error[WYL0220]: 'ref' can only be used on parameters
```

The `ref` and `in` modes apply to parameters and not to a variant's fields.

## Example

```wyl
enum Refs {
    A(ref int x),
}

void main() { }
```

## Fix

Remove `ref`, or declare the value as a parameter of a function or method.

Spec: [Parameter modes](../spec/12-functions.md#functions.parameters.modes)
