# WYL0347

```
error[WYL0347]: '++' can only be applied to a numeric variable
```

`++` and `--` apply to numeric variables only.

## Example

```wyl
void main() {
    mut bool flag = true;
    flag++;
}
```

## Fix

Increment a numeric variable, or assign the new value explicitly.

Spec: [Assignment](../spec/14-statements.md#statements.assignment)
