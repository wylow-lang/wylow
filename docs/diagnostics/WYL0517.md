# WYL0517

```
error[WYL0517]: pointer casts can only be used in 'unsafe' code
```

`(U*) p` converts a pointer to another pointer type without changing the address. Reading or
writing storage through a pointer of the wrong type is undefined behavior, so the cast is an unsafe
operation.

## Example

```wyl
void main() {
    int* p = null;
    uint* bits = (uint*) p;
}
```

## Fix

Cast in an `unsafe` block or an unsafe function.

Spec: [Pointers](../spec/20-unsafe.md#unsafe.pointers)
