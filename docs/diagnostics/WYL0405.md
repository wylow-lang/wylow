# WYL0405

```
error[WYL0405]: 'ref' variable of type 'long' cannot refer to a 'int'
```

A reference has exactly the type of the place it refers to, and no conversion applies.

## Example

```wyl
void main() {
    int value = 1;
    ref long wide = value;
}
```

## Fix

Refer to a place of the reference's type, or declare the reference with the place's type.
