# WYL0423

```
error[WYL0423]: pointer indexing can only be used in 'unsafe' code
```

`p[i]` is the place `i` elements after the one a pointer points to. Its index is not
bounds-checked, so it is an unsafe operation.

## Example

```wyl
struct Buffer {
    int* data;
}

void main() {
    Buffer buffer = Buffer(null);
    int first = buffer.data[0];
}
```

## Fix

Index in an `unsafe` block, or index an array, a span, or a list, whose indexing is bounds-checked.

Spec: [Pointers](../spec/20-unsafe.md#unsafe.pointers)
