# WYL0281

```
error[WYL0281]: cannot find 'missing' in this scope
```

A name is used only where it is declared and visible.

## Example

```wyl
void main() {
    int value = missing;
}
```

## Fix

Declare the name, correct its spelling, or import it.

Spec: [Names, literals, and `this`](../spec/13-expressions.md#expressions.primary)
