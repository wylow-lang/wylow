# WYL0070

```
error[WYL0070]: cannot infer the type of an empty array
```

An array literal with no elements gives nothing to infer the element type from.

## Example

```wyl
void main() {
    var empty = [];
}
```

## Fix

Write the array where a fixed array type is expected, as in `int[0] empty = [];`.

Spec: [Fixed arrays](../spec/04-types.md#types.fixed-arrays)
