# WYL0092

```
error[WYL0092]: cannot infer a type from 'null'
```

A `ref?` variable declared with `var` takes its type from the place it refers to, and `null` is not a place.

## Example

```wyl
void main() {
    ref? var unknown = null;
}
```

## Fix

Declare the type the variable refers to instead of `var`.

Spec: [`ref` and `in` variables](../spec/06-variables.md#variables.references)
