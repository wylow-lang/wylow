# WYL0304

```
error[WYL0304]: 'danger' is unsafe and can only be called in 'unsafe' code
```

An unsafe function performs operations the language does not check. Its callers must mark the call as unsafe.

## Example

```wyl
unsafe int danger(int x) { return x; }

void main() {
    var n = danger(1);
}
```

## Fix

Call it inside an `unsafe` block, or make the containing function unsafe.

Spec: [Calls](../spec/13-expressions.md#expressions.calls)
