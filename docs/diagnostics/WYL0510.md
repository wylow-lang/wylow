# WYL0510

```
error[WYL0510]: return type 'int' of 'codec_encode' does not match the C++ function 'codec_encode'
```

The compiler compares each extern function's parameters and return type with those of the C++
function that it names. Two types match if they are the same type, if both are integer types of
the same size and signedness, or if both are pointers whose pointed-to types match. The C++
compiler makes the comparison when it compiles the program, so the error appears when the program
is built.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "codec";
```

```cpp native/codec.h
#pragma once
#include <cstdint>
int64_t codec_encode(int32_t value);
```

```wyl src/main.wyl
@Include("codec.h")
extern {
    int codec_encode(int value);
}

void main() { }
```

## Fix

Declare the types that the C++ function has: `long codec_encode(int value);`.

Spec: [Signature checks](../spec/21-interop.md#interop.signatures)
