# WYL0165

```
error[WYL0165]: '@Repr' takes one integer type
```

`@Repr` takes the one integer type of the enum.

## Example

```wyl
@Repr
enum Color {
    Red,
    Green
}

void main() { }
```

## Fix

Write `@Repr(uint)`, or another integer type.

Spec: [Integer representations](../spec/09-enums.md#enums.repr)
