# WYL0513

```
error[WYL0513]: the C++ compiler rejects extern function 'codec_missing'
note: 'codec_missing' has not been declared in '::'
```

The compiler checks an extern declaration against its header by compiling C++ code that uses the
declaration's C++ names. If the C++ compiler rejects that code for a reason other than a failed
signature or layout check, the error is reported at the declaration, and the C++ compiler's own
message follows as a note. The usual reason is a name that the header does not declare, or that
the header declares in another namespace.

## Example

A package, file by file:

```wylcfg package.wylcfg
name = "codec";
```

```cpp native/codec.h
#pragma once
void codec_reset();
```

```wyl src/main.wyl
@Include("codec.h")
extern {
    void codec_missing();
}

void main() { }
```

## Fix

Name the C++ declaration. Use `@CppName` or `@CppNamespace` where its C++ name differs from the
member's name.

Spec: [C++ names](../spec/21-interop.md#interop.extern.names)
