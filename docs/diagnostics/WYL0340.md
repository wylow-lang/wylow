# WYL0340

```
error[WYL0340]: format specifier 'F2' cannot format a value of type 'int'
```

An integer specifier applies to integers, and a floating-point specifier applies to `float` and `double`.

## Example

```wyl
void main() {
    int x = 1;
    std::print($"{x:F2}");
}
```

## Fix

Use a specifier that matches the value's type.

Spec: [Format specifiers and alignment](../spec/13-expressions.md#expressions.interpolation.format)
